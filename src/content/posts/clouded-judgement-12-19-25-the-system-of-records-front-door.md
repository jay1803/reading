## TL;DR
AI 时代的企业 SaaS 面对的不是"消亡威胁"，而是"前门转移"问题：系统记录层会存活，但价值几乎可以全部被掌控新接口层的人拿走——就像 OTA 吞掉了 GDS 的大部分市值。

## 核心主张拆解
旅游行业的 GDS 历史是最清晰的参照系。Sabre、Amadeus 等 GDS 平台既是旅行社系统的"真相来源"，也是前台交互入口；互联网带来 Expedia / Booking，后者在 GDS 之上建起了新的消费者前门。GDS 没有消失，但市值对比已经翻转：Booking 约 1750 亿美元，Amadeus 约 300 亿，Sabre 不足 10 亿。

作者认为 Salesforce / Workday / ServiceNow 当前处于 OTA 出现前的 GDS 位置：既持有数据，又拥有人机交互前门。AI Agent 是新型"用户"，将以远超人类的频率调用这些系统——这意味着一个新的前门正在形成，而这个前门目前仍无归属。谁控制了 agent 前门，谁就拿走大部分增量价值。

## 值得质疑
GDS 案例中，OTA 开拓的是此前几乎不存在的消费者自助预订市场——是增量市场；而企业 AI Agent 主要替代现有人工工作流，不一定带来同等量级的市场扩张，价值转移幅度可能被高估。作者提到两种应对策略（主动建前门 vs. 防御性数据锁仓），但对哪种更可能发生、或已有哪些信号，几乎没有展开论证。

## 剩下的那个想法
真正的赌注是：传统 SaaS 巨头能否在被降格为"提供数据 API 的底层"之前，亲手建起 agent 编排层？现有数据护城河是防线还是幻觉，取决于 agent 协议能否绕过数据壁垒直接打通替代方案。Satya 所说的"dumb CRUD database"，可能是结果，也可能是过程。
