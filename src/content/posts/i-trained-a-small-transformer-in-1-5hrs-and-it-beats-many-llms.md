一个从零训练的小型 Transformer，在单张 RTX 5090 上训练约 1.5 小时，就能在 ARC-1 public eval 上取得约 44%—45% 的成绩，达到作者所比较的 TRM、HRM 水平，并在 ARC-2 上取得 7%。这项结果支持作者的核心判断：现有 Transformer 在**样本效率**上的潜力尚未被充分挖掘，ARC 上的部分进展无需依赖递归架构、大规模预训练或大量合成数据。标题所称的"超过许多 LLM"有明确的比较边界：正文最终将主要对照限定为采用相近 test-time training 方式的模型，并承认不同训练范式之间的成本和成绩不能直接混比。

作者选择 ARC，是因为它能把少样本学习的困难集中暴露出来：约一千道谜题，每道题有不同的转换规则，却共享颜色、空间关系等基础概念；模型必须从少量输入输出示例中学习新规则。作者认为，评测所需概念已包含在训练集中，使它适合检验模型能否高效重组已有知识。他的研究目标分为两步：先找出现有 Transformer 和深度学习方法的样本效率上限，再探索突破这些上限的新方法；降低实验成本，则能让缺乏计算资源的研究者参与并充分运行消融实验。

模型把每个输入输出网格对编码成 token 序列，用小型自回归 Transformer 学习，并在测试阶段从随机初始化开始，联合利用训练题与评测题中可见的示例，始终隐藏评测题测试输出。每道题拥有独立、可学习的 additive embedding，使模型能在共享参数中跨任务学习，同时区分各题的规则；3D RoPE 则表示输入输出两个二维网格中的位置。训练使用颜色置换和二面体变换进行数据增强；推理时对测试输入施加多种变换，将预测结果逆变换回原坐标系，再提交出现频率最高的两个答案，这套流程称为 AAIVR。

相较上一版，提分主要来自现代化架构、更高的数据多样性与更充分的随机打乱，以及把网络从四层加深到八层。架构更新包括用 RMSNorm 替代 LayerNorm、用 SwiGLU 替代 GELU 前馈网络；训练改用 NorMuon 配合辅助 AdamW，并采用 WSD 学习率调度。成本下降则主要来自减少增强样本数量、优化器更换，以及训练时采用 packed variable-length FlashAttention、推理时采用 flex-attention kernels，避免 padding 带来的浪费。增强也从离线扩展转为在线选择，通过输入哈希去重、按周期无放回抽取，提高有限训练量中的独特样本比例。

一个影响训练性质的变化，是**只对输出 token 计算损失**，不再同时学习预测输入。作者报告，这项改动把成绩从约 40% 提高到 44%，同时让结果更稳定、不同运行之间的方差更小；输入 token 的额外学习目标是否挤占了有限模型容量，仍只是他的解释假设。更值得注意的是，新方案的测试损失更差，解题成绩却更好，说明在小数据集上追求更低的验证损失，未必能选出真正更善于完成任务的模型。优化器也呈现类似的指标与行为差异：普通 Muon 虽然训练更快，但后期损失和成绩会停滞，需要大幅降低 momentum 或学习率；换成 NorMuon 后，这一问题消失。

新增训练数据来自 ARC-2 中与 ARC-1 不重叠的题目。ARC-2 包含 773 道来自 ARC-1 的题目，以及 347 道新题；由于重复部分包含大量 ARC-1 评测题，直接混入训练会造成答案泄漏。作者表示已过滤掉全部 773 道重复题。去掉新增数据、仅使用 ARC-1 与 ConceptARC，成绩仍约为 40%，但需要约两倍计算量，因此数据扩充同时改善了成绩和训练效率。

消融实验表明，**表示方式与跨任务学习**是成绩的重要来源。把 3D RoPE 换成 1D 位置编码，或移除 per-task embedding，成绩都会降至约 24%，并在约 25% 附近饱和；恢复对输入 token 的训练，成绩约为 39%。如果采用 CompressARC 式的逐题独立从零训练，并同时学习输入输出，成绩降至约 18%；逐题独立训练、只学习输出则约为 15%。这些结果说明，在这一配置下，共享参数上的联合学习、题目身份表示和网格空间表示，比单纯改变训练目标更关键，也表明逐题独立适应与批量联合适应不能视为同一种实验条件。

围绕"在测试集上训练"的争议，作者强调必须区分评测题提供的示例与真正隐藏的测试输出：ARC 是 meta-learning benchmark，系统本来就需要从评测题中的示例学习，禁止的是利用待预测答案。他将利用评测输入的信息归为 transductive reasoning，并指出 ARC 社区允许 test-time training；测试政策中"不能预先知道测试内容"的限制，在他的理解中针对设计系统的人，防止人为按照评测题定制归纳偏置。与此同时，他接受一项实质性批评：同时拿到整批评测题并联合训练，与现实中逐个面对新问题的情境存在差异，这种能力及其收益需要在比较时明确交代。

成本口径也必须与训练方式一起说明。作者表示，所报成本包含从随机初始化训练到全部题目推理的 lifetime compute，并以此前约两小时 RTX 5090 租用成本合计 0.67 美元说明其低成本主张。但把联合训练的总成本除以题目数，会摊薄训练开销；LLM 的排行榜成本又往往只计算在线推理，忽略大规模离线预训练。为减少误导，他改为展示总生命周期计算成本，主要比较 TRM、HRM、CompressARC，并补充训练方式相近的消融实验。他还认为，公开评测题的答案已存在于互联网，因此 LLM 的 public eval 分数无法排除训练污染，应更重视私有评测。

这些结果也让作者质疑 ARC 成绩背后的若干流行解释。普通 Transformer 达到相近成绩，说明现有证据不足以把 TRM、HRM 的成功归因于递归循环与 deep supervision；他认可递归可以在不同比例增加内存搬运的情况下增加计算，但认为其独立提分作用仍缺少充分消融。他还指出，TRM 宣传的"7M 参数"未计入量级超过一亿的可训练 embedding 权重，HRM 也有类似问题，因此模型规模的表述需要区分主体网络与全部训练参数，并进一步检验 embedding 对成绩的贡献。

对 LLM 的 ARC 进展，作者给出的解释是：后训练能让模型学会越来越多 ARC 题型，但这些成绩尚不能单独证明一般抽象推理能力。早期预训练模型表现差，随后 OpenAI o1 达到 75%，而 ARC-2 发布后，包括推理模型在内的成绩再次大幅下降；此后推理模型持续进步，base model 却仍停留在个位数。在作者看来，这组现象更支持成绩依赖后训练及相关训练数据覆盖程度的解释，其中合成 ARC 数据的具体作用仍是推断。他依然看好 LLM 随计算和数据增长继续提分，也认可推理成本下降，但认为排行榜已难以隔离样本效率、训练数据与通用能力之间的关系。

因此，作者主张让 ARC-1/2 更明确地服务于样本效率研究：禁止离线预训练，要求模型提交后从零训练，以限制预先灌入合成题库；不同训练范式分开绘图，避免混用在线成本与全生命周期成本。这是他的评测改革建议，并非现行规则。他同时承认自己的方法仍依赖人工设计的数据增强，希望后续消除这些处理，并尝试更合适的位置编码、进一步现代化的架构和手写 GPU kernels。多次运行已解题目的并集达到 55%，加上若干接近正确的预测，使他判断 Transformer 框架内有望达到 65%，但这尚未成为单次运行的实测成绩。整项工作的意义在于把"模型能解多少题"推进为一个更严格的问题：在明确的数据、表示和计算预算下，模型究竟需要多少经验才能学会新的规则。
