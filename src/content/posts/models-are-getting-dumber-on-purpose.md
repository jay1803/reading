模型正在用更少的参数获得更强的推理能力，同时主动放弃把大量事实储存在权重里；这种看似"变笨"的变化，本质上是把模型重新设计成负责推理的处理器，再由检索、工具和外部知识库在运行时提供事实。

这种分化已经清楚地反映在基准测试上。GLM-5.2 每个 token 只激活约 400 亿参数，却在 AIME 2026 上取得 99.2%；Qwen3.5 以 170 亿激活参数获得 91.3%，DeepSeek V4-Flash 的激活参数更低至 130 亿。相比之下，据传 2023 年的 GPT-4 每个 token 要运行约 2800 亿参数，却几乎无法解答 AIME 题目。小模型的进步同样剧烈：量化后的 Qwen3.5 9B 只需约 6GB 显存，在 Artificial Analysis 的 intelligence index 上却取得了十亿参数级模型中此前最佳成绩的约两倍。就数学和编程能力而言，模型的单位参数效率正在急剧提高。

然而，这种效率没有免费获得。面对无需推理、只考查事实记忆的问题，模型表现会立即反转：在禁止使用工具的 SimpleQA 上，领先者 Gemini 2.5 Pro 的准确率也只有 53%，意味着最昂贵的模型仍会答错近一半问题。Artificial Analysis 测得 Qwen3.5 4B 和 9B 在知识测试中的幻觉率达到 80% 至 82%；当它们不知道某个事实时，往往会生成一个语气自信、形式可信的错误答案，例如捏造一位冷门十九世纪数学家的出生年份。实验室正在有意识地以**世界知识容量**换取**推理能力**。

事实之所以首先被牺牲，是因为它们直接占用参数容量。"Physics of Language Models"系列对知识容量的测量表明，每个参数大约只能存储两个 bit 的事实信息。若模型要记住每位冷门 Wikipedia 人物的出生年份、每个荷兰市镇的人口，以及所有 npm 包中每个函数的参数顺序，就必须用巨量权重承载这些彼此缺乏统一规律的细节，这也是前沿模型一度膨胀到万亿参数规模的重要原因。

推理程序则更容易压缩，因为大量任务反复使用的是一组有限操作：拆分问题、记录中间状态、检查结果，以及在步骤失败后回溯。蒸馏和针对可验证任务的强化学习，已经证明这些程序能够有效迁移到小模型中。14B 参数的 Phi-4 大量使用合成的教科书式数据训练，因此数学能力很强、冷知识表现很弱；过去这被视为合成数据路线的缺陷，如今却越来越像预期中的设计结果。

缩减知识容量也不意味着模型会失去所有领域认知。幸存下来的知识呈现出"广而浅"的形态：模型知道 PostgreSQL 是什么、适合解决哪些问题，也大致理解 MVCC，但若追问某项查询规划器功能从哪个版本开始提供，它便可能转向编造。保留这种概念层面的广度，可以让模型识别问题所属领域、判断应该查找什么，并评估来源是否可信；版本号、人物生卒年和 API 参数等纵深细节则适合在需要时检索，因为它们存储成本高、查询成本低。

把事实移出权重还有一个时间上的优势。一次前沿模型训练需要数月和数亿美元，而训练结束后，内部知识便开始老化：库的 API、商品价格和人员职位不断变化，一个 2024 年模型掌握的 JavaScript 生态信息，可能在发布前就已有一半过时。更新权重中的事实通常需要重新训练或微调，代价高且周期长。代数规则、问题分解方法和发现来源冲突的能力则能保持多年稳定。让权重主要保存程序，只保留少量背景知识，就能把昂贵、更新缓慢的模型与每天变化的现实状态解耦，训练截止日期的重要性也会随之下降。

被移出的知识将由 **harness** 承担，包括知识库检索、工具调用、网络搜索，以及装有文档和代码的文件系统。编码 agent 已经体现了这种工作方式：它无需背下依赖库的全部 API，可以直接搜索 `node_modules` 或读取文档，得到的还是项目当前安装版本对应的信息，而非训练数据里出现频率最高的旧版本。过去每次前向计算都要携带的固定记忆成本，由此变成仅在需要时支付的查询成本；模型负责推理，推理所需材料则在运行时提供。

沿着这一趋势继续发展，消费级 GPU 上运行具备前沿推理水平的模型可能在几年内成为现实。DeepSeek V4-Flash 每个 token 只激活约 130 亿参数，计算量已经落在消费级硬件范围内，真正无法装入显存的是专家层中其余约 2710 亿参数，而这些专家很大程度上承担事实存储。若把知识从权重中剥离，总参数规模就可能接近实际激活规模；一个 20B 至 40B 的模型经过 4-bit 量化后，可以装入从 2022 年起已进入游戏电脑的 24GB 显卡。这样的本地模型面对裸事实问题时应承认未知并主动查询，但配合成熟的 harness，它已能覆盖今天多数前沿模型的实际用途，同时消除按 token 付费，也无需把私人数据传出本机。

这种架构尤其可能缓解幻觉问题。权重中的错误事实没有可定位的地址：用户无法搜索、比较或直接修改它，纠正单个错误还可能需要一次会影响其他能力的微调，而模型会用同样流畅的语气表达正确与错误的记忆。外部知识库中的事实则具有明确来源；模型引用哪份文档，用户就能打开哪份文档，文档有误时可以立即修正，此后的查询都会获得更新，而无需等待可能相隔一年的下一次训练。检索仍无法把幻觉降到零，因为模型可能误读来源，或错误拼接两份材料，但带有来源的错误至少能够追踪、修复并加入回归测试，从而把难以触碰的权重缺陷转化为普通的数据工程问题。

最终，模型卡上或许不再需要醒目标注知识截止日期，因为权重中剩余的内容以年为尺度老化，世界的当前状态则像程序被交给 CPU 一样，在每次任务执行时动态交给模型。**模型能力的长期进步，可能取决于它是否能少记住一些事实，并把有限参数集中到如何查证、推理和纠错上。**
