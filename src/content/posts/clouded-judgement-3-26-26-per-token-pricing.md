## TL;DR
同样一块 GPU、同样一小时，按 token 出售比按小时出租营收可高出 2-4 倍——定价单位从"硅的成本"变成"输出的价值"，这不是涨价，是对整个 GPU 经济学的重构。

## 核心主张拆解
**旧 SaaS 的容错空间消失了。** 80%+ 毛利率意味着定价不精准也能活；AI 时代每次 agent 调用都触发真实推理成本，定价模型即商业模式。太便宜是字面意义上补贴用户，太贵是把客户送给率先搞清楚的竞争对手。AI 原生公司的上限也因此打开：传统 SaaS 被客户头数封顶，按使用量或结果收费的公司，单客 TAM 理论上无上限。

**Pareto 曲线决定你能收多少钱。** Jensen 在 GTC 展示的 Pareto 图描述吞吐量（高并发、廉价 token）与低延迟（实时 agent、溢价 token）之间的 tradeoff。越靠溢价端，每 GPU 小时营收越高。NVL72（72 块 GPU）每小时约生成 40 亿 token：按市场最低价 $0.15/M 可得 $600-800/小时，而同等算力按小时出租仅 $150-300；中端模型 $8-15/M 则进入千美元级别。同一块 GPU，token 定价的营收是租赁定价的 2-4 倍。

**按 token 定价重写了资产折旧逻辑。** 按小时收租的 GPU 云是追着贬值跑的房东——新芯片上市，租金就跌。按 token 出售，帮销售代理促成交易的 token 比摘要维基百科的 token 贵得多，硬件折旧与营收解耦。Groq 被收购的逻辑在此：LPU 专为低延迟推理设计，嵌入 NVIDIA Dynamo 生态后，整条链路可最大化 token 营收而非时钟收入。

**Credits 是这套逻辑的客户侧隔离层。** 客户买 credits，credits 换取跨产品使用量；后端 token 成本通缩、模型组合变化，全在内部消化。这和云厂商承诺消费模型是同一本教材——最终赢家是把 token 经济学当作内部优化问题、而不是客户端可见变量的公司。

## 值得质疑
文章的关键数字是作者自制的"示意性数字"，并非公开数据；整套论点对"企业场景需要低延迟"的假设依赖很重，但大多数批处理场景对延迟不敏感，竞争只会把低端 token 价格压得更低。

## AI 原生公司最先被杀死的可能是定价错误，而不是技术
token 成本通缩是确定趋势（Vera Rubin vs Blackwell：推理吞吐 5×，成本 1/10），靠廉价 token 赚差价的模型没有持续性。真正的护城河在于：谁能把 token 挂钩到最贵的结果——而那个答案，目前没人给得出来。
