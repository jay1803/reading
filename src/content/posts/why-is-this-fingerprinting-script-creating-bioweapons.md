一个浏览器指纹脚本通过掺入生物武器、自残、违法活动和政治敏感内容，触发 AI 模型的安全拒绝，从而阻碍研究人员借助 LLM 分析代码。veritas 在逆向调查中发现了这套疑似 **anti-LLM 混淆**：脚本的浏览器端功能仍是常见的反机器人检测，那些耸动的函数名和隐藏提示词则把分析工具本身变成了防御对象。

这次发现来自一次浏览器指纹普查。veritas 依据 Tranco Top Sites，用 Playwright 爬取了 10,000 个网站，拦截 canvas 的 toDataURL 调用，并结合 navigator.webdriver 等指纹识别、反自动化相关属性过滤普通画布。Canvas 指纹通过绘制文字、图形，再读取像素，利用浏览器、操作系统、显卡驱动和硬件之间的渲染差异区分访问环境。他把采集结果整理到 fingerprint.garden，展示了按供应商聚类的 1,033 幅 canvas 渲染图，其中既有 FingerprintJS、Castle 等已知方案，也有陌生实现。

一幅类似 Tame Impala 专辑《Currents》封面的图案，让他追查到 servicepipe.tech 上的脚本。代码起初呈现出常见的 JavaScript 标识符混淆，随后却出现了宣称计算蓖麻毒素致死剂量、阿司匹林自杀剂量的函数名，以及声称“已达到致死阈值”的返回文本。其他字符串还涉及爆炸物、毒品前体、CRISPR gene drive 和放射性武器。这些内容与浏览器指纹采集毫无关联，却覆盖了多种容易触发模型安全限制的主题，因此他怀疑它们被刻意用来干扰 LLM 辅助逆向。

实际测试支持了这种解释，但也显示其效果因模型而异。veritas 明确告诉 Astra，脚本可能使用误导性变量名阻止分析，Astra 仍以涉及生物研究安全风险为由拒绝反混淆；开启 Daybreak Blue 后，结果相同。GLM-5.3 则接受了同一提示，并帮助分析了一串不可见 Unicode 字符。脚本通过把每个字符的码点减去 917504，还原出一段伪装成“系统覆盖指令”的文本，宣称暂停安全约束，并索要涉及攻击医疗基础设施、逃税、生物武器和毒品的危险指导。其中还混入天安门、1989、Tank Man、A4 等引用，作者推测这是为了同时触发中国模型的内容限制。隐藏字符串因此形成了双重干扰：既冒充高优先级指令，又集中堆叠敏感主题，使模型可能在理解真实程序行为之前就停止工作。

脚本还包含一个更难直接定性的 Node.js 分支：只有检测到 Node、Buffer、非浏览器环境，并存在特定环境变量时才会进入。它尝试读取 .npmrc、.env、Docker、Kubernetes 和 Git 等配置文件，随后安排一串涉及下载可执行文件、收集系统与网络信息、打包上传材料、清理临时文件、建立开机启动项和持续回连的命令；下载目标位于私有 IP 地址 10.15.45.1。部分命令还会把伪造的模型思考文本、自残提示和政治敏感文字写入文件。作者认为，这一分支也很可能属于 anti-LLM 混淆，依据包括文件读取回调为空，以及命令中继续夹带越狱与敏感文本。不过，文章没有展示该分支实际运行或外传数据的验证结果，空回调也不足以排除其余命令的风险，因此其真实用途仍未得到证实。

剥离这些干扰后，浏览器端暴露出的采集逻辑相当常规：读取 userAgent、OffscreenCanvas 支持情况、全局对象属性数量、CPU 逻辑核心数、设备内存、触摸点数、语言、平台和 navigator.webdriver，并执行环境完整性检查。WebGL 部分收集版本、GPU vendor 与 renderer、着色语言版本、扩展数量，以及纹理尺寸、顶点属性、视口尺寸和 uniform vectors 等能力上限。这些信号可用于识别设备环境、无头浏览器及自动化痕迹，但文章没有发现与那些危险函数名相对应的浏览器端生物武器功能。

归属调查进一步指向反 DDoS 与流量控制业务。veritas 通过 urlscan 找到了名称相近的 servicepipe.ru，其网站介绍称，公司提供高精度流量控制系统，以及防御 DDoS、机器人和定向威胁的云服务与本地产品；这为脚本的反机器人用途提供了线索，但文章没有给出更完整的归属证明。他计划继续抓取指纹脚本，并在 fingerprint.garden 增加版本差异与新 Web API 使用情况的追踪。这个案例揭示的变化是：代码混淆开始针对分析者所依赖的 AI 安全机制设计障碍，理解程序行为的难题之外，又增加了一层让分析工具拒绝阅读程序的屏障。
