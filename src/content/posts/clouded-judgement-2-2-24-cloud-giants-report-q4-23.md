### Cloud Giants Report Q4 ‘23
New workloads indicate an increased use of cloud resources and can be seen as a sign of growth and innovation for cloud service providers.

The hyperscalers are really starting to see the tailwind of new workload growth overtake the headwind of optimizations. Sometimes new workloads are AI related. Sometimes they’re classic cloud migrations.

Here’s the broad update on each:
- AWS (Amazon): $97B run rate growing 13% YoY (last Q grew 12%)
- Azure (Microsoft): ~$74B run rate (estimate) growing 28% YoY (last Q grew 28%)
- Google Cloud (includes GSuite): $37B run rate growing 26% YoY (last Q grew 22%, neither are cc)
