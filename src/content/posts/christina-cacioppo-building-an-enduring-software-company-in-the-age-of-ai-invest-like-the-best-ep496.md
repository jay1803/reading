## 嘉宾背景

Christina Cacioppo 是 Vanta 的创始人，曾从事投资工作。她在约八年前创办 Vanta，从帮助企业建立安全与合规流程、完成 SOC 2 等审计起步，再逐步扩展到其他安全领域，以及安全问卷、Trust Center 等向客户证明可信度的工具。按她在访谈中的介绍，Vanta 已拥有约 16,000 家全球客户和五款产品。

## TL;DR

Vanta 的 AI 转型不是给合规软件加一个聊天窗口，而是把多年积累的集成与安全数据变成替客户处理问题的能力；但产品能够执行，不代表团队敢于换掉旧方法，也不代表客户采购和收费模式已经准备好。Christina 愿意暂时吸收推理成本、承担新交互方式的风险，却不愿为了显得像 AI 公司而转售 Token、追求低毛利或包装技术投入。与此同时，她无法完全置身于估值狂热之外：竞争对手的融资叙事会变成员工对薪酬、授权和流动性的现实要求。

## AI 同时放大了技术能力与信任缺口，使“证明自己值得信任”成为更重要的商业需求。

Vanta 最初抓住的需求是：企业为了赢得客户，必须证明自己具有足够的安全能力。Christina 从一开始就把它理解为一家安全公司，而不是单纯的审计工具——帮助企业建立或改善安全项目，再通过 SOC 2、ISO 27001 等审计，以及问卷和 Trust Center，让交易对方认可这些投入。合规是入口，理想状态则是证明企业真实拥有的安全能力，而非只完成一套手续。

她认为，AI 带来了高度兴奋，却没有同步带来对技术公司的信任。围绕数据中心、个人 Agent 等事物的讨论，反而让她感到公众对软件公司的信任正在下降。企业因此更需要说明自己的软件为何可靠、安全、达到可供严肃业务使用的标准。对于 B2B 市场，她相信具体指标、持续改善的轨迹，以及可能由合同支持的承诺，都能帮助建立信任；消费者端更受整体感受影响，她不认为同一套数据说明就足以扭转情绪。

这种变化也在推动采购。过去几年与政府及企业客户接触时，她发现许多机构早已知道自身流程和软件落后，但 AI 让现代化变得更紧迫。CISO 如果只是要求重做企业风险管理项目，预算可能被推迟；如果说明 Agent 带来了新的风险，同一项投入就更容易获得支持。Vanta 希望连接这两端：既帮助企业达到可信标准，也帮助它们向客户、政府与监管者证明已经达到标准，从而推进业务。

## AI 能把低风险问题串成高风险攻击，迫使安全防御从人工排期转向机器速度的持续修复。

Christina 认为，AI 对安全的改变不只是发现更多此前未知的漏洞，更在于模型能够持续尝试，并把多个单独看来无害或低严重度的问题串成攻击路径。人可能在尝试一段时间后放弃，模型却能继续搜索组合。这样一来，过去“这个问题风险不高，九十天内再修”的判断就不再那么稳妥：单项问题的严重度，未必反映它与其他问题连接之后的危险。

把所有问题都标成紧急并不能解决问题。她设想的方向是让机器参与防御，尽可能在发现问题后立即修复，而不是继续依赖人工逐项判断和排期。Patrick 将其描述为持续运行的白帽渗透测试 Agent，旁边配合负责修补的 Agent；Christina 认可这是 Vanta 部分产品可能发展的方向。她预计未来安全攻防会更快、更激烈，人类更多负责设计系统和制定规则，而非批准每一个动作，但通往这种状态的过程不会平顺。

这不意味着 Vanta 要在所有领域直接挑战大型安全厂商。她承认，面向大型企业的一些需求，CrowdStrike 可能做得更好。Vanta 更愿意从已经服务的客户出发，例如处理 AWS、Azure 的配置问题：按她的市场判断，有些客户不会为 Wiz 支付十五万美元，却可能愿意为更符合自身需求的方案支付四五万美元。产品边界因此取决于现有客户、价格承受能力和竞争者所聚焦的市场，而不只是技术上能做什么。

## 既有软件公司的积累只有转化为替客户执行工作的能力，才可能成为 AI 时代的持续优势。

当被问到 Vanta 为什么赢得此前的竞争时，Christina 首先回答的是执行，而不是先发优势。她认为软件公司只能靠持续交付改善客户体验，尤其在别人可能很快做出类似功能的时代，曾经率先进入市场并不能保证未来。过去一年“记录系统已经不值钱”的市场情绪虽然让她不安，却也提出了一个她认可的问题：拥有这些数据之后，公司究竟替客户做了什么？

Vanta 过去的重要投入是集成。它已能连接约四百种工具，从中汇集安全数据，形成内部称为 Trust Graph 的基础。Christina 认为，这些数据让新软件和 Agent 更容易建立，但真正的产品变化是从“指出问题”转向“提出并执行解决方案”。例如，系统发现离职员工仍有账户权限后，不只发出警报，而是准备能够撤销权限的 Agent，询问用户是否执行、是否对其他人员采取相同行动，以及今后是否持续自动处理。授权可以是一次性的，也可以延续到后续任务。

交互方式也随之变化。Vanta 不想预先堆满固定 SaaS 页面，而是让 Agent 根据任务生成界面；客户需要报告时，就基于现有数据按需生成图表，而不是在产品里嵌入一套 Tableau。Christina 相信这既能改善近期体验，也符合软件的长期方向，但她承认这是一场关于采用速度的押注：方向可能正确，市场却还没准备好。已有大型企业希望先关闭 AI 功能，因为非 AI 工具更容易通过采购，购买之后再开启；Vanta 并没有现成的关闭开关，她也不愿为绕过采购流程而把开发时间从实际功能上挪开。

## 团队没有采用 AI，不一定是缺乏能力或意愿，也可能是旧架构与“不允许失败”的预期阻止了尝试。

Christina 认为，领导者首先必须亲自使用工具，并持续更新对能力边界的理解。她建议至少每两周实际动手一次，知道模型擅长什么、会在哪里出错，才能判断“一个 Agent 已经可以替代整个团队”之类的提议。她也修正了自己对员工采用 AI 的看法：过去容易把不主动尝试归因于内在动力不足，现在发现，即使优秀、积极的人也可能被某个具体障碍卡住。

一次企业客户导入流程的重做让她看清了这一点。大客户已有控制措施、政策、风险记录和其他资料，需要把这些内容迁入 Vanta。团队在几轮产品评审中反复提出传统的分步导入向导，尽管她一直要求尝试 LLM。深入追问后，她才发现，团队不是不理解新方向，而是担心“把杂乱文件拖进去就能完成导入”的方案做不出来，同时认为这个项目不允许失败。旧向导至少是他们知道能够交付的东西。

她明确表示，公司愿意押注新流程，并通过持续迭代把它做成。这个风险预期一改变，团队马上愿意推进新的产品评审。最终交付的体验是让用户拖入文件与截图，由 Claude 理解材料、追问缺失信息，再完成配置；按她的描述，它已经上线并运作良好。

工程侧也有类似的条件问题。把编码 Agent 直接丢进八年积累的大代码库，它可能缺乏完整上下文，最后仍要资深工程师在旁照看。Vanta 因而投入代码模块化，让 Agent 能完整理解较小的部分，再有效执行任务。她把这比作过去新工程师入职时的理解成本，只是现在公司想同时让大量 Agent “入职”，旧问题被进一步放大了。

## AI 应用的商业化不能靠转售模型成本来证明价值，也不能把低毛利和技术包装本身当成进步。

Vanta 与客户讨论 Token 定价时，反复遇到一种比较：如果应用只是把 Claude Token 加价出售，客户就会追问，它是否真的比直接使用 Claude 好那么多。Christina 不想主动把应用放进这种竞争，也不认为换成 Credits、隐藏兑换关系，就能消除客户的疑问。她倾向于按结果收费所代表的激励一致性，但还没有找到适用的办法：关闭一张工单是产出，让用户的 Sonos 真正恢复工作才是结果；而文档生成、告警处理、账户注销又是不同工作单位。逐项定价会让客户不断计算“这次交给 Agent 要花多少钱”，增加使用负担。

Vanta 当前的选择是吸收 Token 成本，接受一定毛利下降，先推动使用。Christina 说，约四分之一客户已经进入以 Agent 为中心的流程；她希望扩大这一比例，因为相信执行式体验能够改善留存，再处理后续商业化问题。这不等于为了低毛利而追求低毛利。模型选择上，Vanta 让有安全与合规经验的领域专家编写任务级评估，并检查评估本身是否有效，再据此比较模型。由于其工作更偏向判断和行动，Token 消耗不像编码那样大，目前可以优先考虑质量，而不是只找最便宜的模型。

她对后训练的怀疑也针对投入目的，而非否认其一切用途。她认为，一些公司做后训练主要是为了向投资者证明自己是“真正的 AI 公司”；降低成本可能是合理理由，但质量提升不能想当然。她也承认，按客户数据调整模型，在某些企业部署场景中可能有价值，只是“交给客户一个模型”未必就是最终合适的产品形态，周围仍有体验、集成和部署问题需要解决。

对于 FDE，她认为真实的客户实施工作当然存在，而且这个职位名称确实能吸引愿意深入客户现场、主动解决问题的技术人才。但许多 FDE 工作本质上仍是专业服务，必须与合同规模匹配。Palantir 可以用八位数合同支撑相应投入，只有五六位数合同的公司却未必承担得起同样的人力配置；当前市场对低毛利的容忍，并不能让这种经济性自动变得可持续。

## 创始人可以不认同估值狂热，却不能忽略它通过人才预期、薪酬和流动性要求进入公司经营。

Christina 把当前处境称为认知失调：她仍相信，长期看，高增长、高毛利的企业能够创造大量现金，但市场可能给予增长更快、毛利更低的 AI 企业更高倍数。她不愿为了迎合估值偏好而放弃客户需要的产品和合理经营，却也不能只说市场不理性，因为融资与人才竞争都发生在当下。员工如果觉得自己不在最有前景的“船”上，就会考虑换船。

面对竞争者关于巨大终局和快速估值上调的承诺，Vanta 尝试用实际经营数据回应。她愿意向候选人展示业务指标、公司现状和增长逻辑，而不是简单承诺未来必然达到某个市值。对于已经动摇的员工，她也会追问，对方究竟在优化什么。一位仍留在 Vanta 的优秀负责人曾被新机会吸引，关键并不只是钱，而是觉得在 Vanta 没有足够权力做出改变增长轨迹的决定，而新公司承诺了这种自主权。她的回应是讨论需要什么授权，并让对方真正去做决定。

她最看重的人，是理解公司、客户和领域，能够自主推进、作出大体合理的决定，并在犯错后迅速修正的人。相比通用岗位技能，她现在更重视这些上下文；即使销售技巧略弱，一个真正了解 Vanta 和客户的人也可能更有价值。她估计，顶尖岗位的总薪酬相较五年前已达到约十倍，但仍认为优秀人才的报酬应该更高，内部薪酬差距也可以更大。她看到的约束不是贡献停止增长，而是投资者终究可能重新关注股权激励带来的稀释。

估值和员工持股出售安排，也因此成为她不能忽略的事。她过去主要关注 ARR 及其增长，不太在意倍数波动；如今却必须考虑员工如何比较本公司与其他机会。Vanta 历史上没有做过 tender，但她认为这类流动性安排已被员工视为薪酬的一部分：即使自己不喜欢，也必须提供，或用其他条件补偿缺口。

## 长期创业的动力可以从证明别人错了，转向享受不断重新学习，而可信的领导表达仍须建立在真实相信之上。

Christina 早期的重要动力，是证明那些认为她做不到的人错了。如今这股劲仍在，但已有成果让她多了一份骄傲，也少了一些对抗性。继续创业更像是：既然已经走到这里，就看看还能走多远。她并不是说每天都愉快，而是工作持续变化本身仍然吸引她——刚觉得自己擅长某件事，新的阶段就让她重新感到不擅长，而她喜欢不断学习的过程。

公开表达是这种变化的具体例子。她过去尤其害怕在自己团队面前演讲，因为非常在意大家的看法，也觉得自己是在代表他们。通过反复上台，她逐渐把原本令自己恐惧的事情变成可以发展的能力，也发现自己比预想中更喜欢市场拓展和与人交流。谈到什么让演讲有效时，她认可人们未必记住具体事实，却会记住感受；但对她而言，这不是用情绪代替内容。她必须先真正相信自己所说的内容，才能传递真实投入，否则空洞或敷衍会被听众察觉。

这种持续投入的目标，也不是把 IPO 当成人生清单上的终点。她想建立的是一家长期存在的大型独立软件公司，上市只是可能支持这一目标的手段。她承认，这是创始人的特殊视角，员工可能确实把上市当成重要个人目标；但对她自己而言，核心问题仍是这家公司还能继续做多久、走多远。

## 提到但未深入展开的话题

他们还谈到 Vanta 的广告牌故事：“Compliance that doesn’t suck too much”凭借行业共鸣和认真做事却不端着的幽默感传播，后来公司才发现自己并未签下以为已经锁定的长期合同，最终失去知名广告位；硅谷创始人聚会中的话题包括挖角、FDE 的实际效果和个人 Agent；Christina 转述部分法国客户因担忧美国模型未来的可获得性而转用中国模型的经历；她也简短提出，开源模型周边的部署与工具生态仍有建设空间，销售技术和机器人领域值得关注。
