## TL;DR
OpenAI 单季亏损约 150 亿美元，超过其全年预期营收（130 亿）——微软重组协议的真实逻辑是：用 Azure 的 2500 亿美元消费承诺买下 OpenAI 的自由，同时换取 2032 年前的模型商业权（含 AGI 突破后的成果），但 AGI 一旦被独立专家组认定，收益分成就终止、研究访问也收窄。

## 协议结构
- 微软拿到 OpenAI PBC 的 27% 股份（估值约 1350 亿美元）
- OpenAI 承诺在 Azure 上消费 2500 亿美元，换取可在其他云自由运营的权利
- AWS 是最可能受益的竞争者；Google 若 OpenAI 延伸进广告和浏览器代理，压力最大
- AGI 认定后（或 2030 年），微软的收益分成和研究访问双双缩减

## 财务真相
- OpenAI 权益法投资亏损 41 亿美元下拉微软 GAAP 净利润，但剔除后经营层面实际更健康
- Azure 供应受限（电网接入、数据中心电力）但 RPO 突破 3920 亿美元，未来两年营收能见度创历史高位
- Capex 当季 349 亿（同比 +74%），FY26 全年预计超 1100 亿，且管理层明确"峰值还没到"

## Game Pass 价格重构
- 最终导火索：Call of Duty 黑色行动 6 首日上线 Game Pass，估计蚕食了约 3 亿美元的直接销售
- Ultimate 涨价 50% 至 29.99 美元/月，Xbox 战略转向"多终端层"而非主机专属锁定

## 留下的那个想法
微软的 AI 赌注规模（每季 350 亿 Capex）已经和 OpenAI 的亏损速度（每季 150 亿）在同一个数量级上；两者都押注算力约束会在需求约束之前解除——但如果顺序反了，这张账单会同时到期。
