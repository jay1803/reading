### Cloud Giants Report Q3 ‘23
云巨头（AWS、Azure 和 Google Cloud）对于软件来说并不是一个很好的信号……第二季度（3 个月前）之后，云巨头围绕优化的基调主要是：优化已经开始放松，并净增新的工作负载已拾取。

我相信，尽管软件在 10 年里增长了 5%，但仍能保持不变的更大原因之一是对重新加速的预期（即数字/预测上升）。要么就是人们预计 10 年期利率会回落​​至 3.5%，但感觉不太可能。

Here’s a broad update on AWS, Azure and Google Cloud:
AWS (Amazon): $92B run rate growing 12% YoY (last Q grew 12%)
Azure (Microsoft): ~$66B run rate (estimate) growing 28% YoY (last Q grew 27%)
Google Cloud (includes GSuite): $34B run rate growing 22% YoY (last Q grew 28%, neither are cc)

Azure 也从其 AI 服务中受益匪浅。他们称本季度 3% 的增长来自 Azure AI，这意味着 Azure AI 的运行速度为 1.5B 美元！上季度 Azure AI 的运行费用为 5 亿美元。环比 200% 的增长令人印象深刻。
除去 AI 之外，Azure 同比增长约 25%（恒定货币增长率为 28%，AI 的增长率减去 3%）。上季度，Azure ex AI 同比增长 26%（按固定汇率计算增长 27%，其中 1% 来自人工智能）。
