Agent 的长期记忆应当被设计为开放、可迁移的数据格式，让模型直接读写保留上下文的文字，并通过语义搜索找回相关内容，尽量减少固定处理流水线对模型能力的限制。Cal Paterson 提出的 **Memoryfields** 将这套思路收敛为 Markdown 页面、可选的 YAML 元数据，以及可选的 SQLite 向量索引；真正需要长期保存的是页面，索引只是可以删除、重建的缓存。

这一主张源于真实 Agent 与模型评测之间的差异：评测从空白上下文开始，有助于保证公平；执行实际任务的 Agent 则应当带着已有知识进入工作。Paterson 认为，现有记忆系统有三类常见问题：绑定特定 harness 的系统通过挖掘聊天历史形成记忆，既强化平台锁定，又容易积累大量关于用户的信息，忽略更有用的外部世界知识；复杂系统可能同时依赖 pgvector、Neo4j 和一个专门判断哪些内容值得记住的 LLM，增加运维成本与模型使用难度；追求理想化知识表示的系统则将材料拆成图结构或逻辑命题，使“提炼后的事实”失去原有语境。这些方案都把重心放在记忆处理流程上，Memoryfields 则从模型最终需要读写的数据出发。

采用完整文字页面，首先是因为 Agent 自己生成的记忆没有必要照搬处理历史文档的 RAG 流程。面对大型 PDF，系统可能需要切块、补充信息、反复摘要，才能让模型读懂；但记忆形成时，Agent 已经理解当前内容，可以直接用 Markdown 写下连贯说明。页面可以附带 title、created、updated、uuid 和 summary 等 YAML 字段，正文保留事实之间的关系与背景。为了让整页进入一次向量嵌入，作者建议每页遵守约 8 KB、约 2,000 tokens 的软上限；内容更丰富时增加页面，让每条记忆保持可整体阅读的尺度。

页面如何被找回，比页面之间如何连接更重要。Karpathy wikis 借鉴 Roam 和 Obsidian，以超链接组织 Markdown，要求 Agent 沿知识图谱逐步寻找材料。如果目标藏在 N 层链接之后，就需要 N+1 次串行工具调用，而每次调用可能耗时两三秒。导航还迫使 Agent 根据链接文字、标题或说明判断页面是否值得打开：正文中有用的旁支细节和隐性经验，可能因为标题没有体现而被漏掉。途中读入的首页与无关页面又会占据上下文，使输出受到噪声干扰。

Memoryfields 用基于正文内容的语义搜索直接跳到相关页面，再让 Agent 并行读取这些页面，将检索压缩为一次搜索、一次批量读取。这样既减少串行等待，也降低了知识能否被发现对标题设计的依赖。其关键取舍是：让检索系统负责定位相关内容，让模型阅读有上下文的完整页面，避免模型把大量时间花在图谱导航上。

将记忆暴露为普通文件，也扩大了 Agent 自行解决问题的空间。专门设计的 API 如果接口很多，就要向上下文加载大量接口定义；接口很少，又容易限制访问方式，即使规模适中，也可能没有预见实际需求。文件允许模型使用已经熟悉的工具：作者实际见过 Agent 用 Perl 对整个记忆库执行查找替换，也见过它在记忆中嵌入 CSV，再借助 SQLite 查询。随着模型更擅长 Bash、Markdown 和 SQLite，同一份数据可以获得更灵活的写入、整理和使用方式，无须等待记忆系统新增 API。作者所说的 **“More model, less mechanism”**，就是把这些决策空间留给不断进步的模型。

开放格式还决定了长期积累的知识能否摆脱工具和供应商绑定。Memoryfields 的规范采用 RFC 风格，不限定特定 embedding 模型；标准归档形式是 ZIP，便于交换和保存，但同一套页面也可以放在本地目录、Amazon S3、GitHub 或通过 HTTP 提供。作者自己用 Syncthing 同步个人记忆，用 S3 分享记忆库，并提供配套 CLI 与 skill。默认工具采用 nomic-embed-text-v1.5，理由是其约 270 MB 的体积足够小、可以在无 GPU 硬件上运行，同时保有实用的检索能力；更换嵌入模型不应影响 Markdown 内容的长期价值。

从宽泛定义看，这仍然属于 RAG，但它省去了通常与 RAG 系统相伴的切块、重排序和混合搜索，并且把 Agent 写入记忆与读取记忆放在同等重要的位置。对于“怎样避免存入太多垃圾”的担忧，作者主张宽松记录，相信语义搜索会让不相关材料留在检索结果之外，必要时再清理存储。他特别建议在记忆中加入引用，最好是 URL，使后续 Agent 能核查过时或可疑的信息，并继续充实已有记录。这一策略将记忆质量的维护更多地交给可追溯的来源和后续使用。

可移植性同时带来信任边界：从外部导入的记忆会进入模型上下文，也可能携带恶意指令。作者强调，不应与不可信方共享上下文，包括通过记忆间接共享；静态 ZIP 至少允许接收者先人工审阅，再用 SHA-256 固定经过检查的版本，但这不能解决模型区分正常指令与恶意提示的问题。Memoryfields 最终留下的流程很短：写 Markdown，将整页嵌入并把向量存入 SQLite，需要时语义检索。它将长期资产固定在可读、可审查、可迁移的文字上，让索引、工具和模型都能被替换，而积累的知识继续保留。
