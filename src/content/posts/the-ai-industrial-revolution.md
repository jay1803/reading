## 嘉宾背景
Nivi 主持 Naval Podcast 这期圆桌，Naval 与三位“前沿创始人”讨论 AI 改变生产方式：Guillermo Rauch 正在把 Vercel 做成面向 agents 的 AI cloud；Blake Scholl 在 Boom Supersonic 垂直整合超音速飞机、工厂和喷气发动机；Max Hodak 在 Science 做生物混合脑机接口，用生长在硅上的活神经元恢复感官并探索新的脑区能力。三人的共同点不是“用了 AI”，而是在公司内部重建生产系统：软件工厂、硬件工厂、监管文档工厂和自治工作流。

## TL;DR
这场对话最核心的线索是：AI 正在把“工作产出”从单个任务改成可复制的生产系统。人的价值不再主要体现在亲手写代码、写合规文档、做 spreadsheet 分析，而是体现在选择问题、搭建 agent 可用的 building blocks、设定验证标准、承担最终签字责任，并把物理世界、监管和市场机制接入这个新生产系统。

## 工程师的产出单位变成了“工厂”
Guillermo 认为，工程师过去被评价为“能否交付 output B”，现在更像是“能否生产一个会交付 B 到 Z 的工厂”。这让 10x 工程师的争论被 AI leverage 放大成 100x 或 1000x 工程师：真正的差异来自判断力、架构选择、复用组件选择和 reprompt 能力，而不是 token 消耗量。

Naval 的实践更极端：他不太学习复杂 prompting 技巧，而是用 Codex、Claude、Gemini 反复砸同一问题，以 token 换时间；只要最终输出可验证，模型成本仍远低于人类时间。Max Hodak 补了一层限制：模型当前会“反射”用户在领域里的判断力，高手能从模型里抽出更多东西，junior 虽然会获得提升，但很难自动获得架构品味。

非直觉推断：AI coding 的红利不平均。门槛下降会让更多人进入软件创造，但回报仍集中在能定义系统、识别错误路径、选择抽象层的人手里。

这对应到 Software Factory：工程师的杠杆来自设计一套会继续产出软件的 agent/spec/tool/eval/review 系统，而不是单次把代码写快。

## 纯软件的护城河被压缩，building blocks 反而更值钱
Naval 提出尖锐问题：当模型能用英语理解需求、生成代码，经典软件工程是否还可投资？Guillermo 的回答接近“纯手写软件会贬值，但可复用基础设施会升值”。他引用 Mitchell Hashimoto 的 building block economy：agent 不应该每次都从零发明队列、数据库、邮件系统，而应选择合适的社会化组件，例如 Postgres、BullMQ、ClickHouse 这类稳定基础设施。

这个观点把“库和依赖”重新解释成 agent 的 token cache：已经存在、经过社会验证的组件，可以让模型避免用海量 token 重造文明。Vercel 的立场也因此清楚：agent 越多，agent 依赖的基础设施、部署层、网关、监控和安全工具越关键。

非直觉推断：AI 未必杀死软件基础设施，反而可能把基础设施变成所有 agent 共享的生产资料；真正受压的是只卖通用 CRUD、协作工具或轻量内部工具的软件公司。

## 硬件公司会吃到软件民主化的最大红利
Blake 说 Boom 早期就想把硬件工程流程软件化，因为传统硬件工程大量发生在 Excel、VBScript、邮件交接和工程师个人电脑里，缺少版本控制、测试和自动化。AI 让这个愿景突然变得现实：软件工程师负责架构和系统边界，硬件工程师用 AI 把领域知识写成工具。

他的例子很硬：涡轮叶片需要同时处理冷态和热态形状、空气动力学和结构分析，过去一个工程师一天只能处理一个叶片的一小块分析；现在软件与硬件人员配合，可以实时改变几何并看到结构和气动结果，甚至让两名工程师推进一整台喷气发动机的设计。

Naval 把这延伸到中国：如果硬件供应链强、开源模型可用，原本“硬件好但软件差”的劣势会被压低。Guillermo 则指出，不能产生前沿软件，就会影响一切硬件、工程和生产链条的生成能力。

非直觉推断：AI 对硬件不是“加一个软件界面”，而是把硬件公司的内部知识、仿真、制造、监管和迭代速度全部软件化；这会让小团队做出过去大组织才可能做的物理系统。

## 监管可能变成测试套件，也可能变成代理战争
Max Hodak 认为，AI 在 Science 公司内部最明显的影响之一不是科研本身，而是监管交互：生成文档、追踪 ISO 标准、判断产品演进要满足哪些要求，这些过去需要 regulatory 和 quality 团队数月完成，现在 AI 可以直接处理大部分知识路径。Blake 在 Boom 的例子类似：飞机闪电测试计划可能有 200 页文档，过去改一次飞机就意味着几个月重写；RAG 能把这类工作压到分钟级，降低变更厌恶。

Max 的细分观点很重要：很多 regulation 的目标本身不是错的，干净空气、可游泳河流、产品安全都是真进步；真正拖慢创新的是人类理解、遵循、通信和等待的摩擦。Guillermo 因此把合理监管视为 agent 的 exit criteria 或 test suite：只要规则不矛盾、不荒谬，它们可以成为防止“slop 进空气”的 guardrail。

但 Naval 提醒，监管方也会开始吐 token，形成 agent-on-agent 文档战争；App Store、专利局和政府机构可能被创业者用自动生成材料“DDoS”。Blake 则希望从事前审批转向事后 enforcement，因为当前物理基础设施建设像“每次开车前先写计划给监管等三个月批复”。

非直觉推断：AI 不只会帮公司绕过监管，也可能让监管第一次变成可执行、可验证、低延迟的系统；瓶颈会从“能否写文件”转到“规则是否合理、冲突是否可解、责任如何分配”。

## 医疗创新的深层问题是成本结构和风险归因
Max Hodak 不同意把医疗慢完全归咎于 FDA。他承认 FDA 和监管体系有严重 dysfunction，但更深的问题是政治激励和社会风险偏好：批准十个重要药物没人表扬，一个病人死亡就会被国会质询；这让审批者天然偏向阻止风险，而阻止好东西的机会成本没人看见。

他还指出，Right to Try 和 Single Patient IND 本身不是核心瓶颈，因为 FDA 对医生提出的单病人未批准药物申请批准率超过 99%，甚至能电话批准。真正困难是临床级药物掌握在 IP owner 手里，对方正在花数亿美元跑试验；如果重症患者用药后出事，FDA 可能把 adverse inference 归到药物或 capsid 上，影响整个临床项目。

Max 的中国判断很直接：美国医疗没有真正的私人市场，支付桶基本固定，医疗支出增长跟税收增长走；技术产品越好可以卖越多、总消费增长，而医疗如果两年后花费翻十倍会被视为灾难。中国通过更低上市成本和更低监管摩擦，可能把设备从 100,000 美元级压到 10,000 美元级，形成美国需要警惕的竞争。

非直觉推断：医疗要像技术行业一样增长，关键未必是保险制度微调，而是把新药和新器械的上市成本压到个人可支付、可融资、可直接交易的水平。

## 自治公司先从异常处理、安全和内部工具开始
Guillermo 说 Vercel 已经有大量自治基础设施：系统发现指标异常后自动调查、判断是否创建 incident，并把修复方案递给工程师；agent 还没有直接改 prod 的权限，但已经承担大部分 SRE 调查工作。Vercel 的 deepsec 更激进：用一万个并发 agent 跑整个 monorepo，花 14,000 美元 token 在几天内找到相当于数个季度安全研究进展的问题。

Naval 描述自己的 vibe-coded app：用户在 TestFlight 里报 bug，上传日志和截图，一个 daemon 汇总 bug、分析、后台修复，并生成新的 TestFlight build 给他测试。Blake 在 Boom 做过一周公司级 AI hackathon，要求所有人用 AI 做自己认为最重要的东西；结果不是大量玩具项目，而是很多 needle-movers，连收发包裹的 receptionist 都做出了公司实际使用的自动化。

非直觉推断：自治公司不会一开始就是“无人 CEO”，而会先在异常检测、bug 修复、安全研究、内部工具和流程自动化上扩张；一线员工知道摩擦在哪里，AI 让他们第一次能把摩擦变成软件。

## 人类剩下的稀缺项是启动问题、品味、验证和真正的越界创造
Max Hodak 认为，人类未来回报会从“70% intelligence、30% agency”转向“70% agency、30% intelligence”，因为模型越来越聪明后，关键是人是否会主动打开 Claude、选择要建什么，而不是继续刷 YouTube。Naval 反驳说 agent 也会承担 agency，人类更像提出大方向的人。

关于创造力，Max 给出一个定义：艺术是 meaningful out-of-distribution behavior，即某种让你未来轨迹发生变化的惊讶行为。Naval 的定义更强调情感和意图：艺术是一个人把内在情感捕捉成对象并传递给另一个人；如果同一张图由 AI 逐像素生成，因为没有人的意图，意义会不同。Guillermo 用“Claude 网站都长得一样”说明模型会形成可识别分布，slop 会很快失去惊讶感。

结尾处 Naval 的判断最务实：AI 已经提供基础智能和领域知识，agents 开始提供 agency；剩下的是创造力、taste、足够启动和坚持的 agency，以及持续知道工具边界在哪里。Guillermo 的招聘标准也相应变化：junior 和 super-senior 都可以，但必须擅长 agent 并快速适应。

收束：这场对话真正指向的不是“AI 替代工程师”，而是“工程、监管、医疗、硬件和艺术都开始被重写成可验证的生产系统”；谁能定义系统、控制边界、承担判断，谁就拥有下一轮杠杆。
