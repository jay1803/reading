### 核心主张：Linear A 属于原始希伯来语的闪语支，一名业余语言学家五个月内完成初步破译

Tom Di Mino（自学成才的 AI 工程师兼业余语言学家）声称已破译线形文字 A（Linear A）——这一迈诺斯青铜时代书写系统困扰学界逾百年。研究目前由罗格斯大学和剑桥大学语言学家评审中。

### 关键突破

De Mino 从五处圣所的祈祷文公式入手：公式各行中除第一个词外全部已知，第一个词是同一动词词根在不同地区的变体。该词根包含 5 个已知的 Linear B 音节 + 一个 Linear A 专有符号"*301"。他将 *301 标定为"na"，还原词根"nawaya"，对应希伯来语、阿卡德语和其他闪语的 N-W-Y 词根（意为"居住"）。这一解读将祈祷文与后期希伯来祈祷文建立了具体对应——唯一区别是对象为女神。

Cyrus Gordon 于 1957 年已提出 Linear A 闪语说，但当时无法产出实际翻译；Di Mino 的方案不仅产出了具体翻译，还声称解决了部分 Linear B 的遗留问题——这是一个强力自我验证点。

### 方法与产出

Di Mino 用 Claude Code 构建 Python 脚本套件，系统化查询并交叉比对 GORILA 和 SigLA 两个数字化 Linear A 语料库，使原本只能手工操作的假设检验规模化。成果包括：

- 40 个符号的拟音（含 13 个此前完全未知的符号）
- 5 个 Linear B 遗留未解读符号的音值
- 408 词的英文词汇表
- 9 页草稿手稿《Ya Diktu: Grammar of the Minoan Peak Sanctuary Libation Formula》

### 历史意义

Linear A 约公元前 1800 年出现，1450 年随迈诺斯文明被迈锡尼希腊人征服而消亡；迈锡尼人沿用其符号体系，稍加修改后成为 Linear B。Linear B 于 1952 年由业余语言学家兼建筑师 Michael Ventris 破译，登上《纽约时报》头版。若此次同行评审通过，将是 1952 年以来地中海青铜时代语言学最大的单一突破。
