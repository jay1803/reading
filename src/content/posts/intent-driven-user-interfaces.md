这篇文章讨论了软件界面设计中过度依赖 UI 控件和形式元素的问题，并提倡采用意图驱动的用户界面。作者认为，过多的 UI 元素导致用户难以找到和使用软件功能，而意图驱动的界面可以通过自然语言指令更有效地控制软件。

## 主题
- 😫 **UI 控件过多的问题**
越来越多的设计师在软件界面设计中倾向于使用更多的 UI 控件和形式元素。这种做法的潜在问题在于，过多的功能和 UI 导致用户最终拥有更多他们不了解且不使用的功能。

-   🖼️ **Adobe Illustrator 用户界面演变**
作者使用了 Adobe Illustrator 的用户界面演变图像，来强调“更多功能，更多 UI”的持续发展，这几乎推动了每家软件公司的发布。

-   💡 **意图驱动的用户界面**
作者提到了 Christian Cantrell 的 Photoshop 助理演示，作为意图驱动界面的一个例子。在这个系列的视频中，Christian 使用连接到 Photoshop API 的自然语言指令来执行诸如遮罩一系列照片的主题、模糊图像中的背景、创建图层等操作。所有这些都无需知道如何操作，也无需点击一堆窗口、图标、菜单和指针。
