## TL;DR
AI焦虑是零和博弈的副产品——真正的风险不是"没跟上AI"，而是你的工作本质上是"为他人制造复杂性"；那种工作正在被更大的玩家抢走，AI只是股价叙事。

## 核心主张拆解
作者（geohot）的逻辑链：社交媒体用AI FOMO攻击你 → 但AI只是长期进步指数的延续（本质是搜索与优化，有明确的CS理论上限）→ 真正被淘汰的是"制造复杂性的中间层"工作 → 但原因是大玩家把租金收割整合到自己手里，AI只是包装说法 → 出路：退出零和博弈，转向净正价值创造。

净正价值的门槛刻意设低：消耗多少就创造多少以上即可，不需要无限增长，不需要赢过所有人。

## 反驳或薄弱处
**值得质疑**：作者把"AI不会递归式飞跃"视为已知事实一笔带过，但这恰恰是当前争议最大的技术判断；如果这个前提错了，整篇文章的安慰剂力度会大打折扣。

此外，"创造价值就够了"的建议对已在结构性不利位置的人（无资本、无网络、无技能栈）缺乏操作性解释。

## 留下来的那个想法
"这篇文章的传播会远不及那些末日文章"——作者自己知道这句话，所以他写了它。焦虑比清醒更有流量，这个事实本身就是他的论点最好的证明。
