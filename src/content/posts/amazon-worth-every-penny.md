## TL;DR
AWS 本季增速加速至 20%、创近三年新高的同时，Amazon 自由现金流暴跌 69%——这份财报真正的问题不是"赚多少"，而是"资本消耗能否换来未来的垄断位置"。

## 发现
- AWS Q3 同比增速从 Q2 的 17% 加速到 20%，年化营收 $1320 亿；AWS 与 OpenAI 签下 $380 亿、七年、数十万张 NVIDIA GPU 的云算力协议，Azure 此前的优先权已被 OpenAI 放弃。
- 广告营收 +24% 至 $177 亿，超过 Google Search 与 YouTube 同期增速；Roku、Disney、Prime Video 的 CTV 整合正在扩大广告库存。
- 整体营收 $1802 亿（+13%），EPS $1.65（超预期 $0.39）；Q4 指引营收 ~$2095 亿，运营利润 $21–26 亿。
- FY25 资本支出预计达 $1250 亿，单季度 CapEx 已突破 $340 亿，同比增 78%。

## 为什么重要
自由现金流从 $484 亿跌至 $148 亿（-69%），直接原因是 CapEx 的急剧膨胀，而非主营业务恶化——OCF $1310 亿仍在增长。广告的高利润率（该板块利润率远高于 AWS 的 35%）正在弥补零售和基础设施的资本消耗，维系整体运营利润率约 11% 不跌。

## 破坏了什么常识
尽管 AWS 增速绝对值落后于 Azure（39%）和 Google Cloud（34%），但从新增绝对美元规模看，AWS 每季新增量仍是三者之首——"增速落后"和"扩张最慢"是两件事。

## 一句话
Amazon 正在用自由现金流换基础设施控制权；$1250 亿 CapEx 押注的不是当下需求，而是 Jassy 确信那个需求正在途中。
