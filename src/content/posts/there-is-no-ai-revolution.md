## TL;DR
这篇文章深入探讨了生成式人工智能（Generative AI）行业，特别是 OpenAI 公司的财务状况和商业模式。作者认为，生成式 AI 行业缺乏基本的单位经济效益、产品市场契合度和市场渗透率，OpenAI 持续亏损，并且没有明确的盈利途径。作者质疑整个行业的可持续性，并认为当前的热潮是由媒体炒作和风险投资驱动的泡沫。
### 主题
#### Generative AI 的单位经济效益问题
Generative AI 模型在每次提示和输出时都会亏损。与传统软件不同，Generative AI 的服务成本随着用户数量的增加而增加，因为它需要大量的计算资源。
- Generative AI 需要昂贵的 GPU 来进行推理和训练，这会缩短 GPU 的寿命并消耗大量能源。
- 模型需要大量训练数据，而这些数据的供应已经不足。
- 公司需要花费巨额资金来吸引和留住 AI 人才。
- 即使是付费用户也会让公司亏损。

#### OpenAI 的财务状况
OpenAI 在 2024 年花费了 90 亿美元，但收入仅为 40 亿美元，净亏损 50 亿美元。
- 收入主要来自 ChatGPT 的高级订阅，其余来自 API 销售。
- 即使是付费用户，OpenAI 也会亏损。
- OpenAI 的成本部分由 Microsoft 的 Azure 云计算积分补贴。
- OpenAI 预计 2025 年将亏损超过 144 亿美元。

#### OpenAI 的用户数量
OpenAI 声称拥有 4 亿周活跃用户，但没有明确定义“周活跃用户”的含义。
- 作者认为 OpenAI 专注于周活跃用户是为了避免计算其订阅产品的转化率。
- ChatGPT 的免费到付费用户转化率可能只有 2.583%。
- Generative AI 的实际用途有限，用户参与度可能很低。

#### OpenAI 的产品策略
OpenAI 的主要收入来源是订阅和 API 访问，但在这两种情况下都会亏损。
- OpenAI 的产品没有明显差异化，难以单独销售。
- OpenAI 难以解决 LLM 的“幻觉”问题，这使得它不适用于大多数商业客户。
- OpenAI 的新产品 Operator 和 Deep Research 成本高昂，且输出质量存疑。

#### Generative AI 行业的整体状况
除了 OpenAI 之外，其他 Generative AI 公司的用户数量很少，表明整个行业的规模很小。
- Microsoft Copilot、Google Gemini、Anthropic's Claude、Perplexity 和 DeepSeek 的用户数量远低于 ChatGPT。
- 整个 Generative AI 应用市场的规模可能还不如 Pokémon Go 在高峰时期的规模。
- API 调用量也表明 Generative AI 的实际应用有限。

#### 其他 Generative AI 公司的财务状况
- Anthropic：2024 年收入 9.18 亿美元，亏损 56 亿美元。该公司估值过高，产品缺乏差异化，且依赖风险投资。
- Perplexity：估值 90 亿美元，但用户数量少，产品同质化，且存在抄袭问题。该公司财务数据不透明，盈利能力存疑。
- Hyperscalers（Microsoft、Google）：在 Generative AI 上的巨额投资没有带来相应的回报。Copilot 和 Gemini 的用户数量很少，表明消费者对这些产品并不感兴趣。

#### Generative AI 的普遍性
AI 的普遍存在并不代表它的采用率，而是公司强行将其推入各种产品的结果。
- 企业对 AI 的整合更多是出于管理层的决策和市场需求，而不是消费者需求。
- LLM 的实际用例有限，无法证明其巨大的财务和环境成本。

#### 关于“Agents”和 Artificial General Intelligence
- “Agent”一词被有意用来误导，因为它暗示 AI 具有自主性，而实际上只是连接到数据库的聊天机器人。
- Generative AI 是概率性的，LLM 并不“知道”任何事情，它们只是概率机器。
- 我们不了解人类智能的工作原理，因此模拟它是可笑的。

### 总结
Generative AI 行业，特别是 OpenAI，是一个由媒体炒作和风险投资驱动的泡沫，缺乏可持续的商业模式和实际应用价值。该行业持续亏损，没有明确的盈利途径，并且对环境和社会造成了负面影响。
