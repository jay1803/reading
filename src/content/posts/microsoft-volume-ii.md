## 嘉宾背景

Ben Gilbert 与 David Rosenthal，Acquired 播客联合创始主持人，专注于科技公司历史与商业策略的深度研究。本集是 Microsoft 系列第二部，聚焦 1995—2014 年。两人采访了超过 20 位亲历者，包括 Steve Ballmer、Ray Ozzie、Steven Sinofsky、Brad Smith 等。

## TL;DR

微软 1995—2014 的"失去的二十年"是一个彻底被误读的时代：消费端的失败是真实的，但与此同时，微软在企业软件领域三倍化了营收，并奠定了 Azure 的全部技术基础——Steve Ballmer 手里种下的树，Satya Nadella 摘了果。真正要命的不是那些失败，而是微软从未讲好自己的故事。

## 反垄断案的真实代价是文化，不是法律

DOJ 案的判决要求微软分拆为两家公司（2000 年 6 月），这在法律上从未执行，但在心理上摧毁了公司文化。15 个月的"即将被拆分"预期，让内部精英阶层开始相信公司没有未来，随之带来零和博弈的政治文化（stack ranking + 内部各部门相互"对准枪口"的卡通式组织图）。Bill Gates 的公开形象从天才变成傲慢的 CEO，仅一段庭审视频就重塑了外界对整个公司的判断。Steve Ballmer 在这段最黑暗的时期充当了情感支柱，到处大喊"I love this company"的疯狂舞台表演，是在分拆判决最恐慌期（2000 年 9 月）释放的。

## 企业软件飞轮是微软真正建立护城河的地方

Steve Ballmer 任内打造的 SQL Server + Exchange + Active Directory + SharePoint 三边飞轮，是他最被低估的遗产。Active Directory 成为企业身份的单一真相来源，一旦采用就几乎触发完整微软生态的级联采购。企业协议（Enterprise Agreement）将一次性软件销售转化为三年期订阅年金，2007 年 EA 占微软总营收 55%，OEM Windows 占 30%，其余所有消费端产品合计仅占 15%。这场飞轮建立的同时，IT 部门成为第一用户而非终端用户，微软失去了对消费端产品质量的感知——这正是后来 iPhone 出现后企业防线失守的根源。

## Vista 是微软历史上最昂贵的人才黑洞

Longhorn/Vista 开发周期（2001—2006）让微软最优秀的系统工程师离开了所有真正重要的战场。三大技术支柱（WinFS 对象文件系统、Avalon GPU 渲染引擎、Indigo 网络框架）全部无法集成为可编译的操作系统，四年后从旧版 Windows Server 重新 fork 才勉强出货。直接伤亡之一：Brian Valentine 离开 Exchange 去救 Vista，两年后转投亚马逊，领导 amazon.com 的工程基础设施。正是这批从微软流出的系统工程师，构建了 AWS 的早期技术底座。

## Google Android 让微软的商业模式在移动端结构性失效

微软在移动端失败的根本不是产品，而是 Google 用"低于免费"（less than free）的策略封死了操作系统授权的商业逻辑：Android 开源免费，Google 还补贴 OEM 的销售激励，同时将 Google 服务（含 Play Store）作为配套捆绑。微软向 OEM 收取几美元授权费的模式在低利润硬件行业毫无竞争力。二者的商业逻辑根本不在同一平面：Google 赚的是搜索广告的全球份额，消灭微软的手机业务对 Google 而言几乎是零成本副产品。

## Azure 的真实父母是 Steve Ballmer 和 Ray Ozzie，不是 Satya

2006 年，Ray Ozzie 在 Ballmer 授权下，将 Azure（代号 Red Dog）作为秘密孵化项目在现有事业部之外独立运作，亲自招募 Dave Cutler 从零构建 hypervisor。Azure 的技术 DNA 来自四条并行的经验线：Bing 的大规模分布式系统、Xbox Live 的 40 万人实时在线服务、Hotmail 的亿级 web 应用运维、Windows Server 的企业 OS 积累。Satya Nadella 此后被 Ballmer 从 Bing 调来领导 Server & Tools，完成 Azure 从 PaaS 到全栈云的转型，并在 2013 年将 Azure 从孵化项目并回事业部。公共叙事中，Azure 是"Satya 来了才有的"——这是微软讲故事能力失败的最具体例证。

## 留下的那个想法

微软在这 20 年里有 21 年处于联邦反垄断调查或诉讼中（1990—2011），却在这段时间把营收从 230 亿做到了 840 亿。真正拖垮股价的不是失败，而是无法让市场相信这些数字是真实的护城河。当一家公司把故事讲烂了，哪怕财务报表无可挑剔，市场也会按"终将失去一切"来定价它。
