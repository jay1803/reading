## TL;DR
Azure 38% 增速不是天花板，是微软主动降速的结果——Nadella 明确说，如果把 Q1/Q2 上线的 GPU 全给外部 Azure 客户，增速会超 40%；他们在用算力稀缺性做容量套利，把高 LTV 的 Copilot 内部产品优先于外部用户。

## 发现
- Q2 FY26：营收 $813 亿（+17% YoY），智能云 $329 亿（+29%），Azure 不变汇率 +38%；智能云毛利率跌 4pp 至 59%，自由现金流同比下降 9%（运营现金流反而大涨 60%，差距来自 CapEx）。
- Copilot 势头：1500 万付费席位（+160% YoY），每用户对话量翻倍——使用强度数据直接反驳了"没人用 Copilot"的市场叙事。
- 商业 RPO 飙升 110% 至 $6250 亿，但 45%（$2810 亿）来自单一 OpenAI 合同，非 OpenAI 部分仍以 28% 增速扩张。
- CapEx $375 亿（+66% YoY），约 2/3 用于 AI 芯片；自研 Maia 200（台积电 3nm、1400 亿晶体管）TCO 较现有机队提升 30%，推理性能 3× 超 Amazon Trainium。
- 2026 年 7 月 M365 部分档位提价最高 33%。

## 为什么重要
微软把自己定位成 AI 时代的 TSMC：Azure Foundry 去掉"Azure"前缀，托管超 11,000 个模型，包括 Claude 4.5、Mistral 等直接竞品——无论谁赢模型战，微软都赢基础设施税。Maia 200 是垂直整合的关键一步：把推理负载从高价第三方 GPU 迁移到自研芯片，直接保护毛利率。$2810 亿 OpenAI backlog 表面是集中度风险，实质是 2032 年前的收入地板。

## 破坏了什么常识
市场把 Azure 增速放缓解读为需求或竞争力信号；实际上管理层在主动做 LTV 组合优化——故意给外部 Azure 客户限速，把稀缺算力留给内部 Copilot 和 GitHub 等高价值产品。这不是供给不足，是主动选择。

## 收束行
真正需要盯的指标不是 Azure 增速，而是 2026 年 7 月 M365 涨价后的续约率：运营现金流大增、FCF 下降 9%，整个估值逻辑建立在"Copilot 粘性足以消化 33% 提价"这一假设上——那是第一个真实检验点。
