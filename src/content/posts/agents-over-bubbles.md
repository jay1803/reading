## TL;DR
Agent 不只是"更多算力需求"的触发器——它同时降低了需要"大规模普及"的门槛：少数有主动性的人通过掌控多个 agent，即可释放足以颠覆行业的算力消耗与经济价值，泡沫论预设的"需要亿级用户"的前提根本不成立。

## 核心主张拆解
**三次 LLM 拐点逐步瓦解了原始 ChatGPT 的两大缺陷**（幻觉、需要用户主动管理）：o1 让模型内部自我验证，Opus 4.5 + Claude Code 让 agent 在外部验证执行结果——人类彻底退出循环。每一次拐点都是推理算力的指数级跃升，也是使用量的指数级跃升；资本支出因此有了实际需求背书，而非投机。

**商品化论的致命漏洞**：agent 运行需要模型与 harness（控制软件）深度集成，而非模块化互换。Anthropic/OpenAI 真正卖的是这套集成，不是裸模型——利润流向整合点，而非可替换的模块。微软被迫在 Copilot Cowork 上绑定 Anthropic、放弃"模型无关"立场，就是活证。推论：Dediu 的"苹果外包 Gemini = 天才"论也可能因此崩盘——如果 agent 要求深度集成，靠自建 Siri harness + 外包模型的策略能否跑赢，极不确定。

**企业端才是真正的支付意愿来源**：消费者付订阅费的意愿有限，广告模型也未必够养活 LLM 成本；企业则愿意为员工生产力付费。更深一层：agent 让"裁员"从成本优化变成了"用更小团队重建规模"的必要路径，倒逼企业裁更多人再用 agent 重建，算力需求因此形成正反馈。

## 反驳或薄弱处
**最大的自我悖论**：Thompson 开头说"当没人担心泡沫时才是真泡沫"，结尾却宣布"这不是泡沫"——他自己也承认这可能正是泡沫信号。这段自我戳穿只是显得聪明，并没有真正化解悖论，读者不应把它当成论据。

**商业化时间线全然缺席**：目前能被 agent 可靠处理的任务仍以可验证的代码任务为主；扩展到非结构化的企业工作流需要多久、会踩哪些新坑，文章完全回避。

## 边缘观察
Microsoft 放弃"模型无关"是本文最具诊断价值的信号——不是 Nvidia 的 GTC，不是超规模 capex，而是这家最早拿到 OpenAI 股权的公司悄悄承认：光靠分发不够，必须捆绑 harness 才能卖出去。这比任何宣言都更能说明模型不是商品。
