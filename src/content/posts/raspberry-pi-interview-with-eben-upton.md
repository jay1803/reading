## 嘉宾背景
Eben Upton 是 Raspberry Pi 的创始人：2004 年在剑桥担任计算机科学 director of studies 时，发现计算机专业申请人数下滑，于是在 2008 年成立 Raspberry Pi Foundation，2012 年推出第一代 Raspberry Pi。Raspberry Pi 后来成为仅次于 PC 和 Mac 的第三大计算平台，2024 年 IPO；公司既服务教育使命，也是一家以工业嵌入式应用为主的商业公司。采访者是 Colossus 的 Terran Mott。

## TL;DR
Raspberry Pi 最不显眼、但最强的飞轮，不是“便宜开发板”，而是把低门槛学习、真实工业用途、本土制造反馈和足够便宜的算力连成一条闭环：孩子用它入门，工程师把它带进工作场景，工业收入再反哺教育和下一代硬件。它的战略不是追逐最前沿，而是把“足够强、足够开放、足够便宜”的通用计算持续放到更多人手里。

## 真正有力量的教育工具，是底端接近地面、顶端接到产业
Upton 把 Raspberry Pi 类比为 Python：第一步可以是 hello world，但顶端连接真实工程系统。教育端的短循环是爱好者和工程师把 Pi 带进公司，长循环是学生毕业后把 Pi 当作“计算机的默认形态”。这解释了为什么一个教育品牌会有 80% 收入来自工业应用：它先塑造使用者，再被使用者带入产业。

非直觉处在于，使命和资本主义在这里不是互斥的。Upton 明说公司需要投资回报来继续做工程，而教育基金会作为股东受益；商业化反而让教育使命获得更稳定的资金来源。

## 通用计算的意义，是给不可预设的创造留出口
Upton 反复强调“电脑而不是游戏机”：封闭平台只能允许平台设计者预想过的创造，通用计算则允许人为了自己的问题越界。无论是有人在计算器、Nintendo DS 上硬写程序，还是 Raspberry Pi 被拿去做比特币矿机、无人机、机场屏幕和空间站项目，核心都是同一件事：开放平台会吸引不可预测的用途。

这也影响他对儿童 AI 编程工具的判断。他认可 Claude Code 一类工具对成年人有效，但认为孩子如果没有编程底层理解，AI 代码生成会误导和打击自信；更好的路径是先学会常规编程，再成为更强的 AI 工具使用者。AI 对儿童创作最安全的边缘价值，可能先在游戏素材、图像和音乐生成上出现。

## Raspberry Pi 押注的不是 frontier，而是便宜到能普及的 Technology B
Upton 用 Christensen 的 Technology A/B 框架解释 Raspberry Pi：前沿技术会持续向上、超过多数人的真实需求，而“足够好但极便宜”的替代技术会吃掉大量实际场景。Pi 5 相比 Pi 4 的跃迁已经让很多用户感到“这就是真电脑”；但他更愿意训练自己追求“同样性能、价格减半”，而不是“同样价格、性能翻倍”。

这也延伸到 AI。Upton 预期未来五年硬件性能继续上升、模型继续下沉，也许能把今天 Sonnet 级别的能力放进口袋。重点不是每个人都拥有 frontier model，而是 99% 性能、1% 成本的模型被接入真实问题，经济价值来自第二波工程化应用。

## 制造业回流靠的不是怀旧就业叙事，而是工程反馈系统
Raspberry Pi 起初在中国生产，但在 2012 年发布当天被 Sony Wales 接触，随后把制造迁回威尔士。Upton 对 reshoring 的判断很清醒：它不会恢复 1950 年代式的大规模中产制造岗位；要在高工资地区制造，核心是自动化、流程设计和持续改良。

真正的优势来自距离：英国工程师更愿意去工厂问“你最讨厌生产 Raspberry Pi 的哪一部分？”十多年里，产品为可制造性做出的无数小改动，累积成价格和性能优势。甚至曾被视为自动化象征的 cobot，也因为 USB 连接器等部件被重新设计到可由 pick-and-place 机器处理，而逐渐失去核心地位。制造优势不是一次性搬厂，而是工程、工艺和组织学习的长期复利。

## “爱好者公司”的误读，反而说明品牌资产过强
IPO 后外界常把 Raspberry Pi 描述成 hobbyist company，但 Upton 说这会一直解释到生命尽头：教育品牌太成功，以至于遮住了工业事实。公司 20% 是教育相关，主收入却来自工业场景——比如 Heathrow 机场显示屏、Schindler 电梯、POS 终端、电站监测等。

这是一种高质量问题：大多数公司没人听过；Raspberry Pi 的问题是人们听过，但误解了规模和用途。Liz Upton 早期建立的社区化营销，让这个专业产品获得了异常强的社会认知，而工业业务则把认知转化成真实部署。

## 收束
这篇访谈最锋利的地方是：未来很多 AI 与硬件创新，不一定从最昂贵的 frontier 入口扩散，而可能从“工程师随手就能拿起、孩子也买得起、工厂也敢批量用”的底层载体扩散。Raspberry Pi 的护城河不是某一块板子，而是它已经成为很多人想象“可编程世界”时默认伸手去拿的东西。
