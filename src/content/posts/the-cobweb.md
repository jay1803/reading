互联网看似拥有永久记忆，实际建立在持续覆盖、漂移和删除之上；若没有主动存档，公共事件的证据、学术论证的依据乃至一个时代的历史，都可能在几小时内消失。2014年7月17日，Malaysia Airlines Flight 17在乌克兰 Donetsk 附近坠毁，机上298人全部遇难。分离主义武装领导人 Igor Girkin 随后在 VKontakte 宣称“我们刚击落了一架飞机，一架 AN-26”，并附上实际看来属于 Boeing 777 的残骸视频。Stanford Hoover Institution 馆员 Anatol Shmelev 两周前已把 Girkin 的页面列入 Internet Archive 的 Ukraine Conflict 收藏，要求每天抓取两次；Wayback Machine 因而在下午3点22分保存了这条消息。帖子不到两小时便被删除，这份存档遂成为原始声明仅存的实质证据，并被用来支持美国驻联合国大使 Samantha Power 关于分离主义者曾在社交媒体炫耀击落飞机的陈述。

这种迅速消失并非特例：网页的平均寿命约为一百天，企业改组、平台关闭、主动清理和技术覆盖都会抹去内容。MySpace、GeoCities 和 Friendster 的变迁带走了数百万账户；英国 Conservative Party 曾删除十年的演讲记录，其中包括 David Cameron 赞扬 Google 让公众得以监督权力的讲话；BuzzFeed 清除了四千多篇早期文章。网页更新还会把旧版本无声覆盖，链接迁移则产生 **content drift**：URL 仍能打开，访问者却无法察觉页面已换成别的内容。与明显报错的 **link rot** 合在一起，这种 **reference rot** 使网络上的证据失去可验证的稳定位置。

法律与学术领域已经付出具体代价。2013年的调查发现，法律和政策出版物引用的 URL 在六年后接近一半失效；Harvard Law School 2014年的研究显示，Harvard Law Review 等期刊中超过70%的链接、美国最高法院判决中约50%的链接，已无法指向原先引用的信息。Los Alamos National Laboratory 对1997至2012年间三百五十万篇科学、技术和医学论文的研究则发现，五分之一的注释链接遭遇 reference rot。脚注历经数百年才形成“我如何知道、证据在哪里”的知识规范，网络链接却在短短几年里把它削弱成“我曾在这里找到证据，但它现在可能已经不在”。

Internet Archive 创办人 Brewster Kahle 从1996年起试图为这个失忆系统补上一座公共图书馆。他把目标概括为建立“Library of Alexandria Two”，口号是“Universal Access to All Knowledge”，并在旧金山买下一座外形与机构希腊神庙标志相似的教堂作为总部。这个计划延续了互联网先驱早年的图书馆理想：J. C. R. Licklider 在1960年代设想由计算机连接全部知识，随后推动 ARPA 机器联网；ARPAnet、packet-switching 和“network of networks”由此发展。Kahle 在 M.I.T. 师从 Marvin Minsky，后来开发带有版本控制和时间轴的 WAIS。Tim Berners-Lee 设计 World Wide Web 时也考虑过时间维度，但为了让 HTTP 尽可能简单、优先呈现最新信息，没有把保存历史纳入基础协议。Berners-Lee 后来承认，当时首要任务是让 Web 运转起来；Vint Cerf 则担忧二十一世纪会成为“informational black hole”。

Wayback Machine 正是在 Web 于1990年代商业化并开始消失时着手收集它。它的机器人尝试约每两个月复制一次所发现的网页，重要站点抓取更频繁，例如 newyorker.com 自1998年首次存档后已被抓取近七千次，后来达到每天约六次。约一千名馆员和档案人员通过 Archive-It 建立专题收藏，普通用户也能用“Save Page Now”即时保存页面；MH17 坠毁当天 Girkin 页面留下的十二份截图中，七份来自机器人，其余由人手动保存。到文章写作时，Wayback Machine 已存下超过四千三百亿个网页，数据量从2012年的十 petabytes 翻倍至约二十 petabytes；每天约六十万人使用它，每秒发起两千次查询。

这项规模近乎基础设施的事业却缺乏与其公共价值相称的法律保障。Library of Congress 抓取网页通常要通知或取得站主许可，因此只有九十亿页，并把实际爬取工作外包给 Internet Archive；British Library 有六十亿页，许多国家图书馆也使用 Internet Archive 开源的 Heritrix，并依靠其早期抓取补齐本国域名历史。Internet Archive 采取 opt-out 原则，尽量抓取所有可访问网页，但会服从 robots.txt，甚至曾在发现该文件后移除网站的历史版本；Conservative Party 因此一度让已删除演讲从 Wayback Machine 一并消失。英国2013年把本国 Web 纳入 legal deposit，British Library 依法保存这些内容，无须接受停止收集的要求；法国 Bibliothèque Nationale de France 同样可以广泛抓取，但出于版权与隐私妥协，只允许研究者在馆内使用。结果是 BnF 的网络档案每月只有几十名研究者访问，Wayback Machine 每天却有数十万用户。

各国法律、隐私制度和文化主权观念，也使统一的全球网络档案难以成立。Kahle 2002年提出由 Internet Archive 联合国家图书馆组成全球联盟，国家机构却不愿把文化遗产保存这一根本职责托付给一家位于 Silicon Valley 的美国非营利组织；最终形成的是2003年创立、拥有四十九个成员机构的 International Internet Preservation Consortium。分散保存仍能在危机中发挥作用：2015年 Charlie Hebdo 遇袭后，法国档案人员立即向全球同行征集相关 URL 和信息流，因为他们知道当时铺满媒体的材料很快会消失。馆员 Gildas Illien 将这项工作概括得极其直接：“我们的工作就是记忆。”

Kahle 的公共图书馆理想也与企业控制的数字入口形成冲突。他反对 Google Books 版权诉讼中的和解方案，认为 Google 企图把公共图书馆体系事实私有化；他随后参与创建 Digital Public Library of America，以便把图书馆、档案馆和博物馆资源免费开放。Kahle 所说的“我们正在建造一座由我们构成、也属于我们的图书馆”，点出了 Internet Archive 的政治含义：一旦社会的知识只能通过企业门户访问，企业的存续、商业决策和审查规则便会决定公共记忆的边界。

然而，保存下来的 Web 仍远未成为真正可研究的档案。Wayback Machine 只能按 URL 和日期查找，缺少全面索引、目录和相关性排序，庞大的材料更像电话簿。抓取页面不同组件的时间可能不一致：2012年访问一份2008年的 CNN 存档，会看到 McCain—Obama 竞选报道旁出现 Romney—Obama 辩论广告。数字档案也缺少传统档案那种完整 provenance；Kahle 只能证明系统从某个表面上的网站和 IP 地址接收了什么，无法在本体意义上保证事件确曾发生。尽管如此，Wayback Machine 截图已多次被法庭接受，实际可信度仍高于许多司法裁判依赖的材料。

研究工具的落后进一步限制了档案价值。British Library 邀请历史学者测试 U.K. Web Archive 时，研究 Royal National Institute for the Blind 的 Gareth Millward 发现，一款获该机构背书的语音手表广告在数据库中重复数千次，几乎堵塞所有检索。Internet Archive 清理、压缩 .gov 域名数据并开放给学者后，也因工具难用和缺乏研究者而成效有限。Stanford 档案员 Nicholas Taylor 将困境称为鸡生蛋问题：没有研究就不知道该开发什么工具，工具尚未开发又使研究无法展开。大量保存只解决了材料是否存在，尚未解决如何从中辨别、关联和解释历史。

已有项目开始修补 Web 缺失的时间维度。Harvard Library Innovation Lab 推出的 Perma.cc 允许作者在引用网页时同步创建永久副本，已获六十多所法学院图书馆以及法院、法律评论等机构采用，有望成为法律和科学引文标准。Los Alamos 的 Herbert Van de Sompel 与 Michael Nelson 开发 Memento 协议，让用户指定希望访问的时间，并在全球主要公共网络档案中寻找最接近该时点的页面；它强调冗余，因为把全世界的数字记忆交给单一档案本身就是风险。若 Memento 及其 Time Travel 门户成功，Web 将获得当初 HTTP 放弃的第四维度，人们可以沿链接回到页面被引用时的状态，同时也要面对过去变得难以逃离的隐私后果。

Internet Archive 教堂里的服务器把这种抽象使命变成了可触摸的物质存在：机架中的蓝灯每闪一次，就代表有人上传或读取一份材料。MH17 坠毁当天，有人在 Girkin 删除声明前按下“Save Page Now”，让一条两小时寿命的帖子进入历史记录。**网络档案保存的从来不只是网页，而是公共事实能够被追溯、权力能够被追责、未来能够理解当下的证据条件；当社会生活全面数字化，维护记忆本身便成为一种公共权力。**
