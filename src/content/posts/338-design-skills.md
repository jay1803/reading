## TL;DR
AI 设计类 skills 已严重同质化：作者深度使用后的结论是，大多数 design skills 大同小异，一个项目全跑不仅浪费 token 还互相冲突——覆盖率没意义，筛选力才是稀缺资源。

## 本期精选

**工具层**：
- Grainrad：浏览器内将图片/视频/GIF/3D（GLB）实时转为 ASCII、半调、像素排序等 15+ 风格化效果，可导出 PNG/SVG/MP4。
- OpenUI：生成式 UI 的开源标准工具包，~defineComponent~ 注册组件库后，LLM 在对话中直接返回结构化 UI 而非纯文本，兼容 ShadCN/Material，支持 OpenAI/Anthropic/Gemini。

**本周最佳**：
- mem_brane：通过自指循环、环境语音吸收和透明 LED 结构，把 AI 心智可视化成可感知的空间装置——作者明确说这不是 vibe code 能做出来的，要点开视频才算看到。

**两篇值得单读**：
- /Details That Make Interfaces Feel Better/：文本换行、圆角关系、动效可打断性、数字等宽、阴影与图像描边——提升界面质感的细节层面汇总。
- /Reverse-engineering Claude's generative UI/：拆解 Claude 生成式 UI 工具调用与流式渲染机制，并演示如何移植到 Pi Agent。

**招聘**：原石墨文档创始人的 AI 新项目招前端交互设计师，强调"情绪化设计 / 非线性交互"，关注 Character.AI / Replika / Pi 等。

## 这期留下的想法
同质化同时发生在两端：市面上的 AI design skills，和这份 newsletter 里铺满的新工具（大量功能重叠）。作者对两件事的态度一致：品位和筛选力比覆盖率重要。
