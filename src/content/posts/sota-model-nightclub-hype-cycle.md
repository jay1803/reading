## TL;DR
AI 代码工具的竞争正在从 SOTA 模型崇拜转向 agentic workflow 入口战：Anthropic 先用 Claude Code 把 CLI 编程变成收入引擎和内部生产力飞轮，OpenAI 则靠 GPT-5.5、Codex 增长、ChatGPT/企业分发重新抢回开发者入口。

## 核心主张拆解
- Claude Code 是 Anthropic 的“ChatGPT 时刻”：它把 AI 编程重新定义为命令行里的 agentic coding，并在 2026 年 2 月达到 25 亿美元年化收入，其中 50% 来自企业。
- 这个收入规模已经超过 Cursor 的 20 亿美元年化收入和 OpenAI Codex 2026 年 1 月的 10 亿美元年化收入；Claude Code 还被估算贡献了全球公开与私有 GitHub commit 的约 7%，约每天 100 万次。
- Anthropic 的产品追赶来自自用飞轮：它利用 Claude Code 提升内部 shipping 速度，随后推出 Claude for Excel、Claude for PowerPoint、Claude Cowork，把代码 agent 的交互范式迁移到知识工作。
- OpenAI 的反击路径是模型领先 + 分发优势：GPT-5.5 重新拿下顶级 coding benchmark 与开发者动能，Codex 周活从 3 月约 100 万增长到 4 月 400 万。
- Codex 4 月更新加入 Computer Use、图像生成、桌面控制、web preview，使其从 coding assistant 扩展成白领知识工作 agent interface。

## 为什么重要
- 竞争焦点不再只是模型榜单，而是“谁拥有默认工作界面”：Claude Code/Cowork 押注 CLI 与专业 workflow，OpenAI 押注 ChatGPT、企业账户、GSI 渠道、AWS Bedrock 与既有 enterprise distribution。
- Anthropic 的领先样板来自高强度开发者场景；OpenAI 的领先样板来自把 agent 能力打包进更广泛的 ChatGPT 与企业交付体系。
- 如果文章判断成立，AI coding 工具会成为通用知识工作 agent 的试验场：代码场景先验证 agentic loop、权限、上下文管理和付费意愿，再外溢到金融、法律、合同审查、办公软件和代码审查。

## 关键数据
- Claude Code：2026 年 2 月 25 亿美元年化收入，较 2025 年底 12.5 亿美元翻倍；企业收入占 50%。
- Cursor：20 亿美元年化收入，较 2025 年 10 亿美元翻倍。
- OpenAI Codex：2026 年 1 月约 10 亿美元收入；周活从 3 月约 100 万增至 4 月 400 万。
- Claude Code 影响：约占全球公开与私有 GitHub commit 的 7%，约每天 100 万次。

## 值得质疑
- 文中大量关键数字来自 Sacra 估算，尤其是 Claude Code 收入、GitHub commit 占比、Codex 收入与周活，需要视为方向性信号，不应当作审计口径。
- “SOTA 模型 → 产品动能 → 企业收入”的因果链条可能被压缩了；真实壁垒还取决于留存、权限治理、企业安全、上下文质量、集成深度和单位经济性。
- OpenAI 的分发优势很强，但如果高频专业 workflow 的体验不够深，ChatGPT bundling 未必能自动替代 Claude Code 在开发者心智里的位置。

## 最后判断
这篇的核心价值是提醒：AI agent 战场的领先指标，可能已经从聊天产品 DAU 和模型 benchmark，迁移到“谁能把高价值工作流变成默认执行环境”。
