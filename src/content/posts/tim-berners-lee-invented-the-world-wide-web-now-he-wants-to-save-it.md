Tim Berners-Lee 试图用赋予用户数据控制权的开放协议，挽救自己创造、如今被平台垄断与 AI 侵蚀的 World Wide Web；但新方案的采用困境暴露出，技术上的开放已经难以自行扭转商业权力的集中。1989 年发明 Web 后，他放弃申请专利，把此后数十年投入维护通用标准与平等接入。如今，他通过 Solid Protocol、公司 Inrupt 和个人 AI 助手 Charlie 再次推动变革，面对的却是比当年封闭网络服务更牢固的平台体系。

Web 最初解决的是异构信息无法相互连接的问题。Berners-Lee 在 CERN 工作时，科学家把资料分散存放在不同语言、操作系统和介质里，连加速器操作与传感器校准的信息都可能藏在私人目录或锁柜中的软盘上。互联网已经能够传送数据包，电子邮件、文件传输和论坛也已存在，但缺少统一的信息空间。他把互联网与通过链接组织文档的 hypertext 结合起来，在 1990 年开始建立 HTML、HTTP 和 URL，1991 年 8 月 6 日上线第一个网页。其突破在于让文档摆脱固定目录和系统边界，任何人都能发布，任何页面都能链接其他页面。

免费、简单与可自由扩展，使 Web 超越了同期的 WAIS 和 Gopher；Gopher 尝试收取许可费时，用户便转向其他选择。然而，开放也让浏览器厂商能够各自扩展标准，威胁整个网络的兼容性。Marc Andreessen 推动图片标签、推出 Mosaic，随后凭 Netscape 获得巨额财富，Berners-Lee 则担心自己的创造被厂商接管。为避免 Web 分裂成互不兼容的技术领地，他于 1994 年成立 W3C，让企业通过共识制定标准，并逐步接受不就 Web 技术相互提起专利诉讼的安排。企业合作的动力是共同扩大市场；W3C 在 Microsoft 与 Netscape 的浏览器大战中维持兼容性，以 **principle of least power** 坚持最小化的基础架构，为后来难以预见的用途留下空间。

这套治理机制维护了 Web 的统一，却无法保证它沿着发明者的全部设想发展。Berners-Lee 希望人人既能阅读又能写作，最终占主导的浏览器却把多数用户置于被动消费的位置；他也后悔把地址体系绑定到 DNS，使域名成为投机资产。到 1990 年代末，他把下一阶段寄托于 **Semantic Web**：让网页背后的事实、数据库与来源以机器可读的结构相互连接，形成“Giant Global Graph”，使智能代理能够跨来源推理、安排就医等事务。他在 2009 年的 TED 演讲中反复呼吁“Raw data now”，要求政府、企业与个人释放原始数据，而不必等到建成漂亮的网站。

Semantic Web 遇到的阻力来自开发者与用户需求的转向。Berners-Lee 希望以 XHTML 更严格地区分信息与呈现，浏览器开发者则急于改进 HTML、构建交互式应用。2004 年，一批开发者在 W3C 表决失利后另建标准组织，最终由 HTML5 胜出，Berners-Lee 接受和解。Web 2.0 因而发展出 Twitter 的无限滚动和 Google Maps 的流畅交互；Semantic Web 则主要留在科研数据等特定领域，DBPedia 的数十亿条事实也曾帮助 IBM Watson 赢得“Jeopardy!”。他期待的、依靠公众自愿共享可信结构化数据进行推理的智能网络始终没有普及。后来兴起的 AI 大量依赖平台私下收集与整网抓取的数据，通过统计推断生成答案，与那条技术路线分道扬镳。

平台权力的形成进一步改变了开放网络的经济结构。2012 年伦敦奥运会开幕式上，Berners-Lee 打出“THIS IS FOR EVERYONE”，当时社交媒体仍被广泛视为促进民主与公共参与的力量；Tim Wu 却把 2012 至 2013 年视为平台控制开始稳固的转折期。平台先降低交易和交流成本，以网络效应成为商家与用户无法绕开的入口，再提高抽成、增加广告、攫取数据，同时抬高退出成本。2007 至 2018 年，Facebook、Microsoft、Google 和 Amazon 合计收购了一千多家公司。曾经能够绕过传统巨头的小企业与创作者，逐渐依赖另一批中介。Aaron Swartz 因批量下载 JSTOR 论文遭重罪起诉、于 2013 年自杀，也让公共知识被私人机构封锁的问题变得格外尖锐。

对封闭生态的恐惧，还迫使 Berners-Lee 作出损害开放原则的妥协。2012 年，Netflix 等 W3C 成员提出让浏览器支持 DRM，使用户能播放视频，却无法直接取得底层文件。Berners-Lee 担心拒绝这一要求会把流媒体公司赶进更封闭的专有应用，因此允许提案推进。代表 Electronic Frontier Foundation 的 Cory Doctorow 则警告，DRM 会妨碍无障碍使用与安全研究，使浏览器依赖 Microsoft、Google 的加密模块，还可能让绕过限制的用户面临刑事责任。争执持续数年，Berners-Lee 最终动用主任权力批准 DRM，理由直白到“人们喜欢看 Netflix”。这一决定显示了 W3C 的权力边界：为了把大型服务留在 Web 内部，它接受了限制用户控制权的技术。

**Solid** 试图从数据与服务的关系入手，降低平台的锁定能力。它在 2015 年从 MIT 的研究项目中诞生，让用户把信息存进个人在线数据存储空间 Solid Pods，由应用申请访问权限。搜索记录、购买记录或社交内容不再只能留在生成它们的平台内，用户可以更换服务、重新组合不同来源的数据，平台甚至可能需要付费获取访问权。这也有望降低新应用的竞争门槛。为了推动采用，Berners-Lee 于 2017 年共同创办 Inrupt，向企业销售实现 Solid 的服务器；协议本身保持开放，其他公司同样可以提供实现。到 2018 年底，公司已有二十名员工，据报道获得两千万美元风险投资，Cambridge Analytica 丑闻又强化了公众对个人数据失控的担忧。

早期合作没有转化为广泛使用。英国 National Health Service 试验用 Solid 改善患者对病历的控制；BBC 制作了无需保留用户数据就能推荐节目的“BBC Box”，但产品始终停留在测试阶段。Belgium 的 Flanders 承诺向每位居民提供一个 Pod，在接近七百万人口中，活跃用户却只有约一千人，已有用途包括向雇主发送数字文凭。BBC 项目负责人指出，人们希望控制数据，却不愿因此承担更多操作。Solid 标准共同作者、Inrupt 首位员工 Kjetil Kjernsmo 原本期待公司为数百名感兴趣的开发者提供工具，实际重点却落在企业服务器销售上；他自己也没有用 Solid 做过严肃的日常事务。**数据主权** 尚未产生足以让多数人改变习惯的具体收益。

Inrupt 如今把这个突破口押在 Charlie 身上：一个读取个人数据、为用户提供定制服务的 AI 助手。Visa 等公司预期购物会越来越多地交给 AI 代理，Berners-Lee 关心的是代理究竟为谁服务；若它服从平台利益，就可能比推荐算法更深入地操纵消费。Charlie 的演示用虚构用户 Zoe 的数据展示差别：直接询问 Claude 秋季度假建议，得到 Kyoto、Tuscany 等昂贵热门目的地；加入她居住 Seattle、喜欢自然摄影、预算受限以及拥有 Marriott 积分等信息后，建议变成附近的 Olympic National Park。原型会筛选相关个人信息，连同问题发给 Claude；公司称最终产品将兼容多种模型，并在隔离的 Trusted Execution Environment 中本地运行。修改数据文件、执行代理任务仍属后续计划，发布时间与运营方式均未确定。

Charlie 的示范证明了个人数据能够改善回答，却没有证明它能改变平台经济。Google 已推出自己的代理商务平台，Visa 对 Berners-Lee 方案的实际承诺也并不明确。与此同时，AI 正在削弱开放 Web 的内容生产基础：回答引擎抓取网站、直接向用户给出答案，却不给原站带来维持广告收入所需的访问量。Cloudflare 于当年 7 月推出阻止未经许可 AI 抓取的工具，希望迫使模型公司付费，再把收益分配给创作者；其服务覆盖约五分之一的网站，因而拥有实际施压能力。Lina Khan 指出，如果内容生产者无法获得回报，持续创作的经济激励就会消失。Doctorow 所主张的反垄断、隐私监管，以及允许第三方主动连接专有平台的 **adversarial interoperability**，则把干预直接指向企业权力和法律规则。

Berners-Lee 仍相信，Web 缺少关怀属于可以修复的“设计问题”：公众抗议可以保护 net neutrality，结构化数据可以校验 AI 幻觉，用户对隐私的需求可以推动新的架构。但这些判断尚未回答，采用有限的 Solid 和一个依托现有大模型的聊天助手，如何阻止垄断平台进一步控制信息与交易。Web 当年的成功依赖企业放弃部分专利权、工程师贡献时间，以及竞争者接受共同标准；今天，主导企业已经从用户难以离开、数据难以流动的结构中获得巨额收益。重建开放网络因此需要同时解决两个问题：让技术允许人们离开，也让掌握入口的企业无法阻止他们离开。
