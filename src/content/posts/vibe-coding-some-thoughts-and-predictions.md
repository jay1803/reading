## TL;DR
Vibe coding 是指开发者通过自然语言与 AI 交互来生成代码，而无需手动编写代码的一种新型编程方式。这种方式降低了软件开发的门槛，使得更多人可以参与到软件开发中来，并可能对软件开发的未来产生深远影响。
### 主题
#### Vibe Coding 的兴起
Vibe coding 由 Andrej Karpathy 提出，开发者通过自然语言与 LLMs 交互，例如使用 Cursor Composer 和 SuperWhisper，来生成代码，而无需手动编写。开发者可以提出简单的需求，AI 会自动完成代码编写，甚至修复错误。这种方式已经催生了许多有趣的小游戏。
#### Vibe Coding 对未来的影响
-   **代码生成民主化**：大多数代码将由时间充裕的年轻人或学生生成，而非专业软件工程师。软件开发将像社交媒体一样，受青年文化主导。
-   **从命令行界面到图形用户界面**：Vibe coding 将逐渐演变为 Vibe designing，通过图形用户界面（GUI）进行可视化设计，更符合人类的思维方式。
-   **减少对开源库的依赖**：AI 可以从头开始生成个性化代码，减少对现有开源库的依赖。代码将更像是一次性商品。
-   **设计标准的碎片化**：大量新的 Vibe coder 将带来新的设计模式，打破传统的 UX 设计标准，软件可能会变得难以辨认。
-   **软件开发的瓶颈转移**：创造力和分发/网络效应将成为新的瓶颈。
-   **自适应软件**：软件可以根据用户行为自动调整，而不仅仅是根据 Vibe coder 的指令。例如，如果用户在注册流程中遇到困难，软件可以自动简化流程。
-   **加速软件对长尾产业的渗透**：Vibe coding 使得非技术人员也能开发软件，加速软件对各行各业的渗透。
-   **软件开发团队的变化**：工程师、设计师和产品经理的比例可能会发生变化。
-   **市场营销和销售的变革**：Vibe marketing 和 Vibe selling 将出现，AI 可以自动执行营销和销售任务。
-   **Bug、漏洞和边缘情况的处理**：Vibe coding 需要解决软件开发中复杂的逻辑和边缘情况，例如优惠券使用、退款、权限管理等问题。
#### Vibe Coded Apps 的质量问题
目前 Vibe coded apps 的质量普遍较低，但 AI 代码生成技术正在快速发展，未来有望达到更高的复杂度和质量。即使输出质量较低，但由于其数量庞大、能够满足各种细分需求，并且由普通人创建，因此可能像社交媒体一样占据主导地位。

#### Vibe Coding 的工作原理
文章介绍了如何使用 Vibe coding 来构建一个简单的策略游戏。推荐使用 Replit Agent 或 Cursor 进行开发。同时，文章还介绍了 NicolasZu 如何通过数千个提示构建飞行模拟游戏的经验：
1.  使用 Grok 3 将游戏想法转化为游戏设计文档。
2.  使用 Grok 3 确定最佳技术栈。
3.  使用 Grok 3 将游戏设计文档转化为实施计划。
4.  使用 Cursor 和 .cursorrules 文件来明确技术栈。
5.  使用 Cursor 和 Sonnet 3.7 学习游戏设计文档和实施计划。
6.  使用 Sonnet 3.7 开始第一阶段的开发，并进行测试。
7.  在每个阶段之间创建新的聊天。
8.  如果测试不通过，使用提示来解决问题。
9.  如果遇到困难，可以使用 Grok 3 生成提示。
10. 如果项目代码量超过 20k，使用 Sonnet 创建 architecture.md 文件。
### 总结
Vibe coding 是一种新兴的编程方式，它通过自然语言与 AI 交互来生成代码，降低了软件开发的门槛，将对软件开发的未来产生深远影响，包括代码生成的民主化、设计标准的碎片化、软件开发团队的变化等方面。
