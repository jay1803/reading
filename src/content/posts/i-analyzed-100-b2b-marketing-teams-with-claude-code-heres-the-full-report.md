## TL;DR
这篇报告最值得记住的，不是“AI 没有杀死营销岗位”，而是 B2B 营销的稀缺性正在重定价。产品越来越容易被造出来，真正难的是分发、信任和市场教育，所以头部公司一边把研究工作交给 Claude Code 提速，一边继续为增长、产品营销、活动、生态和品牌组织投入真金白银。

## 发现
- **营销不是被压缩到边缘部门，仍然是核心编制**：样本里营销团队中位数是 13 人，占公司总 headcount 的中位数约 4%。250 人以下公司常在 5% 以上，250 人以上通常落在 2% 到 4%。作者原本以为 5% 更合理，结果现实更克制，但营销并没有塌掉。
- **GTM motion 比公司规模更解释营销配置**：自助式公司营销团队占比最高，达到 5.6%，因为缺少销售队伍后，获客和教育必须由营销补上。卖给 marketer 的公司更极端，营销人数占比中位数 8.3%，是其他公司的两倍以上。
- **CMO 仍是稀缺头衔，不是默认配置**：100 家里只有 27 家有 CMO，且几乎都出现在融资更晚阶段。59 家既没有 CMO 也没有 CRO，说明大量高速增长公司仍在没有完整 GTM C-level 架构的状态下前进。
- **招聘最强信号不是“有没有岗位”，而是“招什么岗位”**：100 家里有 87 家在招 marketing，共 507 个岗位，且所有融资超过 5 亿美元的公司都在招。增长/需求生成和产品营销仍是最大池子，但约三分之一开放岗位落在生态、活动、社区、DevRel、PR 这些“关系型渠道”上。
- **AI 已经成了 JD 默认语境，但组织形态还没完全跟上**：84% 的职位描述提到 AI，18% 提到 agent 或 agentic，OpenAI/Claude/Anthropic 等出现频率已经接近传统 SaaS 工具。但职位名称仍以 specialist 为主，离真正的“AI 时代通才营销人”还有一段距离。

## 为什么重要
- **这在重新定义营销护城河**：当做产品和做内容都更便宜后，营销的价值不再只是投放和写文案，而是构建可信分发、生态位、社群和品类叙事。活动、生态、社区岗位占比上升，就是对“信任稀缺”的直接定价。
- **对创始人和市场负责人，这是 headcount 配置而不是 buzzword 问题**：如果你的公司是自助式或 hybrid motion，却还按纯 sales-led 逻辑压缩营销编制，组织会天然失衡。反过来，如果你卖给 marketer，却不给营销足够 seat 和资源，也是在违背品类规律。
- **对内容与研究型公司，更大的启示是“研究本身可以产品化”**：作者用 Claude Code 把 100 家公司、90 多个数据点和 30 张图串成可复用的技能与 MCP server，等于把一次内容生产，升级成可重复运行的研究基础设施和分发资产。

## 破坏了什么常识
- **“AI 会先砍掉营销”这个直觉并不成立**：至少在高增长 B2B 样本里，AI 更像提升研究、分析和执行效率的杠杆，而不是让营销失业的直接替代品。真正变化的是岗位结构和能力要求。
- **“营销招聘的重心仍是纯数字渠道”也在失真**：当 inbound 走弱、outbound 过载、AI slop 泛滥，线下活动、伙伴网络、社区与 DevRel 反而重新变成高价值渠道。
- **“增长公司自然会设 CMO”并不是事实**：很多公司会先长大，再慢慢补齐营销总负责人，说明营销在组织权力结构里依然经常被低估。

## 值得质疑
- 这不是随机样本，而是偏向高增长、受资本追捧、AI 密度高的 100 家 B2B 公司，更像“头部趋势扫描”，不是全市场统计结论。
- 数据大量来自 Claude Code 抓取、网页信息和职位页，作者也承认做过人工 spot check 和图表修正，所以适合拿来做方向判断，不适合当严格基准线。
- “AI 让营销更重要”在景气期和融资宽松环境里更容易成立，若融资收缩，这个命题未必还能以同样强度成立。

## 最后
这篇文章真正展示的，是营销组织在 AI 时代的双重迁移，一边把研究生产流程软件化，一边把岗位重心推向更难被自动化替代的人际信任、品类教育与生态协同。谁既能把 intelligence 变便宜，又能把 trust 做稀缺，谁的营销团队就会继续扩张。
