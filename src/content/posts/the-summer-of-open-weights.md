开放权重模型正在跨过足以承担大多数 Agent 任务的能力门槛，前沿实验室依靠小幅性能优势收取高溢价的空间随之收窄。2025 年冬天，Opus 4.5 发布后，编程 Agent 的使用量迅速增长，用户愿意为完成任务所需的前沿能力付费；这个夏天的转折，则是以约十分之一的价格获得足够好用的智能。竞争的核心开始转向：更强一点的模型，究竟能否创造足以覆盖价差的价值。

价格变化已经显现这种压力。OpenAI 将快速、低价档的 5.6 Luna 降价 80%，旗舰 Sol 也推出为期三个月、降价 20% 的促销。Meta 的开放模型 Muse Spark 1.2 在 contributor 档上，每百万输入、输出 token 分别只收 0.10 和 0.20 美元，缓存读取更低至每百万 token 0.002 美元；这一档允许 Meta 使用用户数据训练，标准档的输入、输出价格则分别为 1.25 和 4.25 美元。这些报价把低成本推理与数据使用条款之间的交换也摆到了用户面前。

Anthropic 尚未跟进这一轮降价，其每百万输入、输出 token 收费 10 和 50 美元的最高端模型 Fable 5，已经被《Financial Times》报道为因价格过高而难以吸引用户。Anthropic 仍拥有很强的市场份额，但算力短缺限制了它回应价格战的能力：Claude Developer 账号希望永久提高每周使用限额，同时承认容量仍然紧张；公司还以每月 12.5 亿美元的价格向 SpaceX 租用 300MW 算力容量。若需求持续流向便宜模型，缺少可用算力会让它更难通过降价扩大使用量。

替代供给的增加，使这种价格压力更难逆转。OpenAI、Anthropic 和 Google 之外，Z.AI、DeepSeek、Kimi、Meta、Grok 至少五家实验室已经提供相当有竞争力的模型；如果 Meta 如外界强烈暗示的那样开放前沿模型权重，就会有四路足以支持 Agent 工作的开放权重模型可选，受到关注的匿名模型 Ox Alpha 也表明竞争者仍在增加。接下来存在两条路径：挑战者继续缩小能力差距，使模型逐渐商品化；或者前沿实验室再次实现重大跃迁，重新拉开距离。过去多次出现开放模型逼近、闭源新版本又扩大领先的循环，因此后一条路径仍然成立，尤其是数万亿美元 IPO 市值预期系于其中。但作者判断，这次差距已经小到前所未有的程度，下一次巨大跃迁的来源也尚不清晰。

前沿实验室维持竞争力，还可以依靠 **token 效率**。Anthropic 和 OpenAI 的旗舰模型，单个 token 的价格约为优秀开放权重模型的 5—10 倍，但开放模型完成同一任务往往会消耗更多 token，因此标价不能直接代表任务总成本。假设未来的 Fable 6 保持 Fable 5 的能力，却只需十分之一的 token 就能完成同一目标，即使每 token 收费很高，也仍能有竞争力。真正影响用户选择的是完成任务所需的总支出，模型能力与 token 消耗必须放在一起衡量。

算力合约到期后的重新定价，会进一步放大效率的重要性。Gavin Baker 指出，行业中一批以每 GPU 小时约 2 美元、锁定两到三年的算力合约即将到期，而 Blackwell GPU 当前租价明显高于这一水平；相关买家希望续约价格能控制在每 GPU 小时 4 美元，即便实现，底层成本也已经翻倍。在这种条件下，模型用更少 token 完成任务，以及服务商让每块 GPU 输出更多 token，都会形成直接的成本优势。作者因此认为，当前提高服务效率带来的竞争优势，甚至可能超过单纯提升智能。

这也改变了利润在产业链中的分布。过去数十年，软件通常攫取高利润，硬件趋于商品化；如今，模型能力趋同与物理算力稀缺同时发生，使利润空间更多取决于硬件容量和利用效率。OpenAI 能够降价，背后是可用容量与效率提升；Fireworks、Together、Cloudflare 等开放权重托管商，则无论服务谁训练的模型，都有同一个动力：提高每块 GPU 的 token 产出，以更低价格争取需求。廉价推理又会提前释放更多使用需求，让这场效率竞争继续扩大。

前沿实验室由此面临两条保住溢价的出路：在能力上维持足够显著的领先，或者大幅减少完成任务所需的 token，让高昂的单价不再决定最终账单。Fable 5 被认为"太贵"，说明这两种优势都不能被默认成立。开放权重模型已经接近到让大多数 Agent 工作无需调用最前沿模型的程度，而当"足够好"的智能可以被多家供应商提供时，决定定价权的就越来越是可交付的算力，以及把算力转化为任务成果的效率。
