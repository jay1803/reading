### RAM 是苹果垂直整合护城河的例外，而这个例外部分是苹果自己挖的坑

苹果的商业模式本质上是一次 50 年的赌注——通过掌控尽量多的生产环节最大化利润。它已拥有自研 SoC（委托台积电制造），但 RAM 和闪存至今是两个例外。更讽刺的是，当前这次 RAM 危机有苹果自己的因果：Micron 首席商务官 Sumit Sadana 直接指出，2023 年内存市场低谷期，某些客户（暗指苹果）以极低价格疯狂压价，导致行业大幅缩减资本投入，为今日的供应短缺埋下祸根。

### 苹果为何不能垂直整合 RAM

RAM 制造的技术壁垒使内化几乎不可行。三星自己生产内存芯片，但为了更高溢价的企业客户，三星甚至拒绝将芯片卖给自己的手机产品线——即便是最了解自身供需的厂商也无法绕开市场扭曲。苹果若进入这一领域，投入回报高度不确定；Apple Car 是高成本无产出的近期参照。

### 当下处境

苹果不再是最大的 RAM 买家，话语权已经倒转。Micron 知道 RAM 是苹果无法自产的少数核心组件之一，未来谈判将更强硬。现在苹果不得不向特朗普政府游说，寻求从中国受制裁 RAM 供应商进口以缓解涨价压力。消费者承担了结果：Mac 和 iPad 部分型号价格已上涨 200 美元以上。
