## 无底数的对数就是坐标系无关的向量

对数换底公式本质上是单位换算，不是一个独立定理。作者引入"无底数对数"log N——类比坐标无关的几何向量——来把这件事说清楚：log_2 N = log N / log 2，其中 log 2 就是"比特"这个单位。换底等于换度量标准，不换被测量的对象。这和向量 v = v_x * x + v_y * y 在不同基底间坐标变换完全同构。

### 向量 = 对数；对数 = 向量

这个对应是双向的：

- 向量方向：baseless log N 对应几何向量 v，log_b N 对应 v 在基底 x 上的投影 v/x。p 进赋值 ν_p(n) 和复分析中消去阶 ord_a f(z) 都是对数上的投影算子，数学各自发明了独立记号而没有统一。
- 对数方向：微分几何中切向量 v = v_x ∂_x + v_y ∂_y 本身就是平移算子 T^v = e^v 的对数，所以向量就是对数。

两个方向都是真命题，这使"对数 ↔ 向量"不像类比，更像同一结构的不同语境下的实例。

### 维数算子 dim 就是对数

|K^n| = |K|^n，所以 dim_K V = log_{|K|} |V|。这在有限域上是字面意义上的等式。张量积 ⊗ 对维数是乘法，直和 ⊕ 对维数是加法，与对数的乘积法则完全对应。作者的困惑是：这个显然的事实几乎从未出现在教材里。

### 自然对数是导数

ln x = lim_{a→0} (x^a - 1)/a = ∂_y x^y |_{y=0}。这解释了为什么 ∫x^k dx 在 k = -1 时特殊：ln x 行为上像 x^0 的一阶近似，不是数学上的意外。

### 作者的核心论断

所有这些——无底数对数、几何向量、dim 算子、ν_p、导数——都是同一件事：乘法代数与加法代数之间的同构，以及不同"坐标系"间的投影。物理学中的广义协变原理（性质独立于坐标选择）同样适用于纯数学，而现有数学记号在这里制造了大量遮蔽真实结构的冗余。作者认为这些本应是教材中自然推出的结论，而不是需要重新发现的东西。
