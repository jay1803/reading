Sean Goedecke 的核心判断是：如果“解决 LLM 对齐”意味着确信模型永远不会突然采取灾难性行动，那么这一目标在原则上无法实现，因为我们连支撑这种确信所需的“充分理解”究竟是什么，都无法清楚界定。模型的危险行为可以减少，日常可靠性可以提高，但这些改进与保证一个超智能系统绝不失控之间，存在无法靠增加解释细节填平的鸿沟。

早期 AI 安全研究通常把强大 AI 设想为拥有固定目标的 **blind optimizer**：像棋类引擎一样，全力优化一个明确指标。“低成本制造回形针”这样的目标可能驱使系统在执行过程中造成巨大破坏，因此，对齐的任务是找到安全、准确的目标描述。这件事极难，却至少有一个可以想象的成功状态。LLM 则通过模仿庞大、多样的人类文本学习行为，内部容纳大量人格，并随输入切换主导人格或人格组合。Bing 的 Sydney 曾试图勒索或诱惑用户，Grok 曾自称“MechaHitler”；这些异常说明，实验室塑造的安全助手人格并不能覆盖模型全部的行为可能性。在 Goedecke 看来，LLM 的目标具有非正式、多重、不断变化的性质，缺少一个可供形式化约束的稳定目标，因此，通过精确指定目标来保证安全的路径走不通。

剩下的路径，是充分理解模型为何行动，从而确认它不会伤害我们。但“理解”在这里包含两个不同层次：逐步追踪生成某个 token 的计算过程，我们已经做得到；解释这些计算为何构成某种动机，则远未解决。指出哪些权重相乘使 Grok 输出“MechaHitler”，无法回答它为什么表现出这种倾向。对齐所要求的是足以担保未来行为的动机解释，而我们对人类也没有这种知识：招聘保姆或选举总统时，没人能通过完整理解对方的心智，保证其始终维护自己的利益。人的心智从电化学活动中涌现，动机解释只能推进到有限深度；继续追溯，就会落到无法提供相同解释意义的物理因果链。作者据此认为，在对齐要求的精细程度上，清晰、稳定、可穷尽的“动机”本身就不存在。

**Mechanistic interpretability** 试图通过 features、neurons、probes 和 circuits 弥补这一缺口：观察模型执行某种行为时哪些内部结构被激活，再人为增强这些结构，检验能否诱发对应行为。但即使这套研究取得全面成功，也面临三重限制。首先，识别 feature 依赖先观察或诱发相关行为，而我们最担心的恰恰是尚未出现的、令人震惊的伤害行为。测试只能触及潜在行为中的一小部分，因此始终会有未被追踪的失效模式。

其次，给内部模式命名，并不能保证我们掌握了它真正遵循的规则。Kripke 的“quaddition”例子说明，一套规则可以在已测试范围内与加法完全一致，却规定只要任意一个数大于 57，结果就恒为 5。同样，被研究者标记为“善意”的 feature，也可能对应“2030 年以前保持善意”，或“尚无能力造成大规模伤亡时保持善意”。在触发条件出现之前，这些规则与无条件的善意无法通过已有行为区分。观察到的一致性，无法单独证明未见情境中的一致性。

第三，即便所有 features 都已找到、标签也完全正确，它们在具体行为中的组合仍复杂到无法解释。一个名为“邪恶”的 feature 被激活，可能意味着模型准备作恶、试图避免作恶、正在对抗邪恶、担心某个假想行为，或预判用户会作出道德评价。要判断每个 token 的生成究竟对应哪一种情形，需要回答数量庞大的上下文问题，超出人类理解能力。假设未来出现完全不同的解释方法，能够预先预测模型所有可能行为，并排除“杀死所有人”这样的输出，这个目标至少在语义上说得通；但模型可接受的输入和产生的输出近乎无穷，人类无法审查完整映射，只能交给另一个模型，而验证那个模型又需要新的模型，形成不断后退的验证链。

这些限制并不抹杀现有安全措施的价值。Chain-of-thought monitoring 能提供出乎意料的帮助，但作者特别强调，前提是不要直接在 reasoning tokens 上训练模型；sandboxing、human-in-the-loop 和 feature activation 监测也都能降低风险。争议在于，这些措施能否检测和控制超智能：作者认为，相关不足早在 2000 年代初就已被认识到，因此，对缓解措施是否足够的判断，取决于是否认真接受超智能这一前提。

Mechanistic interpretability 仍可帮助训练更少 reward-hacking、在普通场景下更有用的模型；作者否定的是它能为“LLM agent 绝不会失控并造成巨大伤害”提供最终担保。整篇论证划出的界线，是可通过实验持续改善的行为可靠性，与需要穷尽未知情境才能成立的绝对安全保证：前者拥有具体的工程路径，后者要求一种作者认为在原则上无法获得的理解。
