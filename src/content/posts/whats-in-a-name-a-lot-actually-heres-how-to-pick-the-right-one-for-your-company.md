## TL;DR
公司命名的最大误区是把它当"创意问题"——实际上它是一个可拆解的流程：定位先行，命名 brief 约束创意边界，海量 namestorm 后靠商标和域名现实过滤，而非靠主观偏好。

## 核心洞见
- 好名字不是"天才闪现"而是迭代过滤的幸存者。Disney、Nike 当初都不是团队最爱的选项；Phil Knight 选 Nike 时只觉得"不算太糟"。名字只是品牌的大使，不是品牌本身，你无法预支未来一百年的品牌资产。
- "两层名字"是最高段位：表面让陌生人秒懂，内圈人看到时"会心一笑"——Google 来自数学术语 googol（10 的 100 次方），Moderna 是 modified + RNA 的混合词。
- 要问研究者的是"负面联想"，而不是"哪个最好"：问太多人投票只会得到最小公分母——大家都接受但没人真正爱的名字。Vicks 在德国叫 Wick，因为德语发音会变成粗俗词汇。

## 具体机制：五步流程
1. *定位先行*：把产品写成一句话（为谁 / 是什么 / 差异化），作为命名的输入，而非直接开始头脑风暴。
2. *命名 Brief*：明确至少 10 个参数——竞品名单（避免撞风格）、偏好类型（描述性 / 暗示性 / 虚构性）、商标容忍度、域名预算。
3. *Namestorm*：用 LLM 做横向发散（别让 AI 直接建议名字，而是让它列出"25 个冷门发动机零件"之类的词根素材）；人做纵向筛选。候选量要达到数百甚至数千，才进入评分过滤（商标 / 域名 / 独特性 / 发音 / 时效性），缩到 10-25 个。
4. *缩到 top 3*：好兆头是"有人爱有人恨"（平均讨好 = 无聊）或"你反复回想说不出为什么"。坏兆头是容易被玩梗、和竞品同名、太描述性会锁死公司发展方向（ZenPayroll → Gusto）。
5. *商标审查*：USPTO 自查 → 律师综合搜索（含普通法 / 域名 / 社媒）→ 低 / 中 / 高风险评级 → 决定是否注册（注册费约 $5k）。注册商标按 USPTO 分类（Class 9 可下载软件 / Class 42 SaaS / Class 7 机械……），可跨类持有。

## 隐藏限制
- *.com 崇拜正在消退*：用户行为已转向搜索栏和 App Store，前缀变体（tryfigma.com）/ .ai TLD 已被广泛接受；执意拿 .com 可能代价七位数——要想清楚是否真的对转化率有量级影响。
- *单品公司别给产品另起名*：ChatGPT 的用户大多不知道背后是 OpenAI，这是无意中造成的品牌稀释；例外是面向完全不同受众的产品（Square → Cash App）。
- *命名全程大约需一个月*：不是一次头脑风暴或一个 prompt 能搞定的，但专业命名公司收费从 $25k 起到六位数——DIY 是现实选择。

## 留下来的那个想法
全文最反直觉的隐含判断：差名字几乎不会杀死好公司，但"还行但没人爱"的名字是一个慢性消耗——它每天都在悄悄拖累口碑传播，而你几乎感知不到这个代价。
