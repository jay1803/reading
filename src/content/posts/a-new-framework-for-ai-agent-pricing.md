## TL;DR
AI agent 定价目前存在四种模型，但作者认为只有"按结果收费"能在 LLM 成本持续下降的未来活下来。现实中 75% 的 AI 创始人连该选哪种都没想清楚——这篇框架文的价值就在这里。

## 核心洞见
四种模型各有其对应的预算来源和竞争暴露点：
- 按 Agent（FTE 替代）：切入 headcount 预算（是 IT 工具预算的 10 倍），定价固定可预期，但差异化低，易被"我更便宜"竞争对手冲击。
- 按动作（消耗模型）：镜像 BPO 逻辑（2025 年大型企业 BPO 支出 $152.8B），透明但与 token 成本直接挂钩——作者明确说这个模型无法经受 LLM 降价考验。
- 按工作流（流程自动化）：复杂多步骤流程定价，复杂度提供护城河，但也带来定价困难和负边际风险（任务超出范围时无法追加收费）。
- 按结果（成果导向）：与客户价值最对齐，对 LLM 降价最免疫，作者认为这是长期赢家。

## 具体机制
决策框架三步：①替代具体人头且任务标准化 → 按 agent；多步骤流程 → 按工作流。②结果可量化可归因 → 按结果（或用"成果奖金"混合过渡）。③任务杂、频次不可预测 → 按动作（可与按 agent 混合）。LLM 成本预计 3-5 年内下降 10-100x，现在不布局，未来边际会被侵蚀。

## 隐藏限制
按结果定价的两大陷阱：归因路径不清（AI SDR 产生的线索算谁的）和合同定制化蔓延。给出的解法（A/B 测试或 POC）在实际销售周期中往往不切实际。"LLM 成本下降 10-100x"是整篇危机感的核心依据，但无出处。

定价不只是捕获价值，它向市场传递的是"你的 agent 应该被如何感知"——这个信号维度比模型本身更难复制。
