## TL;DR
本文是作者 Eric Flaningam 对超大规模云服务商（hyperscalers）的季度更新，分析了他们在 AI 领域的战略、资本支出、市场份额以及各自的业务进展。超大规模云服务商在 AI 领域采取垂直整合战略，包括硬件、平台和应用三个层面。目前，他们在 AI 基础设施上的资本支出巨大，但 AI 应用的价值创造仍有待观察。
### 主题
#### Hyperscalers 的 AI 战略
Hyperscalers 的目标是成为垂直整合的计算提供商，包括三个层面：
1. 硬件：三家公司都在设计 AI 加速器，Google 的 TPU 最先进，AWS 的 Trainium 和 Inferentia 次之，Microsoft 最近发布了 Maia。
2. 平台：提供“自己动手”的 AI 服务，包括数据平台、模型微调服务和构建自己的 AI。
3. 应用：面向最终用户的 AI 应用程序，如 Github Copilot 和 Amazon Q，未来可能发展为代表用户执行任务的“代理”。
这种垂直整合战略类似于历史上新兴产业的发展模式。随着复杂性的增加，垂直整合的公司会逐渐放弃利润最低、防御性最弱的环节，最终围绕其最核心的知识产权进行防御。AI 领域最重要的问题是堆栈每一层的复杂程度，这将决定当前垂直整合提供商的护城河有多深。

#### 资本支出
目前 AI 资本支出的约 50% 用于土地、租赁和建设，AI 数据中心的真正建设尚未开始。Hyperscalers 正在进行“圈地运动”，以确保未来十年的计算能力。
其余的资本支出主要用于 GPU 和其他 AI 基础设施，这将由需求驱动。
各 Hyperscalers 的季度资本支出变化：
- Amazon：114 亿美元 -> 176 亿美元 = 54% 同比增长
- Microsoft：89 亿美元 -> 139 亿美元 = 55% 同比增长
- Google：69 亿美元 -> 132 亿美元 = 91% 同比增长
- Meta：62 亿美元 -> 85 亿美元 = 36% 同比增长
Hyperscalers 之间的资本支出存在一种微妙的平衡：Microsoft 无法获得足够的计算能力，Google 暗示可能过度投资，而 AWS 则对自身状况感到满意。
#### 市场份额
AWS 继续缓慢地将市场份额让给 Azure 和 GCP。这并非对 AWS 的控诉，而是其战略和云市场购买动态的结果。AWS 选择了基础设施优先的战略，与 Crowdstrike 和 Snowflake 等云 SaaS 公司密切合作，而不是更多地投资于自己的产品。这导致整体收入增长较低，但运营利润率较高，至少在短期内如此。
从季度净新增收入来看，AWS 实际上表现最强劲。
Azure 和 AWS 将成为最大的两家云提供商，GCP 明显位居第三。
Hyperscalers 的增长率依然强劲。AWS、Azure 和 GCP 的运行率分别为 1050 亿美元、780 亿美元和 410 亿美元，同比增长率分别为 18%、29% 和 29%。
整个云市场依然强劲。过去四个季度，TTM 净新增收入持续增长。

#### AWS、Azure 和 GCP 的业绩
##### AWS
Andy Jassy 在财报电话会议上提到了三个趋势：
1. 公司已完成大部分成本优化工作，并重新关注新的工作。
2. 公司再次将精力投入到基础设施的现代化改造上，并从本地基础设施迁移到云端。
3. 各种规模的构建者和公司都对利用 AI 感到兴奋。
AWS 在战略上独树一帜。Microsoft 和 Google 希望主导堆栈的每一层。AWS 表示了这一点，但他们的行动表明他们是一个基础设施提供商。这是他们最擅长的，并且他们在 AI 领域也保持着这一点。
AWS 并不太关心应用层，只要公司在 AWS 基础设施之上构建应用程序。

##### Azure
Microsoft 是分销网络的故事，这在 AI 领域得到了体现。到目前为止，Microsoft 是 AI 应用程序的最大收入赢家（包括第一方应用程序和使用 Azure OpenAI 构建的应用程序）。
本季度的一些亮点：
Azure AI 客户超过 60,000 家，同比增长近 60%，每位客户的平均支出持续增长。
同时使用 Azure AI 和数据分析工具的客户数量同比增长近 50%。Microsoft Fabric（由 AI 驱动的下一代数据平台）现在拥有超过 14,000 名付费客户。
自全面上市两年多以来，已有超过 77,000 家组织采用了 Copilot，同比增长 180%。
Copilot 正在推动 GitHub 的整体增长。GitHub 的年度收入运行率现在为 20 亿美元。
通过粗略计算，可以估算出 Azure AI 的收入。在过去的 5 个季度中，他们都披露了 Azure AI 收入增长的贡献。将其与 Azure 净新增收入相结合，可以了解他们每个季度增加了多少 AI 收入：
- 2023 年第四季度（对 26% 增长率的贡献为 1%）：约 1.2 亿美元
- 2024 年第一季度（对 29% 增长率的贡献为 3%）：约 3.79 亿美元
- 2024 年第二季度（对 30% 增长率的贡献为 6%）：约 8.03 亿美元
- 2024 年第三季度（对 31% 增长率的贡献为 7%）：约 9.91 亿美元
- 2024 年第四季度（对 29% 增长率的贡献为 8%）：约 12 亿美元
大致估计，他们在上个季度达到了 50 亿美元的运行率。
还可以将 Github Copilot 的收入添加到其中：
Copilot 推动了 GitHub 的整体增长。GitHub 的年度收入运行率现在为 20 亿美元。Copilot 占今年 GitHub 收入增长的 40% 以上，并且已经比我们收购 GitHub 时的整个业务规模还要大。
因此，Github Copilot 为 Azure 增加了 3 亿美元以上的运行率。
最后，我们不知道其余的 Copilot AI 收入（Microsoft Copilot、Sales Copilot、Security Copilot），因此 Microsoft 至少有 53 亿美元的 AI 收入运行率，但更可能超过 60 亿美元。

##### GCP
GCP 再次加速了收入增长，季度收入超过 100 亿美元，营业利润达到 10 亿美元。
其他有趣的注意事项：
[关于 AI 收入的小型定量]“面向云客户的生成式 AI 解决方案已经产生了数十亿美元的收入”
[继续强调垂直整合]“我们正在 AI 堆栈的每一层进行创新，从芯片到代理等等，这是一个巨大的优势。”
作者对 GCP 的立场保持不变：欣赏他们的技术和品牌。从技术角度来看，他们是 AI 芯片、模型和数据产品方面定位最佳的超大规模云服务商。
但 Microsoft 在 GTM 执行方面做得更好。他们迅速发布应用程序，对这些应用程序进行了出色的营销，利用其分销网络进行追加销售，并进行合作以弥补技术差距（例如 OpenAI）。

### 总结
目前市场主要由 AI 基础设施驱动，但 AI 的最终价值将由应用层决定。然而，目前尚未看到 AI 应用的大规模价值创造，其价值增值方式（例如，主要是削减成本还是产生收入）尚不清楚。
