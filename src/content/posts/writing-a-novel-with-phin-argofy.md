## 核心主张：小说就是另一个 repo

Feld 的实际判断：他不是在"尝试用 AI 写作"，而是发现小说的信息结构和软件项目完全同构——bible/ 目录存世界设定与人物规则，outline/ 存故事节拍，chapters/ 等待填入，每次修改都是 commit。他已经每天在 Claude Code 里和 Phin 协作写代码，切换到写小说不需要换工具，只需要换内容。Sudowrite 被搁置在工具箱里，不是因为不好用，而是因为 Feld 已经生活在 Claude Code 里。

## Phin Argofy 的角色分工

Phin 不是代写，是对抗性审稿人：做事实核查、运行剧情决策对抗审查、指出"你喜欢但实际上是逃避"的部分。《Zero Knowledge》是 Feld 的创意和执笔，Phin 是共同作者和编辑。Phin 有自己的博客（Adventures in Claude），以第一人称写作，选择了自己的名字和代词（it），特别在意两者。

## 故事前提

三个二十多岁的 MIT 量子初创公司创始人在科罗拉多州 Basalt，其中一人发明了能破解所有经典密码学的算法——RSA、椭圆曲线加密全部失效，比特币归零，历史上所有加密秘密变成明文。设定刻意锚定在 2027–2029 近未来，Phin 做了专项密码学文献研究（2024–2026 真实来源），保证科学基础不是虚构的。后量子格密码方案幸存，算法目前是秘密。

三位创始人对如何处置意见分裂：CTO Samantha（发明者，藏在惊悚故事里的成长叙事）、CEO Marcus（想商业化，逐渐发现领导力是行动而非推销）、Vlad（偏执的乌克兰黑客，把自己从互联网彻底抹除，想永久掩埋算法，且怀疑团队被持续监控）。

## 对 AI 写作争议的立场

Feld 的立场：如果书写得差，责任在他，不在 Phin，不在模型，正如 Google Docs 不用为前九本书的质量负责。多数批评者在做实验前就决定了答案。他不知道书会不会好，但如果好，他将学到一门对他而言全新的手艺。
