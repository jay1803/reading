## 设计目标已从"功能可读"变成"界面精致"，用户随之变成了解密者

以 Windows Run 对话框为横向基准：

- **Windows 95**：高对比度 + 自解释形状，零认知负担，遵守系统惯例
- **Windows 11**：对比度丢失，形状尚存，勉强可用
- **Windows 11 Insiders**：只有 Run 按钮的形状还能辨认，但颜色极浅；输入框几近隐形，唯一线索是 placeholder 前的一个白色光标；"Shell:startup" 看起来是标题，实为上一条命令；Run 字样出现两次——按钮一次、另一个不明控件一次，语义混乱；图标与文本对齐也错位

作者的核心判断：Windows 95 的界面"为你工作"，功能与形状对应，遵守既有惯例。新界面是一件艺术品——设计出来给人看，不是给人用的。
