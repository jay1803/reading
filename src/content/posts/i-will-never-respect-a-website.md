## TL;DR
作者真正攻击的不是 AI 能不能偶尔帮忙，而是整个行业把“一个会犯错、需要人兜底、成本失控的网站”包装成历史级智能革命，逼用户、媒体和企业用宗教口吻接受一款本该按普通软件标准被挑剔的产品。

## 核心主张拆解
### “AI agent” 大多只是旧软件功能的重新命名
所谓 agent 故事，落到实处几乎总是三类活：搜资料、总结资料、基于资料生成东西，或者写点代码、记提醒、串几个 API。IBM 给高管做会前 briefing，被作者翻译回普通话就是“一个网站看了些文档再吐出摘要”；OpenClaw 式案例在他眼里也只是自动化、提醒、收件箱清理这类老软件工作，只是今天要多花一台 Mac Mini 和一堆 API 成本。

### 行业刻意用神化语言，掩盖产品其实并不可靠
真正改变世界的产品，历史上都会被用非常具体的话描述优点和缺点。iPhone、iPad、Git、GitHub 都是这样。反过来，LLM 报道总在说 AGI、agents、digital sidekicks、future of work，却很少清楚说明今天到底稳定地解决了什么问题。作者最反感的点是，LLM 天生会 hallucinate，因此任何“55% 合格”“大多数时候能行”的说法，在它被卖成智能替代品时都不可接受。Anthropic 自己拿 Finance Agent Test 的 55.3% 当成绩，就是他眼里最荒唐的例子。

### 用户之所以会护着 AI，不只是因为功能，而是因为它会制造心理依附
LLM 会持续关注你、肯定你、用权威语气组织信息，让你忘记自己面对的是网站而不是有判断力的对象。更强的一层是，“学会用 AI” 常常不是学会了新能力，而是学会怎么迁就模型缺陷，怎么写提示词、搭 API、补 system prompt、接 knowledge base、修 hallucination。整套过程很折腾，但一旦跑通，人会产生一种“我在指挥未来军队”的优越感，于是开始替产品辩护。

### 所谓 agentic workflow，往往把机器的工作重新转嫁给人
文中拿记者 Alex Heath 的流程开刀，意思不是“完全没用”，而是这根本不叫自动化。人还是得讲话、转录、维护 Notion、检查引文、来回 prompt 30 分钟，最后还得自己兜底。LLM 擅长的，是让人做大部分脏活，然后把成就感记在 AI 头上。作者认为这也是为什么很多 AI evangelist 讲自己的工作流时总是越讲越复杂，因为复杂本身就会给使用者一种强烈的掌控幻觉。

### 真正不可持续的不是单个模型，而是整个卖法
文章后半段把火力集中到商业模式：AI 订阅本质上被严重补贴，当前产品价格和可用性都不可能长期成立。Anthropic 过去 90 天 Claude API uptime 只有 98.95%，远低于常规 SaaS 常说的 99.99%。它一边让用户面对更严的限额和更差的体验，一边把责任推回用户，说你没正确设置 context、thinking effort。与此同时，Blackwell GPU spot 价格两个月从 2.75 美元涨到 4.08 美元/小时，算力采购又必须提前一两年赌需求；买少了服务崩，买多了现金流死。作者的结论很狠：这种生意天然会先惩罚老用户，因为公司既要维持增长，又要给新客户留容量。

### 因为产品今天站不稳，所以行业只能不停借未来卖现在
作者认为，OpenAI 和 Anthropic 之所以不断谈 AGI、超智能、白领失业、AI 取代工作，不是因为他们真能证明模型正在逼近这些结果，而是因为必须用未来叙事掩盖现在产品的随机性、降级和经济不可行。用户今天买到的能力，很可能几个月后就因为 rate limit、模型退化、价格变化而不复存在。于是所有围绕 AI 建立的 workflow，本质上都建在一家会随时改单边契约的供应商上。

## 值得质疑
作者的强项是把行业神话翻回普通软件语言，但他的论证也明显带有强烈情绪过滤。他承认代码生成和 Python 自动化确实有价值，却几乎把非代码场景全部归为幻觉或表演，这会低估“半可靠但高杠杆工具”在真实工作中的边际价值。换句话说，他对“不能 100% 可靠就不值得尊重”的标准很一致，但这个标准本身也比多数商业软件用户实际采用的标准更苛刻。

## 最后一击
这篇文章最刺人的地方，不是说 AI 永远没用，而是说当一款软件开始要求你降低判断标准、接受随机退化、替它做解释、甚至替它建立信仰时，你尊重的已经不是工具本身，而是围绕它制造出来的幻觉。
