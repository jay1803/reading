## TL;DR
储备货币地位与慢性赤字的因果方向，本身就是伪问题：系统是双向自我强化的闭环。美国已将"储备资产"从货币和国债扩展到整个文明体系——作为全球唯一兜底方，网络效应越深，地位越牢固。

## 因果链拆解
- **外部需求说**：世界需要美元 → 向美国出口并积累不花回去的美元资产 → 储备需求内生
- **美国超支说**：赤字制造大量流动性美元计价资产 → 全球借贷/定价基准天然选美元 → 储备地位确立
- 历史起点：布雷顿森林体系将美元设计为储备货币；关闭黄金窗口后基础设施留存，反而使美联储能无约束地供给世界所需美元

## 英国先例与护城河厚度
20世纪初美国GDP已超英国，但英镑储备地位又维持了数十年：大量英镑债务仍在流通 → 还债者仍需积累英镑 → 伦敦流动性市场持续存在。美国更极端：其贸易份额（23%）低于GDP份额（26%），但美国金融体系已大到"所有未受美国制裁、未封锁资本流动的国家的金融系统，事实上都是美国系统的一部分"。

## 为什么均衡极难打破
美元资产规模 → 流动性更高 → 风险调整回报更好 → VC激励集中 → 全球顶端人才随资本流入美国。经济冲击下，美国放缓往往引发他国更严重衰退，反而制造美元紧缺，进一步强化美国中心地位。打破均衡意味着美国从净消费者变成净生产者偿债——金融体系规模大幅萎缩，所有主要参与者都有动机维持现状。

美国持有慢性赤字，是向世界"供应美元资产"的机制本身，不是病，是合约。
