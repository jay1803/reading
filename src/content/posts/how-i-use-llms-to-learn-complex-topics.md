让 LLM 把复杂知识转化为可观察、可操控的流程模拟，能帮助学习者把抽象概念与具体对象、变化过程联系起来，比直接阅读模型生成的解释更容易理解和记忆。Laurentiu Gabriel 在研究可能拖慢 AI 数据中心建设的瓶颈时，发现自己对芯片制造的许多环节缺乏了解，于是尝试让 AI 制作一款模拟晶圆厂生产流程的游戏，用视觉体验补足普通文字解释过于简化的问题。

这套方法先建立知识基础，再将知识转化为模拟。在 CC 或 OpenCode 的 plan mode 中，他先要求模型整理某个主题的基础知识，再要求模型复核这份知识库的准确性，随后生成具有低多边形风格、类似 RollerCoaster Tycoon 的流程动画。他同时指定交互要求：页面适配大屏和小屏，提供随时暂停流程的控制功能。完成后，把项目推送到新的 GitHub repository，并启用 GitHub Pages，让模拟成为可以直接访问的学习工具。

他用这套流程制作了 **ChipTycoon**：学习者跟随一辆小车，从收集沙子开始，一直看到芯片制造完成并送往数据中心。小车承载的物料会随着制造步骤发生视觉变化，因此学习者既能追踪工序顺序，也能观察产品在各个阶段如何转变。低多边形设计省略了细节，但仍可呈现制造过程中的主要变化。Gabriel 认为，这种学习体验比在 Google 上不断寻找材料，或消化语言模型输出的项目符号列表更有效；他还宣称生成结果“100% 准确、没有幻觉”，但文中提供的校验步骤只有模型复核知识库，没有展示独立验证依据。

模拟的下一步改进，是提高视觉表达的具体程度，并加入主动回忆。假如低多边形画面让人难以想象石英砂经过熔炉后究竟变成什么，可以使用他提供的 **unreal-game-assets-creation-skill**，将图片转成 3D 对象，再把这些对象映射到模拟中，提高物料与加工结果的视觉还原度。在此基础上，还可以加入有关前序制造步骤的问题和直观谜题，让学习者在推进流程时检验记忆。整套方法把知识组织成一条可以追踪、暂停和回顾的因果链，再通过提问与解谜强化对各环节的掌握。
