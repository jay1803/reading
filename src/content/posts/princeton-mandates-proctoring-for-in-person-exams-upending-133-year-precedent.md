## TL;DR
Princeton 强制恢复线下考试监考，关键含义是一项 1893 年以来的荣誉制度承认：在 AI、个人设备和社交压力共同作用下，“学生互信 + 同侪举报”的模型已经失去足够可观察性，发现违规的责任被重新交给教师见证人。

## 关键事实
- 新规从 7 月 1 日起生效，所有线下考试都必须由教师在场监督；教师角色被定义为“见证发生了什么”，原则上不干预学生考试。
- 教师会议以仅 1 票反对通过该提案；此前考试与学业 standing 委员会、教师政策咨询委员会已一致通过。
- Princeton 的 Honor Code 起源于 1893 年学生请求取消监考；此后校方规则明确禁止监考长达 133 年，这次需要修改 Faculty Rules 与 Rights, Rules, Responsibilities。
- Honor Committee Constitution 和 Honor Code 本身不需修改；疑似违规仍由学生主导的 Honor Committee 审理，监考教师可提交观察报告并作为证人作证。
- 2025 届 500 多名 senior 调查中，29.9% 承认在作业或考试中作弊，44.6% 知道 Honor Code 违规但未举报，只有 0.4% 表示曾举报同学。
- 具体执行细节仍未定，包括监考人与学生比例、监控行为边界，以及教师在考场中应如何记录和报告异常。

## 背后逻辑
- AI 和小型个人设备改变了作弊的外观：违规行为更不容易被同学观察，也更难让同学承担即时判断和举报压力。
- 学生匿名举报增加，背后是对网络 doxxing、羞辱和同侪关系后果的恐惧；这说明原本依赖学生互相监督的制度，在社交成本上已经失衡。
- 新规把“发现违规”的第一层责任从考生群体转移给教师见证人，同时保留 Honor Committee 的学生审理结构，试图在低信任环境中保留一部分旧制度外壳。
- 它保留荣誉制度名义与学生审理环节，但把制度重心从纯粹自我约束模型改造成“学生审判 + 教师证据输入”的混合模型。

## 制度代价
- 最大代价是文化信号：Princeton 等于承认传统 Honor Code 无法独自应对 AI 时代的考试诚信问题，133 年的象征性信任被正式降级。
- 支持者强调现实主义：监考不能根除作弊，但能形成威慑，并减轻学生在考试时观察、判断、举报同学的压力。
- 反对者担心监考会侵蚀 Princeton 学术文化中最核心的互信感；Jill Dolan 的评价“a shame, but necessary”基本概括了制度转向的情绪张力。
- 执行边界会决定这项改革的实际性质：如果教师只是被动见证，变化主要在证据链；如果监控标准扩张，改革会更接近常规高压监考制度。

## 值得质疑
- 文章没有给出 Honor Code 案件增长的完整时间序列，也没有证明线下监考对 AI 相关作弊有多强抑制效果。
- Senior Survey 的自报作弊率很重要，但它混合了作业与考试，不能直接等同于线下考试作弊率。
- AI 作弊的关键环节可能发生在备考、作业、带回家考试、允许设备的考试或考试前资料生成中；线下监考主要解决“考场可见行为”这一段。
- 新规减少学生举报压力，却可能提高教师与学生之间的制度距离；这种信任损耗能否被更清晰、更公平的程序弥补，文章没有展开。

## 最后一层意思
Princeton 这次改变的真正含义是：当技术让违规更隐蔽、社交环境让举报更昂贵，精英大学也会从高信任荣誉共同体退回到可审计、可作证、可追责的低信任治理模式。
