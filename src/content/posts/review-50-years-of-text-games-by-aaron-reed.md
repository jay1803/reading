## TL;DR
文本游戏的真正机会是把 AI 放进有硬规则、有历史、有物理、有可追责状态的模拟世界。旧 IF 的魔法来自作者预先穷尽玩家意图，LLM 的魔法来自语言理解和补缝；真正的“好玩”需要玩家撞上一个不迁就他的世界，并从规则摩擦里生出意外。

## 核心主张拆解
### 文本游戏一开始并不“原始”
早期图形游戏反而更省资源：像素可以用少量坐标和规则表达，文本却要逐字存储。ROCKET、Hunt the Wumpus、The Sumerian Game 这类早期作品使用文字作为显示器和控制台，本体仍是数字模拟；文字只是仪表盘，不是世界本身。

### Adventure 把“文字”变成了世界材料
Will Crowther 的 Adventure 把洞穴经验、图结构、手写地点描述、物品交互、解析器命令合在一起，创造了互动小说的核心幻觉：玩家似乎可以用自然语言对一个世界发号施令。它的魔法来自极不经济的人力投入——作者预先想象玩家可能输入什么，再写下恰当回应；“YOUR FEET ARE NOW WET” 这种无关进度的反馈，就是沉浸感的燃料。

### IF 的黄金时代死于图形，也幸存于虚拟机
Zork、Hitchhiker’s Guide、Suspended、A Mind Forever Voyaging 等作品证明文字能制造电影无法视觉化的结构和感受。但图形界面成熟后，IF 很难与互动动画竞争。Infocom 的 Z-machine 反而成了长期生命线：虚拟机让旧游戏跨平台存活，也让非程序员能用开放工具继续创作，形成 IF Archive、IFComp、XYZZY 等小众生态。

## 为什么旧 IF 被困住
IF 最大的问题是承诺了开放，却经常暴露边界。玩家一旦输入自然但未被作者预案覆盖的动作，或者猜不到解析器接受的短语，世界就从“共同创作”坍缩成“作者给出的选项”。这种限制比规则明确的游戏更刺痛，因为它先制造自由幻觉，再随意收回自由。

更深的问题是，游戏的乐趣高度依赖涌现：观众建议让即兴剧跑偏，桌游规则组合出设计者没想到的策略，DM 随机表生成荒唐遭遇。传统 IF 依靠作者穷举反应，反而压制了这种意外；它越精致，越容易把玩家困在作者已经想过的空间里。

## 历史上的三种补救
### 让人类加入世界
MUD 把 Adventure 式空间变成多人在线世界，用真人的即兴能力补足机器理解力。但人类会拒绝配合，共同维护世界也很费力，所以 MUD 往往滑向 BBS、社交网络和轻度 LARP。

### 让玩家变成作者
从 MUD 里的 wizard 到 LambdaMOO、Second Life、Roblox，玩家创作内容能扩大世界供给，却没有根治 IF 的解析器、规则一致性和涌现设计问题。它更像把生产外包给用户，而不是解决“世界如何回应自由行动”。

### 用 ELIZA 效应假装理解
His Majesty’s Ship “Impetuous” 这类作品用模式匹配和线性剧情制造互动幻觉，短期可骗过玩家，长期缺乏重玩价值。玩家很快会发现输入并不改变世界，只是在给预定叙事添烟雾。

## AI 游戏为什么还没爆
LLM 确实解决了旧解析器最痛的“理解玩家意图”问题，但它们单独做不好游戏，原因有三层：

1. **太容易被玩家说服**：好 DM 和硬规则会抵抗玩家，抵抗本身会激发创造力；当前 LLM 被训练得过度顺从，缺少“世界不让步”的质感。
2. **生成内容趋向平均值**：模型很有用，但默认会产出互联网上文本的均值；游戏需要怪异、具体、非平均的局部惊喜。
3. **缺少稳定世界模型**：LLM 会让物体、人物、因果、空间关系漂移。游戏乐趣需要可被利用的地面事实；如果隧道会因为叙事方便突然消失，玩家就无法围绕规则形成技能。

所以 AI Dungeon 式产品没有打开新黄金时代，核心原因不是文字生成能力不足；“会接话”不足以构成“可玩的世界”。

## 可行方向：模拟 × 程序生成 × LLM
文章认为更强路线是回到那些“文字只是模拟外壳”的老游戏，并把它们与 IF 合并。The Hobbit 提供早期样本：NPC 有目标、情绪和脚本，物品有重量、大小、脆弱度，谜题按世界状态判定，因此“用 Gollum 的尸体杀死 Smaug”这种荒唐解法能成立。Dwarf Fortress 把这条路推到极端：地质、历史、器官、语言、文化、生态全都被模拟，玩家的离谱方案之所以难忘，是因为世界真的有规则可以承受它。

LLM 的合适位置是填补模拟之间的缝：
- 用语言理解把玩家自由输入映射到规则系统；
- 为异常情况提供有损但可用的桥接；
- 批量生成随机表、描述、变体和测试数据；
- 充当机器人玩家，大规模探索玩家会尝试什么、世界哪里缺反馈。

这种架构让程序生成负责“硬地面”，让 LLM 负责“软边界”。前者提供可涌现的因果，后者降低作者为每种交互手写回应的成本。

## 值得质疑
作者把 LLM 的“mediocrity engine”问题归因于平均化训练，判断大体成立，但略低估了未来模型在长期状态维护、工具调用、规则验证上的工程改进空间。真正的瓶颈也许不是模型本身，而是游戏架构是否愿意放弃纯自然语言即兴，转向可检查状态、可回放事件、可调试规则和受约束生成。

另一个薄弱处是商业判断：文章解释了为什么 AI 文本游戏还没爆，却没有充分区分“作品趣味”“大众市场”“创作者工具”三条曲线。模拟主义 + LLM 可能先成为小团队创作杠杆，而不是直接产生大众爆款。

## 最后一层
这篇书评真正关心的不是怀旧，而是“语言能不能再次成为游戏世界的主界面”。如果旧文本游戏的前 50 年是在资源限制下发明魔法，下一阶段的关键会是给 AI 一个不会被它随口改写的世界，让玩家、模型和规则三者一起产生意外。
