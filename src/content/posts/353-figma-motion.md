## Figma Config 2026：补短板年，动效与 shader 终于到位

Figma 这一年的更新逻辑是补竞品已经抢占的阵地。Motion 是典型案例——内置时间线与关键帧本应是设计工具的基础功能，被 Lottie 生态压着好几年，这次总算进主产品；Shader Fills 则是被 Paper 和 Wonder 抢走用户后的跟进，shader 现在已是新一代设计工具标配。

### Figma Motion 的实际局限

目前不能导出为 Lottie，功能初级，进入生产环境的可行性有限，预计还需一到两个迭代周期。

### Figma Agent 的赌注

画布理解、Skills 打包、外部工具连接、团队共享——Figma 把 Agent 定位为第二增长曲线，而非辅助功能。

### 股价低估的真正原因

作者判断：Figma 估值长期被压，根本原因是公司持有比特币带来的负面情绪，而非产品或营收问题。AI 能力与核心产品持续改进，长期基本面稳健。

### 本期值得读的 Articles

- Less is more（Jakub）：AI 把加法变得过于容易，真正稀缺的是品味与判断力；agent 应被明确的设计意图约束，而非堆功能
- Vercel 的 product-design skill 实践：把设计决策作为代码治理，通过 AGENTS.md 路由与 ESLint 规则让 coding agent 能加载决策上下文

- Hermes Agent MoA Presets（Nous Research）：把 Mixture of Agents 以虚拟模型形式暴露，宣称超 Opus 4.8 和 GPT 5.5 各 8% / 11%——待独立验证
- Batchwork：统一批量 LLM API，聚合多家 batch 模式，声称节省最高 50% 调用成本
