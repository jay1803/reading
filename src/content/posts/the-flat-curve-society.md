## 曲线没有变平——只是对你来说它"看起来"变平了

Yegge 的核心论点不是 AI 进步放缓，而是：指数增长会继续，但多数人再也看不到它了。原因有两个，且本质上是同一个问题的两面。

第一重力量是**监管封锁**。Yegge 认为我们距离前沿 AI 被当作核武器管控只剩 2-3 代模型。政府通过卡供应链（芯片、算力）实现封锁，中美都会把超级智能圈在自己边界内。最终，前沿智能以"服务贩卖机"形式存在：你发去规格，他们的模型帮你实现，在他们的服务器上，你付钱。多数公司不会把代码和问题发给模型厂商，因此这条路对大多数人并不可行。

第二重力量是**辨别地平线**（discernment horizon）。人类对模型输出的判断能力有天花板——超过这条线，你根本不知道模型是对的还是在带你走向悬崖。Yegge 还区分了另一个概念，**需求地平线**（demand horizon）：如果你手头没有足够难的问题，更聪明的模型不会显出优势。收集"口袋测评"（hard problems）是区分两者的方法——你能提出难问题，你的需求地平线就高；你能验证答案，你的辨别地平线才高。

这两重地平线汇合在同一点：超人类智能既不能被监管者信任（没有人能监督它），也不能被使用者有效利用（没有人能验证它）。这是"危险"和"无用"的统一根源，而不是两个独立理由。

## 可预见的行业影响

**SaaS 不会消失。** 公司在几个月内烧完全年 AI 预算后，buy-vs-build 天平已经明显向采购倾斜。能让你省掉自建和维护成本的 SaaS 依然成立，代理化改造和全面替代在今天的模型能力下仍然过于昂贵。

**开源模型触顶。** OSS 落后前沿约 7 个月，在供应链锁定和前沿厂商拒绝协助训练危险开源模型的情况下，难以突破"Fable 级"天花板。今天的模型大致就是多数人能长期用到的模型。

## AI 扫盲的可测量框架（Netflix 研究）

Netflix 工程师 Ezra Savard 的研究给出了三个**基于日均 token 消耗**的入门梯队：

- **0M tokens/day**：没在用 coding agent 做日常工作
- **4M tokens/day**：全天同步使用单个 agent
- **12-15M tokens/day**：同时放开 2-4 个 agent 异步工作

关键数据：
- **5 小时**的训练可以让人从梯队 0 跳入梯队 1，且 96% 的学员在 6 周后仍维持在新梯队
- 训练格式不可妥协：每次 5-10 人 + 直属 manager 同时参与，带来实际工作，算作公司正式工时；缩减任何一个环节（更短、更大班、个人自愿）效果都不保留
- 超过 15M tokens/day 后，token 消耗不再是有意义的测量指标——此后应切换为**结果导向**测量

进阶梯队的核心技能是 **token 节约**（token hygiene）：知道什么事情手动做比让 agent 做更省钱，例如直接 `!git push` 而非让 agent 执行，每次可能节省 10 万 token。入门者是"token 大户"，这是正常的探索阶段；高手是极度 token 高效的——正如 Genetec CEO 开的玩笑："我不是不用 AI，我只是 _极其_ token 高效。"

## 平台期是工程化的前提

Yegge 认为平台期不是坏事——不稳定的指数增长一直在让创业公司的产品快速被新模型淘汰。平台期给了"扎营建设"的机会。

真正的工程挑战是任务分解和打碎大型 monolith，让今天的模型在其能力边界内高效工作。Sonnet 级和 Opus 级模型会因为便宜且可广泛获取，在前沿继续移动多年后依然保持价值——因为能把它们淘汰的模型大概率对多数人不开放。
