个人网站要在主人去世后长久存续，既需要有人持续付费，也需要重新考虑：保存一个人的数字遗产，是否必须永久占用他生前的域名。Ernie Smith 指出，公司可以通过继任安排延续域名和托管服务，个人却通常只被注册商与托管商视为持续消费的客户。一旦本人去世、信用卡停止付款，网站及其承载的数字身份也会逐渐消失。对于把作品积累在个人网站上的作家与创作者，这意味着身后作品的存续取决于一套缺乏长期保障的商业关系；互联网没有普遍适用的“公墓”，能够接收这些历史的档案机构也相当有限。

Smith 为关注死亡与哀伤的媒体 GraveSite 撰文时，介绍了由非营利机构接管网站、代替逝者持续支付账单等方案。但让网站与域名“永远”存在，也会产生代际资源分配问题。他用自己的 erniesmith.net 举例：如果把这个推广自由撰稿业务的域名交给永久保存服务，未来同名的 Ernie Smith 是否就失去了使用它的机会？读者提出的这一疑问揭示了域名与网站内容之间的寿命差异：原持有人去世后，域名可能已失去现实用途，网站中的作品与记录却仍值得保存。随着域名持有人不断离世，永久保留地址与为后来者释放名称之间的矛盾会持续累积。

这使讨论转向一种不依赖域名的信息保存架构。曾参与 Google Chrome、现就职于 Microsoft Edge 的工程师 Alex Russell 提到 **Web Packages**：把完整网站打包成可分发的对象，读取时无需绑定域名，甚至无需联网。这项构想最初来自 Chrome 团队，但几乎没有获得其他浏览器厂商支持，后来逐渐淡出主流 Web 标准讨论，目前仍由 Web Incubator Community Group（WICG）承载。随着失去维护者的网站越来越多，Smith 认为它值得重新受到重视。

打包保存也回应了旧网站的维护与安全负担。停止维护的网站往往只能以静态形式保留，可能缺乏现代网站普遍采用的 HTTPS，并携带潜伏的安全问题。Web Packages 提供了一种将网站整体封装、分发和研究的路径，其列出的用途之一就是便于第三方开展安全漏洞审查。如果把旧网站视作可以随时取阅的书卷，保存工作就有机会减少对持续运营域名与在线服务的依赖；域名可以承担一个阶段的访问入口，内容则进入寿命更长的保存体系。

Smith 最尖锐的判断落在当前体系的倒置上：一个人精心搭建、独立维护的网站，百年后仍可访问的机会，竟可能低于其 Facebook 个人主页，或早已遗忘的 Blogger、LiveJournal 页面。个人掌握发布渠道，并没有自动获得长期保存作品的能力。数字遗产的持久性，最终取决于能否把内容的保存期限，从创作者的寿命、付款能力和域名占用期限中解脱出来。
