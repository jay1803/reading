当前 LLM 在数学上的突出优势，是凭借广博知识和高速搜索找到适合大量试探的证明与构造；人类可能仍占优势的领域，则是必须识别真正的进展、深度剪枝才能找到答案的问题。Gowers 以 2026 年 8 月初的能力为讨论对象：据文中所述，OpenAI 刚宣布解决十个数学与理论计算机科学的重要问题，包括首次构造 non-sofic group，以及证明 multicolour Ramsey number R(3,…,3) 随颜色数超指数增长。这些成果说明 LLM 已能解决重大开放问题，却不足以说明它们在数学的所有方面都超过人类；如果已经全面领先，再叠加速度优势，数学成果应当呈现更大规模的涌现。

最显眼的成果确实多属于例子或反例，包括上述两项，以及文中提到的 Jacobian conjecture 和 unit distance conjecture。但"LLM 擅长反例"首先面临一个分类难题：**寻找例子不能直接等同于证明存在量词开头的命题**。Vinogradov 的三素数定理说，存在一个阈值，超过它的每个整数都能写成三个素数之和。从形式逻辑看，证明这个阈值存在，也可以描述为给某个全称命题找到了反例；数学家却显然把它视为定理。研究的实质在于怎样处理任意一个足够大的整数，阈值是在证明完成后确定的。

Gluskin 关于 Banach-Mazur compactum 直径的结果，则展示了相近逻辑形式背后的另一种研究任务。Banach-Mazur distance 衡量两个同维赋范空间之间线性同构所需的最小失真；Fritz John 定理给出任意两个 n 维空间之间距离不超过 n 的上界。常见空间 ℓ₁ⁿ 与 ℓ∞ⁿ 看似相距很远，但通过 Hadamard matrix 一类变换可以大幅降低失真，因而无法给出与 n 同阶的下界。Gluskin 在 1981 年证明，存在固定正常数 c，使每个维度 n 都有一对空间，其距离至少为 cn。他用标准基向量、若干随机单位向量及其负向量的凸包作为单位球，并证明独立选出的两个空间以高概率相距足够远。

这个结果的量词结构同样包含"存在常数、对每个维度、存在对象"，但其核心工作是构造彼此遥远的空间；让空间具有指定维度并不困难。Vinogradov 的核心困难却恰好是让三个素数之和等于指定整数。因此，例子与定理的区分取决于变量在数学问题中承担的角色，不能只看量词排列。Skolemization 还可以把"对每个 x 存在合适的 y"转化为"存在一个为每个 x 选择合适 y 的函数"，这也贴近数学家把构造理解为统一配方的习惯。类似地，证明 torus 与 sphere 不同胚，可以通过寻找区分二者的 invariant；证明某个向量不属于一个紧集的凸包，可以通过寻找 separating linear functional。全称结论经常依靠存在性对象得到证明。

更根本地说，寻找某种对象贯穿几乎所有数学研究。归纳证明可能需要寻找更强的归纳假设，证明一个性质蕴含另一个性质可能需要寻找中间性质，证明任何命题都可能需要寻找一种此前未知的证明方法。Goldbach's conjecture 的例子尤其说明，理解一个命题为什么可信，与掌握能够证明它的工具之间存在巨大距离：素数的概率模型和计算数据支持猜想，但把这种启发变为严格证明，仍然需要足够强的技术。因此，LLM 的优势无法用"适合存在性问题"得到有效解释。

"反例"还包含数学共同体的预期。ℓ∞ 是一个基本的 non-separable Banach space，但通常没人把它称作"所有 Banach spaces 都可分"的反例，因为这个全称判断本来就没有充分理由成立。类似地，non-sofic group 已有多种候选构造思路，Gowers 的印象是专家很少坚信所有群都具有 soficity，因而首次找到这种群更接近填补一个期待中的例子。Ramsey number 的超指数下界对相信指数增长的人构成反例，对态度中立或倾向更快增长的人则是正面构造。Gowers 曾研究其等价问题：用多少个 triangle-free graphs 才能覆盖 complete graph。二部图给出对数数量的覆盖，利用 complete 5-partite graph 可分成两个 triangle-free graphs 能进一步改善；要突破到次对数数量，就需要染色数无界的 triangle-free graphs。他当时探索的方向与最终结果一致，因此并未把结果理解为推翻自己的预期。

排除这些分类上的解释后，更有解释力的假说是：**LLM 擅长某些发现证明的方法，而这些方法恰好适用于一批重要构造问题**。模型掌握大量标准论证，又能承担人类无法承受的失败次数，因此在"尝试许多未必新颖的思路，直到某次组合奏效"的任务上拥有优势。一些专家对模型成果的反应与此相符：问题被解决时令人震惊，仔细检查后却发现方法并不十分新颖，合适的一个小提示就可能让熟悉领域的人找到它。这支持高速试探的解释，但尚未构成对模型发现机制的科学证明。

构造例子的路径本身也有很大差异。可以逐一测试现成对象，例如 Ryan O'Donnell 建议把 Boolean functions 的猜想先放到 dictators、majority、parity、tribes 和 recursive majority of 3 上检验；也可以对标准对象做 products、quotients 或 limits。另一些构造适合逐步完成：若对象需要满足无限多个条件，而每个条件单独容易满足，就在第 i 阶段确保第 i 个条件此后始终成立。还有些问题适合随机选择对象，再证明成功概率为正或很高；在无限情境中，则可通过证明失败集合具有 measure zero、属于 meagre set 等方式获得 generic example。这些方法常有大量标准先例，因而能够发挥模型知识广、试探快的优势，但概率估计本身若需要重大新思想，优势就不能直接推定。

另外几种方法更依赖对研究方向的判断。使用 metavariables 时，研究者先保留对象的未定部分，尝试证明目标性质，再从证明需求中逐步提取约束，将对象限制为越来越具体的参数化家族。尝试证明相反结论时，失败的证明可能暴露一个足以推出该结论的关键引理，再寻找违反引理的对象；违反引理并不保证满足原目标，却可能有效缩小构造范围。Successive approximation 则从一个预料不会成功的候选出发，诊断失败原因，再修正下一版。这些方法的价值取决于能否判断新约束、失败和修正是否带来了实质进展。

人类可能保留优势的条件因此很严格：答案必须位于一棵深而分支繁多的搜索树中，广博知识加高速枚举仍无法遍历，而研究者能够凭借对进展的敏感判断大幅剪枝。Gowers 与 ChatGPT 5.6 Pro 讨论开放问题时，经常得到乍看有希望、细想后价值有限的方案；模型也会连续宣称把问题缩小为"更精确、更狭窄的问题"，却没有明显推进。训练材料主要包含整理后的证明，隐藏了发现者如何区分有效方向与死路；同时，模型的速度优势可能让低效搜索暂时仍能取得成功，削弱形成严格剪枝能力的压力，直到组合爆炸真正成为障碍。

检验这种能力也不容易，因为看似来自深刻思考的新论证，可能只是模型调用了文献中已有的人类思想。Gowers 提议用较弱、适度隔离数学文献的模型和精心设计的问题集，观察哪些问题特征影响成功率；也可以改变奖励结构，在奖励解题之外，惩罚过多死路和直接从文献取得答案，检验模型是否由此学会更有效的研究策略。他没有断言 LLM 永远无法跨越这道门槛，纯粹扩展规模或调整训练方式都可能使其迅速跨越。

真正有说服力的标志，是模型提出类似 2016 年 cap-set problem 解法的突破：大幅超越此前界限，采用领域专家未曾考虑的路线，并催生一系列后续应用；方法初见时出人意料，理解后却显得自然，而且难以靠偶然试探撞见。衡量数学能力的关键，由此从解决了多少个反例问题，转向能否在不可穷举的搜索空间里识别值得走的路径，并创造能够重新组织一个领域的证明方法。
