对 0.mk 在 2009 至 2014 年间保存的 65.8 万条短链接进行逐一追踪后，结果显示早期网络留下的内容已大面积消失：在 655,178 条安全且可抓取的历史链接中，76.7% 无法加载，而幸存者明显向 YouTube、Wikipedia 和 Google 等大型平台集中，个人博客、论坛、地方新闻站和图片托管服务构成了失联内容的主体。

这批数据来自 0.mk 团队在旧硬盘中找到的数据库备份，共恢复出 657,958 条记录，其中 657,607 条创建于 2015 年以前；排除目标格式错误、内部地址、带凭据或受策略限制的 2,429 条后，研究者在 2026 年 8 月测试了其余链接。由于多个短链接可能指向同一目的地，全部记录实际对应 494,781 个不同 URL，其中 492,620 个可以抓取，只有 21.3% 成功加载，去重后仍有 78.7% 无法打开。这个结果甚至高估了真正保存下来的内容，因为登录墙、广告停放域名和"内容已不可用"提示都被算作成功加载，HTTP 响应存在并不代表原始页面仍然存在。

在不同 URL 的层面，55.0% 经第二个网络重试后依然死于连接或 DNS 等网络层问题，23.7% 返回 HTTP 错误；其中 76,403 个 URL 返回 404，另有 29,663 个返回 403 或 429。后两种状态可能意味着网站只是在阻止自动抓取，因此研究者谨慎地把总体结论表述为"无法加载"，没有断言所有页面都已经消失。域名层面的结果同样严峻：133,605 个可抓取主机名中，只有 34,827 个至少有一个 URL 能加载，其余 98,778 个没有任何可访问页面。

年度数据还揭示了原始链接数量可能怎样误导判断。2011 年有一个账户集中创建了 83,398 条指向 pelaphptutorials.com 的不同链接，使这一年按 URL 计算的失效率达到 92.5%；每个主机只计一次后，失效率降至 61.7%，几乎与 2010 和 2012 年一致。移除这批链接后，2011 年记录数会从 103,053 条降至 19,655 条，低于 2012 年的 23,148 条，因此原始短链接总量不能直接当作用户增长曲线。2013 和 2014 年的大部分记录在恢复的数据中属于匿名用户，而相关主机名约四分之三没有任何 URL 能够加载，也不能据此推断正常使用在 2012 年后突然崩溃。

这份数据库尤其记录了逐渐消失的马其顿语互联网。0.mk 是马其顿第一家 URL 缩短服务，用户曾大量分享 A1 Television、Utrinski Vesnik、Dnevnik 和 Vest 的内容；A1 Television 于 2011 年关闭，后三家报纸都在 2017 年停刊，数百篇地方新闻如今往往只能偶尔从 Internet Archive 找到。短链接本身因此比生产内容的新闻机构活得更久，也暴露了网络保存中最脆弱的一层：地址还在，地址所指向的公共记忆已经消失。

部分已消亡服务的域名今天仍会返回页面，更进一步说明"能加载"并不等于内容获救。用户曾把 Facebook 照片以 CDN 直链分享，835 条记录对应的 789 个 fbcdn.net URL 如今无一可用；PureVolume 已停止原有服务，却有 653 个不同 URL 中的 633 个能够返回页面，Google Code 也有 754 个 URL 中的 628 个仍会加载或跳转。大型集中式平台总体保存得更稳定，小型网站则更容易连同域名、服务器和上下文一起消失。

数据库还留下了早期网络文化的微型遗迹：0.mk 的第一条链接创建于 2009 年 7 月 14 日凌晨 3:52，目标只是某个 WordPress 博客的 CSS 文件，一生仅有两次点击；第二天有人把 `0.mk/localhost` 指向 `http://127.0.0.1/`，两次点击都把访问者送回自己的电脑。`0.mk/1` 用四个字符指向长达 63 个字符的 thelongestlistofthelongeststuffatthelongestdomainnameatlonglast.com，累计获得 10,415 次点击，但目标网站已经消失；最长目标 URL 则是一条 2012 年的 CodePen 测试链接，全长 38,753 个字符，查询参数反复写着 TRYING_THE_MAXIMUM_URL。另有 4,478 条记录指向 bit.ly、TinyURL 和 goo.gl 等其他短链接服务，形成双层依赖；Google 在 2025 年关闭 goo.gl 后，这些链条即使 0.mk 一端仍然工作，也会因为中间环节消失而断裂。与之相对，2009 年 7 月 15 日创建、指向 google.com 的 `0.mk/7` 已累计 95,999 次点击，17 年后仍可使用。

0.mk 当年于 2014 年关闭，是因为收入无法覆盖托管和维护成本，持续不断的垃圾链接、过滤工程与滥用举报审核也超出了三人业余团队的承受能力。到 2026 年，AI 已能承担大量开发、垃圾检测、滥用审查、客服和监控工作，团队因此恢复服务，并把这些历史链接部署到分布于 300 多座城市的边缘节点上。0.mk 的复活同时揭示了一个更普遍的事实：网络记忆的寿命既取决于内容价值，也取决于谁能长期承担域名、服务器、审核和维护成本，而过去十余年的资源集中化，正在决定哪些历史能够继续被访问。
