## TL;DR
增长策略的真正杠杆不在于把核心用户服务得更好——而在于识别那些"不像核心用户"却能驱动增长的五类边缘用户，且对其中任何一类的忽视都会留下实质性的商业缺口。

## 五类用户骨架

- **Power user（超级使用者）**：使用频率远超正常，是功能需求的最响亮来源，但存在"power user trap"——过度迎合他们会以牺牲核心用户体验为代价；反之忽视则可能流失高价值生态贡献者。
- **Viral user（病毒用户）**：通过口碑、UGC、社交分享、评价、推荐驱动外部增长；关键反直觉点：最具传播力的往往是**免费用户**，而非付费用户——因为高付费用户的高预期反而抑制了推荐意愿。SurveyMonkey 70%+ 的获客来自免费用户投放的问卷所携带的品牌曝光。
- **Champion（内部拥护者）**：在 B2B 场景中是 Power + Viral 的叠加——既深度使用产品，又在企业内部主动推广。Amplitude 的 Champion 特征是大量创建图表并分享给团队，形成数据文化扩散；区别于纯粹的消费者。
- **High-LTV user（高终身价值用户）**：带来最多收入的客户画像，即 B2B 里的 ICP（理想客户画像）；典型标准是员工数 200+、合同底线 $15K 以上。
- **Adjacent user（相邻用户）**：有产品使用意图但不符合核心用例，因现有产品定位或体验门槛而无法激活。成熟增长策略的核心任务之一是将相邻用户逐步纳入核心用户群——否则随时间推移受众扩张停滞，增长天花板提前出现。

## 隐藏限制
这五类用户相互不排斥——同一个人可以同时是 Viral user 和 Champion。文章框架实用但较浅：除了"识别"，如何系统性地为每类用户设计不同的产品路径与留存机制，作者并未展开。Adjacent user 章节引用 Bangaly Kaba 的框架但未给出量化识别方法。

## 最值得带走的判断
Viral user 最可能是免费用户这一发现，直接撬动了"付费用户才是增长引擎"的惯性假设——意味着 freemium 模型的价值被严重低估在许多公司的增长账里。
