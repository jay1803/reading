## TL;DR
过去六个月 LLM 的真正拐点不是“最强模型”频繁换榜，而是 coding agents 跨过了可日用的质量门槛；同时，开权重和本地可用模型的上限被重新估计，个人 AI 助手开始从玩具原型变成一种新计算形态。

## 核心主张拆解
- 2025 年 11 月是作者眼中的关键拐点：三大模型厂商之间的“最佳模型”位置在一个月内多次易手，从 Claude Sonnet 4.5 到 GPT-5.1、Gemini 3、GPT-5.1 Codex Max，再到 Claude Opus 4.5。
- 比模型榜单更重要的是 coding agents 的质量跃迁。OpenAI 和 Anthropic 在 2025 年大部分时间用可验证奖励强化学习提升代码能力，再配合 Codex、Claude Code 这类 agent harness，结果是代码代理从“经常能用”变成“多数情况下能用”。
- 这个变化的实用含义很大：开发者可以把 coding agent 当作日常工具，而不是把主要时间花在修正模型犯的低级错误上。
- 12 月到 1 月的假期实验潮说明，新模型激发了大量高野心项目，也暴露出一类过度兴奋风险：能快速做出复杂 demo，不等于这些项目真的有需求、质量或安全性。
- 2 月 OpenClaw 的爆发代表另一条主线：个人 AI 助手开始被重新想象为常驻的个人计算实体，而不是单次问答工具。
- 过去一个月的开放模型进展也很关键：Google Gemma 4 被作者视为美国公司迄今最强的开权重系列之一；GLM-5.1 是 1.5TB 级别的开权重模型，能力强但硬件门槛高。

## 关键时间线
- 2025-09-29：Claude Sonnet 4.5 发布，成为 11 月初的主流“最强模型”候选。
- 2025-11：GPT-5.1、Gemini 3、GPT-5.1 Codex Max、Claude Opus 4.5 相继改变前沿模型排序。
- 2025-12 至 2026-01：开发者集中试用新模型和 coding agents，出现大量短期实验项目。
- 2026-02：OpenClaw 以个人 AI 助手形态快速出圈；Gemini 3.1 Pro 展示更强的图像和动画生成能力。
- 2026-04：Gemma 4 和 GLM-5.1 推出，强化了“开权重模型正在超预期进步”的判断。

## 值得质疑
- “最佳模型”判断很大程度来自作者的实际体感和创意生成测试，不是严格 benchmark；它适合观察趋势，不适合当作精确排名。
- OpenClaw 和个人 AI 助手的热度更像早期开发者圈层信号，还不能直接推出大众市场已经成熟。
- GLM-5.1 这类超大开权重模型证明能力边界在扩大，但 1.5TB 体量意味着它与“普通人本地运行”的叙事仍有距离。

## 最后一层意义
LLM 竞争的中心正在从单个聊天模型转向“模型 + agent harness + 本地资产 + 长驻运行环境”的组合能力；谁能把模型变成可靠的日常执行系统，谁才真正吃到这一轮进步。
