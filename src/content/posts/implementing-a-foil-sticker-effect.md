## TL;DR
这篇文章给出一套实时可跑、可控、视觉上可信的 foil sticker 着色方案：用视角驱动的虹彩变色、程序化金属闪片和可剥离几何形变，在 Three.js 里重建贴纸那种昂贵、会“活起来”的质感。核心做法是把问题拆成两层：顶点阶段负责“贴纸怎么翘起来”，片元阶段负责“表面怎么发光、怎么变色、哪里会闪”，于是效果既便宜、可调，又能抓住观众最敏感的视觉线索。

## 关键洞察
虹彩是第一层关键错觉。真实世界里的彩虹反光来自薄膜干涉，但实时图形没必要逐项解那套物理；只要让颜色随视角连续漂移，观众就会把它认成全息箔。实现上用视线与法线的夹角得到 cosTheta，再把它映射成一组相位错开的正弦波生成彩虹色，并用 uIriMin / uIriRange 控制“膜厚”区间，用 uIridescence 控制强度。这里保留的是现象级真实感：表面一转动，颜色就活起来。

金属闪片是第二层关键错觉。foil 的高级感很大程度上来自大量细小、离散、会跳动的高光；过于平滑的镜面反而像塑料覆膜。实现上在 UV 空间里用 hash 噪声生成 flake mask，用亮度阈值把闪片更多限制在更亮、更像金属的区域，再轻微扰动法线重算反射方向，让每个 flake 都有不同的 sparkle 角度；最后叠加 flakeSpec 和 phaseMod，保证它们会闪、会跳，但不会整片一起死亮。这样得到的是“颗粒化的贵”，比单纯加大 specular 更像真实箔面。

几何层面，贴纸被建模成沿对角线掀起的一块薄片。顶点着色器以 hinge 为支点，根据 UV 位置算出 peelFactor，再把 peel angle、peel amount 和 per-vertex factor 相乘，得到每个顶点各自的旋转角度；旋转本身用 Rodrigues 公式完成，所以能绕任意轴平滑弯起，而不是只有僵硬的翻折。法线也按同样方式旋转，保证光照与形变一致；顶点位移距离被记成 vAOIntensity，后面可拿来做 lifted area 的假 AO，也可让背面在揭起更高时显得更暗，于是“正在被撕开”的立体感成立。

片元阶段把这些线索拧成一个统一材质。先做 alpha cutoff，避免透明区域继续参与昂贵计算；背面只渲染成白色并按剥离强度适度变暗，把预算集中在正面。正面则把环境贴图反射、Fresnel–Schlick、虹彩、金属度、粗糙度和 flakes 叠加起来：粗糙度决定环境反射的 LOD，Fresnel 让掠射角反光显著抬高，iridescence 给反射染上随角度变化的色偏，flakeEnv 把局部闪片的环境颜色混进去。最终颜色由 diffuse + spec 组成，先决定哪里像印刷基底，再决定哪里像金属箔层。

颜色空间是另一个决定成败的细节。网页贴图通常是 sRGB 编码，如果不先转线性空间就直接做光照，高光会发灰，中过曝，中间调也会变脏。所以 base texture 先做 sRGB -> linear，所有 shading 在 linear space 里完成，最后再编码回 sRGB。这个步骤没有噱头，却直接决定前面那些 Fresnel、反射和虹彩叠加之后看起来是清亮的金属质感，还是廉价的假特效。

整套方法的重点是“视觉上可信”而不是“物理上完整”。它借用 PBR 的 metalness、roughness 和 Fresnel 作为稳定控制旋钮，却把目标放在可调参、可艺术指导、可实时渲染的结果上；对于浏览器里的展示、包装 mockup、数字藏品或交互玩具，这种取舍比追求严格物理正确更实用。

## 一句话总结
foil sticker 的说服力来自几种廉价错觉的精确叠加：视角变色负责全息，随机闪片负责金属，剥离形变负责物体性，Fresnel、环境反射和正确的颜色空间把它们粘成一个成立的材质。
