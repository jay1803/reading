## TL;DR
让人无法"忘记"设置下一个计时器的方法，不是加强提醒，而是把"不设置"变成一个需要主动做出的决定——屏幕会自动变模糊，直到你作答为止。

## 核心洞见
习惯失效的常见原因不是动机不足，而是"遗忘路径"阻力太低。普通计时器提醒一次后就闭嘴；这个计时器要求你主动关闭才能恢复正常屏幕——把默认值从"需要记得设置"改为"需要决定不设置"，反转了意志力的方向。

## 具体机制
- 每次计时结束弹窗问"接下来专注什么"，迫使行动前先命名意图
- 若不作答，屏幕逐渐模糊直至无法工作；作者称从未主动选择关闭它
- 计时间隔可调（3–30分钟）：开放性任务用短间隔收紧注意力，进展顺畅时可拉长至30分钟
- 不抢占键盘焦点（保证正常工作不被打断），但出现在 Dock 中支持 Cmd+Tab——让"提醒"与"打断"解耦

## 设计副产品
作者用 Cursor / Claude Code 边构建边迭代，绕过了传统 Figma 原型→用户测试流程：AI 编程工具压低了"可用功能软件"与"草图"之间的成本差距，使真实产品可以直接替代纸原型做验证。

## 工具在训练人，而不只是提醒人
作者注意到，随时间推移不只是跑偏被更早捕捉，跑偏本身也在减少——强制中断逐渐内化成主动思考。这意味着该工具的价值是复利型的，不是线性的。
