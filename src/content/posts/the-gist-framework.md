### GIST
Not every metrics are matters.
2 types of metrics:
- Impact Metrics
  - Revenue
  - Number of Customers
  - Number of Active Users
  - North Star Metric
- Outcome Metrics
  - Funnel metrics
  - User behaviors
  - System performance
  - Quality metrics

User Value will help you reach the North Star Metric
Business Value will help to reach the Top Key Performance Indicators

#### North Start Metric Examples
- Facebook: Daily Active User
- Whatsapp: Send Messages
- YouTube: Minutes watched
- Airbnb: Nights booked
-eBay: GMV
