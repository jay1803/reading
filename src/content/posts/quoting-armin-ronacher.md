## 摩擦是团队隐性语言的同步协议，agent 正在移除它

Armin Ronacher 的核心论点：软件项目真正的共同语言不是 Python 也不是英文，而是对系统边界、不变量、所有权和架构动机的集体隐性认知。这套知识几乎从不集中记录——它活在代码审查、争论和向别人解释改动的过程中。

Simon Willison 指出的结构性风险：在 agent 出现之前，修改别人的模块需要读代码、提问、协调依赖方。这些摩擦中有一部分是浪费，但另一部分是"你的理解变成我的理解"的传输机制——它在同步人，让团队持续校验彼此对系统的认知是否仍然一致。

Agent 可以绕过这整套流程。问题没有被显式回答：当摩擦被消除，谁来维护那套隐性共识？效率提升与集体认知扩散之间，存在一个至今没有答案的取舍。
