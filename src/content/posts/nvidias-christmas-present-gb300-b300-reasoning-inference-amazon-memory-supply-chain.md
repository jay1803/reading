## TL;DR
Nvidia 计划在 GB200 和 B200 发布仅 6 个月后，推出全新的 GB300 和 B300 GPU。B300 GPU 在台积电 4NP 工艺节点上进行了全新的流片，计算裸片设计经过调整，与 B200 相比，产品级 FLOPS 提升 50%。GB300 和 B300 的内存容量将分别提升至 288GB，但内存带宽保持不变。这些改进主要针对推理模型推理和训练性能的提升。由于超大规模数据中心可以更多的自定义设计，GB300 的供应链也发生了巨大变化。
### 主题
#### B300 & GB300 – 不仅仅是增量升级
B300 GPU 是在 TSMC 4NP 工艺节点上的全新流片，计算裸片设计经过调整。
- 与 B200 相比，B300 产品级 FLOPS 提升 50%。
- GB300 和 B300 HGX 的 TDP 分别为 1.4KW 和 1.2KW（GB200 和 B200 分别为 1.2KW 和 1KW）。
- 性能提升的其余部分来自架构增强和系统级增强，例如 CPU 和 GPU 之间的功率动态分配 (Power Sloshing)。
- 内存从 8-Hi HBM3E 升级到 12-Hi HBM3E，每个 GPU 的 HBM 容量增加到 288GB。
- 内存引脚速度保持不变，内存带宽仍为每个 GPU 8TB/s。
- 三星至少在未来 9 个月内无法进入 GB200 或 GB300 的供应链。

#### 专为推理模型推理而设计
内存的改进对于 OpenAI O3 类型的 LLM 推理训练和推理至关重要，因为长序列长度会增加 KVCache，从而限制关键批处理大小和延迟。
- 从 H100 到 H200（仅升级了更多、更快的内存），有两个影响：
  1. 由于内存带宽增加（H200 为 4.8TB/s，H100 为 3.35TB/s），所有可比较的批处理大小的交互性通常提高 43%。
  2. 由于 H200 运行的批处理大小比 H100 大，因此成本降低了约 3 倍，每秒可生成 3 倍的 token。这种差异主要是因为 KVCache 限制了总批处理大小。
- 更多的内存容量提供了巨大的好处：
  1. 推理模型可以提供更快的推理时间，这将增加用户使用和付费的倾向。
  2. 3 倍的成本差异是巨大的。
  3. 最强大和差异化的模型能够比性能稍差的模型收取更高的溢价。
- Nvidia 并不是唯一可以增加内存容量的公司。ASIC 可以做到这一点，事实上，AMD 可能由于其相对于 Nvidia 更高的内存容量而处于有利地位，MI300X 为 192GB，MI325X 为 256GB，MI350X 为 288GB。
- Nvidia 的 NVLink 是一个关键优势。
- 当升级到 GB200 NVL72 和 GB300 NVL72 时，基于 Nvidia 的系统的性能和成本大幅提高。在推理中使用 NVL72 的关键点在于，它使 72 个 GPU 能够以极低的延迟处理相同的问题，共享内存。
- Nvidia 的 GB200 NVL72 和 GB300 NVL72 对于实现许多关键功能非常重要：
  1. 更高的交互性，从而降低每个思维链的延迟。
  2. 72 个 GPU 分摊 KVCache，以实现更长的思维链（提高智能）。
  3. 与典型的 8 GPU 服务器相比，批处理大小扩展更好，从而降低成本。
  4. 更多样本可用于处理相同问题，以提高准确性和模型性能。
- 因此，NVL72 的 token 经济效益提高了 10 倍以上，尤其是在长推理链上。

#### 为 GB300 重新设计的 Blackwell 供应链
对于 GB300，Nvidia 提供的供应链和内容发生了巨大变化。
- 对于 GB200，Nvidia 提供整个 Bianca 板（包括 Blackwell GPU、Grace CPU、512GB LPDDR5X、VRM 内容，全部集成到一个 PCB 上）以及交换机托盘和铜背板。
- 对于 GB300，Nvidia 将只提供 B300 的“SXM Puck”模块、BGA 封装的 Grace CPU 以及 HMC（将来自美国初创公司 Axiado，而不是 GB200 的 Aspeed）。
- 最终客户将直接采购计算板上的其余组件，第二层内存将是 LPCAMM 模块，而不是焊接的 LPDDR5X。美光将成为这些模块的主要供应商。
- 交换机托盘和铜背板保持不变，Nvidia 完全提供这些组件。
- 转向 SXM Puck 为更多 OEM 和 ODM 参与计算托盘提供了机会。
- 另一个重大转变是 VRM 内容。虽然 SXM Puck 上有一些 VRM 内容，但大部分板载 VRM 内容将由超大规模数据中心/OEM 直接从 VRM 供应商处采购。
- Nvidia 还提供 GB300 平台上的 800G ConnectX-8 NIC，在 InfiniBand 和以太网上提供两倍的横向扩展带宽。
- ConnectX-8 相比 ConnectX-7 有了巨大的改进，不仅带宽翻倍，而且 PCIe 通道也从 32 条增加到 48 条。

#### GB300 对超大规模数据中心的影响
延迟的 GB200 和 GB300 对超大规模数据中心的影响意味着，从第三季度开始的许多订单将转移到 Nvidia 新的、更昂贵的 GPU 上。
- 部分原因是 GB300 由于更高的 FLOPS 和更多的内存而提高了性能，但也有一部分原因是能够控制自己的命运。
- 由于上市时间挑战以及机架、冷却和电源/密度的重大变化，超大规模数据中心不允许在服务器级别对 GB200 进行太多更改。
- 现在有了 GB300，超大规模数据中心可以定制主板、冷却等。这使亚马逊能够构建自己的定制主板，该主板采用水冷，并集成了以前风冷的组件，例如 Astera Labs PCIe 交换机。
- 一个很大的缺点是，超大规模数据中心必须设计、验证和确认更多的东西。这可能是超大规模数据中心有史以来设计过的最复杂的平台（除了谷歌的 TPU 系统）。

### 总结
Nvidia 推出的 GB300 和 B300 GPU 带来了显著的性能提升和供应链变化，特别是在推理模型方面。
