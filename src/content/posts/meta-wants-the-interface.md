Meta 正试图通过 Muse 占据消费者表达意图、比较选择并完成交易的入口，将商业控制力从应用内的注意力延伸到整个互联网的决策过程。9 月 8 日推出的 Muse 目前仅在美国和加拿大开放，Sensor Tower 统计其下载量已超过 340 万，并登上美国应用商店榜首。产品负责人 Nat Friedman 表示，它深受 OpenClaw 启发：用户交付目标，agent 负责理解需求、调用服务并代为行动。Google 聚合信息、Meta 聚合社交注意力、Amazon 聚合购物需求之后，Muse 争取聚合的是这些活动更上游的**消费意图**。

Muse 的关键在于把记忆、情境理解、执行能力和 Meta 的分发渠道结合起来，并跨越自家应用边界。它可以把 Instagram 上保存的食谱变成采购清单，记住朋友的饮食禁忌，安排聚餐并发送邀请；同一套能力还能用于跨平台比较商品、规划旅行和预订餐厅。当这些服务持续掌握用户背景、在需要时接续执行，Muse 就开始成为覆盖其他应用的个人操作层，削弱用户逐一打开网站、搜索和点击的必要性。

Meta 正通过硬件把这一入口推进到意图产生的现场。Muse 将进入 AI 眼镜，根据用户看到的商品、餐厅或地标提供帮助，甚至直接协助购买；Meta 预计到年底，Ray-Ban、Oakley 和 Meta Glasses 合计将提供超过 100 种眼镜选项。Zuckerberg 同时发布了掌心大小、外形类似 Tamagotchi 的 Muse Charm，让未佩戴眼镜的用户无需解锁手机也能与 agent 对话，计划在假日季出货。OpenAI 正与前 Apple 设计负责人 Jony Ive 筹备首款消费设备，Meta 因而也在争夺随时可用的实体 AI 入口。

这一布局的商业回报可以直接来自交易。Muse 对大多数用户免费，同时提供每月 20 美元和 100 美元的高用量订阅，Meta 还计划从促成的交易中收取小额费用。只要控制购买前的决策入口，即使商家、支付和履约均由其他公司提供，Meta 仍能参与收益分配。公司目前承诺，Muse 对话及其虚拟机内的数据不会共享给广告系统；这一承诺并未排除未来在用户许可下引入商业合作，或通过合作伙伴的广告与交易基础设施变现。

Amazon 封锁 Muse 在 Amazon.com 上购物，反映出它最需要保卫的是购买发生前的发现过程。用户若让 Muse 寻找"适合长途飞行、价格低于 300 美元的最佳降噪耳机"，agent 可以先完成评论研究、规格比较和推荐，再把订单交给 Amazon。Amazon 仍可能获得销售收入，却失去搜索广告、赞助商品曝光、商品发现和追加购买机会。2025 年，Amazon 广告收入达到 686 亿美元，同比增长 22%，较 2021 年翻倍以上，且比订阅收入高近 190 亿美元；同年非 AWS 业务营业利润为 344 亿美元。Amazon 没有披露广告利润率，但这些数据支撑了文章的推断：高利润广告可能承担了零售与物流业务相当大的一部分盈利，剥离广告后，底层业务存在亏损的可能。

外部 agent 还可能改变零售商每笔交易的收益。据报道，Walmart 通过 OpenAI Instant Checkout 获得的购买转化率约为直接购物渠道的三分之一，购物篮也更小。如果 agent 减少了追加购买，商家又要支付佣金、固定导流费或推荐位费用，利润分配就必须重新谈判。Amazon 的仓储、运输、库存布置和最后一公里配送网络仍然难以被 AI 替代，但这套高固定成本体系依赖订单规模摊薄成本；agent 若把部分需求转向 Walmart 或其他零售商，也会侵蚀其履约效率。

企业对 agent 的态度，取决于利润来自价值链的哪一层。Shopify 希望商家和 Shop Pay 出现在消费者选择的任何购物入口，PayPal 则向 Muse 开放商家网络，两者都不依赖一个充满广告的自有搜索界面，因此更愿意接受 Meta 掌握前端。Walmart 作为电商市场的追赶者，也有动力用部分界面控制权换取原本可能流向 Amazon 的需求；Muse 不打算自行掌握结账环节，又降低了合作阻力。依赖发现与推荐赚钱的平台防御动机更强，依赖交易处理、商家服务和基础设施赚钱的企业则更容易从开放中获益。

广告价值也会随决策入口迁移。Amazon 广告主已经可以在 ChatGPT 对话中触达用户，使 Amazon 得以向站外扩展广告业务，OpenAI 则变现对话中产生的消费意图。Muse 同样可能容纳此类合作。竞争焦点将逐渐从争取人类点击，转向**进入 agent 的候选集合**：准确的商品数据、实时库存、价格、履约能力和可信商家关系，会影响 agent 是否考虑并推荐某个选项，部分承接搜索流量的网页和广告位则可能失去价值。

这一变化还会冲击依赖消费者惰性的行业。聊天机器人可以提醒用户储蓄账户利率过低，agent 则能进一步识别闲置资金、比较收益并转移余额；保险和券商账户也面临相同机制。当发现更优选项与实际切换之间的摩擦下降，企业维持低待遇客户的能力就会减弱。对银行而言，这一影响最终需要由更高的存款成本和更频繁的客户余额迁移来验证。

用户操作的减少，同时意味着后台计算工作的增加。一次传统搜索只需若干查询与点击，agent 完成同一目标却可能反复规划、检索、比较、调用工具、检查结果并执行交易；如果它持续在后台研究和沟通，每位用户带来的推理负载还会扩大。Meta 为 Muse Realtime Avatar 重构实时推理系统，以持续生成同步语音和视频，并称优化后服务容量提高至原来的 8 倍，单颗 GB200 可同时支持 12 路视频会话，延迟低于一秒。这展示了持续交互对计算效率和系统架构的要求。

因此，agent 带来的基础设施需求会超出训练大模型所依赖的 GPU。持续推理与任务编排还需要 CPU 处理数据检索、工具调用和企业服务衔接，需要更大的系统内存承载模型上下文、外部数据与工具输出，也需要网络和高速互连。文章以 AMD 的高核心数 EPYC 服务器 CPU 为例，说明 agent 工作负载如何拓宽受益范围；作者同时披露 AMD 是其最大持仓，这一投资立场需要与技术判断分开看待。整条经济链的变化是：模型之上，agent 压缩用户接触的网页、搜索和广告界面，并重新分配决策权；模型之下，完成这些被隐藏的工作需要更多计算、内存、通信、支付和交易基础设施。
