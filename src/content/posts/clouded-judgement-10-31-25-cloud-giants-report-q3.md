## TL;DR
三大超大规模云厂商 Q3 全部加速（AWS 20%、Azure 39%、Google Cloud 34%），且一致声称供给而非需求是瓶颈——GPU 上线即被消化，没有"暗光纤"风险，有的只是建造速度的竞赛。

## 核心数据与机制
- AWS $132B run rate，增速从 17% 升至 20%；Trainium2 季增 150%，已是数十亿美元业务，Bedrock 多数 token 跑在自研芯片上；管理层将 Bedrock 定位为下一个 EC2 规模的推理引擎。
- Azure AI 算力今年扩张 80%+，全球首批部署 NVIDIA GB300；软件优化使 GPT-4.1/5 每 GPU 吞吐提升 30%+；OpenAI 与微软续约至 2030–2032，签下 $250B 新 Azure 用量，AGI 到来之前 Azure 为独家云。
- Google CapEx 从 $85B 上调至 $91–93B，2026 年将"大幅增加"；Gemini API 每分钟处理 70 亿 tokens；AI overviews 带来搜索查询增量而非蚕食存量；Anthropic 承诺最多使用 100 万 TPU。

## 打破的预期
市场广泛担忧 CapEx 过剩和需求软化；但三家均报告需求持续超供，Google 明确将 34% 增速和 46% QoQ 积压跳升直接归因于企业 AI 需求，并预计供需紧张延续至 2026 年。

## 值得质疑
"算力即护城河"逻辑仅在需求无弹性时成立。文章未呈现的风险：大量 CapEx 转化为利润率的时间表不明，Trainium2 "150% QoQ 增长"和"数十亿美元"的说法均基于低基数，实际 margin 结构未披露，**证据薄弱处**在于作者未对三家的增量利润率做任何测算。

## 收束行
Anthropic 是这场军备竞赛的结构性奇点：AWS 为它建了 50 万片 Trainium2（年底扩至 100 万），Google 让它承诺 100 万 TPU——同一家公司同时成为两个直接竞争对手定制硅战略的最大外部客户；这个谈判筹码比任何一家云厂商的增速数字更值得长期追踪。
