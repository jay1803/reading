## 概述

这篇文章比较了 Windows NT 和 Unix 的设计。作者的主要问题是探究 Windows NT 是否比 Unix 更先进，并比较了二者在设计上的关键差异。作者的观点是，NT 在推出时具有许多先进特性，但如今与现代 Unix 系统相比，其优势已不再明显。

## 主题

- 🏛️ 对象导向内核：NT 是一个对象导向的内核，所有内核对象都在一个统一的命名空间中。这提供了集中访问控制和通用标识。而 Unix 尝试将非文件对象放入文件系统，如 /proc/ 和 /sys/，但与 NT 相比，这些更像是事后补充。

- 🤝 统一事件处理：NT 中所有对象类型都有一个信号状态，可以在用户空间中编写事件驱动代码。这使得可以轻松地等待一组对象的状态变化，无论它们是什么类型。而在 Unix 系统中，同时等待 I/O 和进程完成是很困难的。

- 💽 I/O 子系统：NT 的 I/O 子系统从一开始就是异步的。NTFS 在其时代是一个非常先进的文件系统，具有 64 位寻址、日志记录和 Unicode 文件名。相比之下，Linux 直到 2001 年才通过 ext3 获得日志记录。

- 🧵 线程支持：NT 从一开始就支持线程，这对于 SMP 机器上的高性能计算至关重要。而许多 Unix 系统是在现有设计中改造线程的，例如 Linux 在 1996 年的 2.0 版本中将线程表示为进程。

- 🛡️ 安全性：NT 从一开始就具有先进的安全设计，基本上是一个基于能力（capability-based）的系统。用户进程从内核获取一个访问令牌，代表用户会话的权限。这与 Unix 不同，Unix 进程只有标识符，内核需要在进程表中跟踪每个进程可以做什么。

- 🌐 网络支持：NT 从一开始就支持网络功能，同时支持 Internet 协议和传统的 LAN 协议。NT 提供了集成的目录和身份验证功能的域，这比 Unix 更容易设置。NT 还具有内置的 RPC 支持。

- 💻 硬件抽象层 (HAL)：NT 的一个关键组件是 HAL，它提供了访问机器硬件的抽象原语。这使得 NT 可以运行在各种架构上。相比之下，当时的 Unix 系统通常与特定架构耦合。

- ⚙️ 注册表：NT 将系统和应用程序配置集中在一个称为注册表的数据库中。这与 Unix 不同，Unix 仍然受到数十种 DSL 和不一致文件位置的困扰。

- 🌍 国际化：NT 从一开始就支持本地化。相比之下，Unix 直到 20 世纪 90 年代末才开始出现 UTF 支持，并通过可选的 gettext 附加组件支持不同的语言。

- 🔄 统一内存架构: NT 从一开始就采用了统一的内存架构。而较早的 Unix 实现具有用于文件系统和虚拟内存的单独内存缓存。
