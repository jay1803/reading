## TL;DR
作者 Brie Wolfson（Colossus CMO，曾任职 Stripe 和 Figma 早期）以"嵌入式观察者"身份在 Cursor 待了 60 天后写下的公司文化报告。Cursor 此时约 250 人，估值已达百亿美元级别，从 $0 到 $100M ARR 没有一个销售团队。这篇文章不是产品介绍，而是对一家公司如何在极短时间内维持高密度人才和创业激情的细节还原。

### 办公室：刻意的反企业感

Cursor 总部在旧金山 North Beach，门口没有 Logo，墙上没有宣传海报，书架上满是实际被翻过的书。家具来自一个湾区的欧洲复古家具收藏者。黑板代替白板，公司总裁 Oskar 会告诉你他从哪里买到最好的粉笔。

每天下午 1 点，厨师 Fausto 做午饭，全公司在公共餐桌聚餐，饭桌上几乎只谈工作——但是那种充满好奇心的"工作"，不是汇报。甚至 Fausto 本人现在也在 Slack 里和员工互动，有人给他做了一个 AI 菜单生成器，帮他应对团队快速扩张的压力。

86% 的员工在旧金山或纽约的实体办公室工作。公司明确保护深度工作时间，几乎没有例行会议，Slack 消息和会议都没有拍肩膀可靠。

### 招聘：以人为原子单位，而非职位

大多数公司的招聘逻辑：发现能力缺口 → 开职位 → 找候选人 → 录用一个。

Cursor 的招聘逻辑：在 =#hiring-ideas= channel 里贴一个人的名字 → 全公司围猎 → 如果双方意向一致，周一就入职。

几个典型案例：
- Eric Zakariasson：在斯德哥尔摩办 Cursor 工作坊，被发现
- Ian Huang：用户遥测显示他深夜疯狂用 Cursor 写代码，被发现
- Lukas Möller：创始人飞德国两次才把他带回旧金山
- Jordan MacDonald：六个月咖啡聊天没松动，最后一台手工送上门的咖啡机拿下

录用率极低，每一个 offer 都需要管理层签字。公司里有 50 位前创始人，超过 1/5；近 40% 来自 MIT、哈佛、斯坦福、CMU 等顶校，但没人谈自己上过什么学校。

女性工程师和产品人比例不足，这是明确的 P0 问题。

### 人才密度的结果：没有明显的不胜任

作者观察到一个现象：Cursor 办公室里几乎看不到"明显的不胜任"。每个人都以高度自信完成自己的工作，不是表演出来的，是因为确实能做到。

一个例子：楼梯很陡，没有扶手。有人问为什么，答案是："人们知道怎么走楼梯。"

IC（Individual Contributor）是公司最高身份。联创 Aman Sanger 本人至今是 IC，每天在角落里写代码，几乎不被打扰。一个新入职的销售说：在上一家公司，30 天后才被允许跟客户通话；在 Cursor，不到 30 小时就上了。

### 工作节奏：不是 996，是热爱

外界流传 Cursor 执行 9-9-6（早九晚九，每周六天），这不是事实。没有任何工时强制要求，但相当一部分人因为热爱而自发工作很长时间。

节奏是感染性的：如果同事都在快速推进，你也会。作者承认自己在 Cursor 也在周末和深夜工作，"主要是因为自己想，也想让优秀的同事刮目相看。"

新员工的前几周通常会有种"喘不过气"的感觉，但一旦意识到这种高期望来自于公司对自己能力的高度信任（严格招聘的副产品），恐慌会转化为自信。

### Dogfooding（吃自己的狗粮）

Cursor 团队人均使用 Cursor 的时长可能全球最高，唯一的潜在竞争者是 Apple 和他们的 Mac/iPhone。

产品路线图因此是高度自下而上的。想要某个功能存在，是构建它最好的理由。Tab、CmdK、Agent、Bugbot、Background Agent 这些核心功能都是这样诞生的。

=#braintrust= channel 是全员 Slack 频道，用 emoji 投票决定功能去留。真实案例："cmd k – edit full file – 🟢=删除 / 🔴=我在用，保留"。

团队内部使用的 Cursor 版本比公开版本提前约三个月，用来测试、打磨新功能。GTM 团队同样用 Cursor 构建网站更新和内部工具，=#built-with-cursor= 频道里有拼板球场占用追踪器、婚礼网站、Metguessr（用大都会艺术馆藏品玩的 GeoGuessr）等。

### Fuzz：一起拆掉它

每次大版本发布前，产品负责人在 Slack 发消息，全公司聚到地下室，安静坐下，用一小时疯狂尝试让产品崩溃，把发现的 bug 和 UI 问题发到 Slack。

没有强制要求参与，但大家都来，因为有真实的主人翁感：你在 Cursor 里全天写代码，你不想它有 bug。

### 建设性摩擦：挑剔是文化

在 Cursor，大家会频繁指出彼此工作中的问题，而且不掩饰。创始人 Michael 鼓励在全员 Q&A 上问"辛辣问题"，Sualeh 会 DM 人"你现在在担心什么？"

作者借用前同事在 Stripe 发明的词："micro-pessimist, macro-optimist"（微观悲观，宏观乐观）——对执行细节极度挑剔，对整体方向高度乐观。

这种文化不会变成有毒文化，是因为批评者同时是问题解决者；没有人把挑刺当作一项运动，所有人都真心希望产品和彼此变得更好。

Michael 被问到想让公司感觉像什么时，他举了 The Beatles 纪录片 /Get Back/ 的例子——三周 deadline，全员关进录音棚，手一直放在乐器上，感觉摸索，直到做出 /Let It Be/。伟大是在日常的碰撞中产生的。

### 天花板策略：只服务最好的开发者

Cursor 明确将目标用户定位为"最顶尖的专业软件开发者"，而不是"任何想写代码的人"。这在市场上有些争议，因为有大量非开发者职位的人也在用并喜爱 Cursor。

公司的立场：别的公司去拉低门槛，Cursor 专注抬高天花板。

逻辑：你的用户会把你的产品拉向某个方向。Cursor 想被拉向顶尖匠人的方向，而不是泛大众的方向——这样才能真正改变软件构建的方式，而不只是做渐进式改进。

### 使命才是奖励

公司从 $0 涨到 $100M ARR，bot 在 Slack 通知全公司，大家用了几个 ♥️，然后继续工作，"办公室里的对话照常进行"。

作者在 Cursor 这几个月里，没有听到任何人谈论"发财之后要买什么"——在 Stripe 和 Figma 早期，这是员工最爱的饭桌话题。在 Cursor，没人谈。

原因可能是：如果明天就可以退休，大多数人做的事还是现在在 Cursor 做的事。

## 总结
Cursor 的核心竞争力不是产品功能，而是一种文化配方——极高的人才密度 + IC 至上的组织结构 + 以使命而非财富为驱动力 + 建设性摩擦作为日常运转方式。这种文化在 Stripe 和 Figma 早期也出现过，但 Cursor 在更短时间内、更有意识地在构建它。最大的风险是：商业上的早期成功可能反而会稀释这种文化。
