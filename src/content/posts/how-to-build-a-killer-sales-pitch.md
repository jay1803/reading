### 概述
这篇文章是关于如何构建一个出色的销售演讲。作者认为，许多 B2B 销售演讲都是产品功能演示，未能帮助潜在客户做出购买决策。作者提出了一种两部分的销售演讲结构，包括“setup”和“follow-through”，以帮助客户了解整个市场并与销售方的观点保持一致，从而做出更自信的购买决策。
### 主题
- 📉 客户决策困难：B2B 购买过程中，40% 到 60% 的情况最终结果是“不做决定”。
因为 B2B 购买决策的风险很高，决策者更害怕犯错，而不是错失机会。一个糟糕的决定可能会对公司和个人产生负面影响。

- ⚙️ 销售演讲的两个部分：销售演讲结构由“setup”和“follow-through”两个主要部分组成。
“setup”让客户了解整个市场并与销售方的观点保持一致。“follow-through”侧重于销售方的差异化价值以及如何实现这种价值。

- 🤔 市场洞察：市场洞察是销售演讲中至关重要的一步。
市场洞察是销售方对市场的看法，它将销售方与竞争对手区分开来。市场洞察帮助客户理解为什么销售方的差异化价值很重要。

- 🆚 替代方案：在销售演讲中，要讨论替代方案的优缺点。
销售方不针对特定产品，而是针对实现目标的方法。这可以帮助客户了解整个市场，并建立销售代表的可信度。

- 🌍 完美世界：在讨论了替代方案的优缺点之后，销售方会问“对于像您这样的客户，完美的解决方案是什么样的？”。
如果潜在客户同意销售方对完美解决方案的描述，那么销售就已经成功了。如果客户不同意，销售方应该取消他们的资格，因为没有东西可以卖给他们。

- 💼 案例研究：销售演讲的“follow-through”部分包括展示案例研究示例。
案例研究可以展示客户忠诚度和收入的改善。案例研究应该强调投资回报率和对业务的影响。

- 🤝 跨职能团队合作：作者提倡跨职能团队合作进行销售演讲。
产品、销售和市场团队共同参与，可以更好地了解产品、客户和市场。这有助于创建一个在整个买家旅程中更一致的故事。

- 🚀 Help Scout 案例：Help Scout 的观点是，客户服务是增长动力，而不是成本中心。
许多 Help Scout 的客户最初使用共享电子邮件收件箱进行支持。随着业务增长，客户需要更高级的功能，如优先级和分配。Help Scout 将竞争解决方案分为“共享收件箱”和“传统帮助台”。

- 🔗 Postman 案例：Postman 的观点是，拥有多个团队使用不同的工具进行 API 开发、测试和文档编写是非常低效的。
低质量和难以使用的 API 会对客户体验和收入产生负面影响。公司必须快速交付易于使用的高质量 API。
