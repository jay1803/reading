## TL;DR
增长的下一个战场不是社交推荐，而是让 AI agent 推荐你——一个人只需对 agent 说一次"用 Vercel"，这条指令可能驱动数千次自动交易，超过传统百次口碑推荐。

## 四个循环的拆解
作者把推荐路径分成四层：Human→Human（传统口碑）、Agent→Human（GEO，让大模型搜索推荐你）、Human→Agent（H2A，让人类把你写进 agent 的偏好配置）、Agent→Agent（A2A，agent 之间自主协商与推荐）。前三层是现有逻辑的延伸；A2A 才是真正的结构性断裂——没有人类在回路，agent 之间基于信任网络直接交换厂商偏好，速度最快、价格最低、数据最全者胜出。品牌进入 =preferences.md= 的位置越靠前，获得的机器流量越呈指数增长。

## 兼容性成为新护城河
一个被低估的点：agent 推荐的前提是 agent 能访问你。被 CAPTCHA、2FA、不兼容 API 拦住的品牌，即使口碑再好也进不了 A2A 网络。MCP 接入能力、agent 友好的 API 设计，会成为与价格和品牌并列的核心竞争要素。

## **证据薄弱处**
A2A 的"主动推荐"场景（agent 自发通知其他 agent 切换平台）目前完全是推演，无实证基础；文章对话示例接近科幻。"2028 年 10 亿 agent"引用的是微软 Copilot 公告，定义宽泛，不等于具有购买决策能力的自主 agent。

## 边缘判断
这篇文章真正有价值的不是四个循环框架，而是一个具体的行动优先级翻转：现在大多数公司还在优化 SEO，但更紧迫的事可能是检查自己的产品对 agent 是否可穿越。
