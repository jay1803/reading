## TL;DR
投资者败给市场，根本原因不是策略不够好，而是看不懂策略在做什么——关键时刻失去信任、乱动，才是亏损的真正来源。策引（MyInvestPilot）因此选了反主流路线：AI 只当翻译器，把自然语言意图翻译成可执行的结构化 DSL，引擎来做决策；策略透明可理解，才是执行纪律的前提。

## 核心洞见
- **为什么放弃代码**：AI 生成 Python 有三个致命问题：幻觉（import 不存在的库）、前视偏差（look-ahead bias，回测漂亮实盘崩溃）、不可复现（同一意图每次生成的实现结构完全不同）；沙盒隔离的运营成本对个人维护的产品也不现实。
- **为什么放弃 API**：REST API 描述操作没问题，描述计算图就变成深度嵌套的 JSON 迷宫；每加一种新能力都需版本化 API 和维护向后兼容，包袱太重。
- **DSL 的本质**：不是让 AI 写任意代码，而是限定在预定义正交积木里做组合——积木数量少，组合空间大。执行层是 DAG（有向无环图），AI 只需声明节点和依赖关系，引擎按拓扑排序执行，不需关心执行顺序。

## 具体机制
- **Schema 供应链**：同一份 Schema 驱动 CI 生成 LLM quickstart 文档（74KB）、Web 编辑器 AJV 校验、引擎运行时类型检查——文档与执行永远同源，杜绝 AI 生成与引擎执行的漂移。
- **Prompt 演化**：从简单原语清单（高失败率）→ 加约束说明 → ABSOLUTE PROHIBITIONS（展示 AI 真实犯过的错误与正确写法对比）+ 12 个分级 few-shot 示例（Level 1 双均线到 Level 12 加密货币链上指标），覆盖 97.5% 的原语；ABSOLUTE PROHIBITIONS 比正向引导更有效，原因是 AI 在"明确禁止"下比"应该怎么做"下更谨慎。
- **原语扩展案例**：Streak 原语（带状态，记录条件连续满足天数）在 A 股股债轮动策略（2018-2024 回测）中，将胜率从 40% 提升至 81.3%，年化收益从 1.65% 升至 5.42%，交易次数从 60 次降至 16 次，盈亏比从 2.5 升至 40.69。QQQ 相对强度策略中，引入连续两日确认机制将最大回撤从 -93.83% 降至 -53.96%，2020-2025 年化 27.28%。
- **混合 Agent 架构**：Local Agent（浏览器内 ReAct）处理模糊意图和 UI 状态，Remote Agent（Python 异步服务）处理确定性重计算（常超 30 秒）；Redis 队列解耦两层，结构化 JSON 任务入队。核心分工一句话：Local 处理 Ambiguity，Remote 处理 Workload。

## 隐藏限制
DSL 不是银弹：带复杂历史路径依赖的状态机逻辑用声明式 DSL 表达极别扭，强行覆盖会让 DSL 膨胀成另一门语言（DSL Hell）。最终系统保留两条路：原语 DSL 处理 90% 的无状态组合逻辑，Python 代码路径留给高阶复杂状态场景，共用同一套回测框架和数据管道。

## 系统最终是关于纪律的，不是关于答案的
三条原则贯穿全文：约束生成空间优于修复输出；文档与执行必须同源；确定性层（队列、回测计算）与概率性层（自然语言理解、分析文本生成）必须分离。更深一层：在高风险决策系统中，目标不是"给出答案"，AI 一秒能给十个——而是帮人建立一套自己能理解、能信任、能持续执行的决策框架。用户在回撤时不乱动，靠的是理解，不是意志力。
