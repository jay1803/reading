## 激励结构失效，而非技术能力缺失

美国没有主流开源 AI 模型的根本原因是激励问题，不是技术问题。中国 DeepSeek、Qwen、Kimi 能做，说明技术门槛可逾越；但美国 VC 体系找不到为开源模型融资的逻辑。开源软件的变现路径（托管服务、企业功能、专有引擎）在模型层几乎失效——任何人都可以拿起权重起一个推理 API 端点直接竞争，而竞争者里包括 Fireworks、Baseten 和全部超大规模云厂。

## 开源软件商业化路径为什么不能套用到模型

传统开源的核心是"先成为默认选项，再找变现层"（Kafka / Spark / Mongo 模式）。模型层的问题：权重一旦公开，变现层的差异化壁垒几乎不存在。微调 + 评估反馈循环是最自然的第二步，但同样竞争者太多。许可证差异（MIT/Apache 全开放 vs Llama 商业限制 vs 完整训练数据开源）影响开发者社区在哪里聚集，并决定谁捕获商业价值——但这个变量本身解决不了变现逻辑缺失的问题。

## 蒸馏路径正在关闭

中国模型主要靠蒸馏前沿模型快速追近。这条路之后会越来越难：前沿模型的使用方式从问答对变成了 50+ 个并行 agent 的复杂工作流，"蒸馏"很难从这类系统提取有效信号；部分前沿模型根本不开放 API 而是直接包进产品。不蒸馏就要从头预训练，成本是另一个量级。作者现在倾向认为前沿与开源的差距在扩大，而不是收窄。

## 出路

三个可能的破局点：
1. 英伟达（Jensen Huang）或各国政府出于主权利益提供大规模资金——类似当年 Nvidia 扶植 Neocloud 生态的逻辑
2. 开源先于闭源获得某个研究突破
3. 闭源前沿实验室主动开源旧版本或精简版（作者认为这是最现实的希望）
