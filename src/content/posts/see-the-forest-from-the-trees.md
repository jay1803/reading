## TL;DR

这篇文章主要分析了 Forrester Wave 发布的 2020 年第一季度企业检测与响应（EDR）报告。报告指出，CrowdStrike 在 EDR 领域处于领先地位，其安全分析能力是关键的差异化因素。文章还讨论了 Elastic Security 的潜力与定价模式，并认为 Forrester 对其定价模式的负面评价有误。

## 主题

### 🛡️ 行业报告分析

Forrester Wave 发布了 2020 年第一季度企业检测与响应（EDR）报告。报告指出安全分析能力是 EDR 供应商的关键差异化因素。CrowdStrike 在该报告中被评为领导者，并在“最强战略”方面排名最高。CarbonBlack 则落后。

### 🥇 CrowdStrike (CRWD)

Forrester 认为 CrowdStrike 是 EDR 市场的领导者，拥有最佳的安全分析能力。CrowdStrike 的优势在于其威胁情报和相关服务，能够检测到最新的攻击。Forrester 认为 CrowdStrike 在以下方面表现出色：

## **战略：** 排名最高，尽管在“计划增强功能”方面得分较低，但仍被认为是明确的第一。
## **市场占有率：** 与 Microsoft 并列最高，客户数量同比增长 116%，收入同比增长 89%。
## **当前产品：** 排名第三，主要是在“支持的系统”（Mac 和 Linux 系统）和“扩展能力”方面得分较低。
## **响应能力：** 得分仅为 3.0，低于竞争对手，表明在自动化响应处理方面有待提高。

### 📊 Elastic (ESTC) Security

Forrester 认为，如果 Elastic 的商业模式不拖后腿，它有潜力颠覆 EDR 市场。Forrester 对 Elastic Security 的定价模式持负面看法，认为其消费模式会阻碍用户采用。文章作者强烈反对 Forrester 的观点，认为 Elastic 的定价模式（特别是对于拥有大量设备的企业）具有巨大的成本优势。

Forrester 认为 Elastic Security 的问题在于它更像是一系列很酷的概念验证的集合，而不是一个单一的产品。文章作者认为，Elastic Security 的主要问题在于其数据分析范围仅限于单个客户，而 CrowdStrike 等云原生解决方案可以分析所有客户的数据，从而发现更广泛的威胁趋势。

## 总结

CrowdStrike 凭借其卓越的安全分析能力，在 EDR 市场中处于领先地位，而 Elastic Security 虽然具有潜力，但其数据分析范围受限，可能影响其竞争力。
