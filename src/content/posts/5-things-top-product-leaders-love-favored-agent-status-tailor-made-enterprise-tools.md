## 企业软件的下一局：定制取代通用，代理通道成护城河

通用企业软件（Workday、Adobe、Atlassian 等）迫使所有公司以近乎相同方式运营，导致运营层面无法真正差异化。AI 加上 vibe coding 和 MCP，正在解锁"定制软件"时代：小型内部工程团队可为公司量身构建 CompanyOS——专属于本公司文化、工作流和代理部署逻辑的操作系统。

### 企业软件格局的三条推论

- **图谱持有者将赢**：以 Atlassian 为例，其 teamwork graph（用户交互、项目关系、工作逻辑）才是与 AI 结合后真正生成价值的资产。即便应用界面被定制软件替代，图谱本身仍有护城河。
- **大模型需求将分裂**：默认调用 Claude/OpenAI 前沿模型的必要性在下降。法律、医疗、物理等垂直定制模型（无论 Anthropic 开发还是开源微调）将取代通用调用。
- **最好的行业软件只会存在于一家公司内部**：别人无法复制，因为它是专为该公司量身打造的。

### "优先代理"身份是 consumer agent 的真正护城河

Instinct、Littlebird、Hermes 等 consumer agent 全都撞上同一道墙：CAPTCHA 和反 bot 机制。真正的破局点不是技术，而是商业协议——如果 agent 公司能与 Uber、Amazon、Airbnb、Amex 等签订"优先代理"通道协议，获得直接 API 访问权（比人类更快、更便宜），就能彻底绕过网页导航转为数据/服务直连。服务商同样受益：合法代理带来行动力强、自带信用卡的高质量流量。最先锁定"优先通道"的 agent 公司将形成难以追赶的先发优势。

### 产品领导者的五项核心热爱

Belsky 强调这五项不是建议，而是筛选条件——不具备这些热爱的人不适合做产品领导：

1. **热爱批评和质疑**：区分 cynicism（警惕）和 doubt（从中建立信心）。当所有人说你疯了，要么你真的错了，要么你真的发现了什么。
2. **热爱激烈内部辩论**：辩论是导航"答案不显然地带"的最高效机制，也是对抗团队冷漠的手段。
3. **热爱 merchandising**：不只是销售，而是在任何受众面前持续叙事——招聘、留人、对齐团队、建立文化都依赖它。商学院不教，但它最重要。
4. **热爱建团队和文化本身，不亚于建产品**：团队质量直接显现在产品质量里；能在波动中变强的文化才是跨行业真正的竞争优势。
5. **热爱与客户在一起**：最好的产品来自对"痛点"的共情，而非对"解法"的热情。
