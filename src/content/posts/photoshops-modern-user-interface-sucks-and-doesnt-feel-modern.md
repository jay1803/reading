## TL;DR
Photoshop 2026 的“现代界面”把已被验证的交互细节做坏了：焦点、字段选择、Tab 顺序、Undo、错误反馈等基础机制退化，导致专业工具从顺手的肌肉记忆系统变成持续索取注意力的摩擦源。

## 核心主张拆解
- 新 Spectrum 视觉语言没有产生明确的现代感或效率收益；作者看到的是新的错位、新的不协调，以及和旧界面相比偏横向替换的设计变化。
- 最大问题集中在“焦点”这一类底层交互：打开尺寸窗口时第一个字段不自动聚焦；点击字段后旧值不预选中；部分输入框区域显示 hover 却无法聚焦；清空字段会弹出粗糙错误模态框，并把焦点从字段拿走。
- 这些退化直接破坏高频工作流。过去可以“输入宽度 → Tab → 输入高度 → Enter”的键盘路径，现在 Tab 会经过 Pixels 菜单；Photoshop 还忽略 macOS 的 Keyboard navigation 偏好，并且自身也不一致，因为 Anchor 又不能通过 Tab 到达。
- 其他问题说明这不是单点 bug：点击 relative 复选框或 canvas extension color 不再恢复上一个控件焦点；拖动 slider 后 ⌘Z 被 UI 元素吞掉；下拉菜单变慢；某些 tooltip 和像素瑕疵显得缺乏基本打磨。
- 对专业工具而言，微摩擦会被工作时长放大。一个每天 8 小时使用 Photoshop 的人，会把这些“纸割伤”重复成长期效率损耗和情绪损耗。

## 为什么这比普通 UI 吐槽更严重
- Photoshop 这次变化看不出是在转向新客群或新战略；核心用户仍然需要原来的精密操作能力，但原有帮助他们省力的细节被移除了。
- 作者批评的多数问题都是成熟解法：字段进入时预选中、错误轻量提示、遵循系统键盘导航偏好、保留 Undo 语义、让焦点行为可预测。这些不需要前沿研究，只需要尊重 UI 工程基本功。
- 内部驱动的界面刷新需要补偿用户迁移成本：要么讲清楚新设计带来的价值，要么提供实际可感知的改进。文章认为 Adobe 两者都没做到，只留下一个可关闭“modern user interface”的设置，像延期而非解决方案。

## 值得质疑
- 文章来自长期 Photoshop power user，判断标准明显偏向高频专业操作；轻量用户可能更关心视觉一致性或可发现性，而不一定立即感知这些键盘路径损耗。
- Tab 顺序确实存在无障碍完整导航与专家快捷路径之间的张力；作者也承认这是难题。更强的论证需要 Adobe 的设计目标、可访问性约束和用户测试结果来对照。
- 即便如此，文中许多例子是可复现的具体交互缺陷，不依赖审美偏好；尤其是焦点丢失、值不预选中、Undo 被吞，足以支撑“基础质量下降”的判断。

## 可执行改进
- 把输入错误从阻断式模态框改成字段旁的轻量提示，并保留当前字段焦点。
- 支持更完整的表达式输入，例如在尺寸字段直接输入 `660*2`。
- 公开或提示已经存在的隐形快捷键，减少用户靠记忆和偶然发现工作。
- 给常用选项增加记忆能力，例如 Use Legacy 这类反复切换项。
- 让 Tab 顺序遵循系统偏好，并保证同一窗口内所有控件的键盘可达性规则一致。

## 最后一眼
这篇文章真正刺中的不是“新版不好看”，而是专业软件正在丢失对长期用户肌肉记忆的尊重；当一个工具把成熟细节当成可牺牲装饰，界面刷新就会变成信任折旧。
