## 抽象层的膜可以双向穿透：legibility 才是编程能力的护城河

Doctorow 认为，每一代计算抽象（晶体管、高级语言、View Source、LLM）都在重复同一个恐慌——"下一代程序员会因为抽象太高而失去对底层的感知"。1968 年贝尔实验室的 CARDiac 纸板电脑（CARDboard Illustrative Aid to Computation）就是为了对抗晶体管化带来的这种担忧而设计的。历史证明这种恐慌每次都会部分实现、部分被化解。

核心能力不是"会用某个抽象层"，而是"能在多个抽象层之间自由移动"。真正的 Fingerspitzengefühl（指尖感）来自于实际操作底层：CARDiac 手动移卡片、杂志 BASIC 逐键抄写并自己发明调试器、View Source 拆解别人网页。就像物理、化学、生物学的分层关系——化学家平时用化学工具，但知道什么时候需要下钻到物理层级。

## 第一批程序员的反直觉案例

Claire Evans《Broad Band》记录：第一批程序员是女性，她们做的是被认为"非技术"的体力劳动——物理接线。这项工作反而给她们提供了最高保真的跨层次心智模型，让她们成为那个时代最好的 debuggers。"入门门槛低"和"对底层的深刻理解"不互斥。

## Vibe coding 是漏斗顶端，不是文明终点

LLM 生成代码、View Source、Stack Overflow 粘贴、Excel 宏录制器——结构上都是"自动生成代码的漏斗顶端"。多数人拿到解决方案就离开；少数人会开始好奇"膜里面是什么"，沿着抽象栈向下追溯。进漏斗的人越多，产生的工匠就越多。

Doctorow 明确区分了个人软件（personal software）与生产软件：个人软件只要解决自己的问题就算成功，不需要可维护、可扩展。vibe coding 的辩护不依赖于"它最终会产生大师"，而是"解决自己的问题本身就有价值"——这和用 CARDiac 手动加一加一在道德地位上等价。
